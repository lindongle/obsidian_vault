**ai**: 在 Teamcenter 和 Active Workspace (AWC) 中，表渲染（表格属性渲染）的配置主要分为**基础样式表（XRT）配置**和 **AWC 高级模板（propertyRendererTemplates）配置**两种方式。

### 一、 基础样式表（XRT）表格属性配置
在 Teamcenter 的样式表（`XMLRenderingStylesheet`）中，可以通过 `<tableProperty>` 标签来定义表格及其包含的列属性[^1]。配置完成后，在客户端点击编辑时会自动出现添加/移除/复制按钮[^2]。

**配置示例 1：在 Section 中定义表格**
```html
<section titleKey="tc_xrt_FirstTrial" collapsed="true">
    <tableProperty name="y6_CRFirstReview" width="100%">
        <property name="y6_IDX" width="65"/>
        <property name="y6_ReviewDepartment"/>
        <property name="y6_ReviewPeople"/>
        <property name="y6_ReviewResult"/>
    </tableProperty>
    <break/>
</section>
```

**配置示例 2：在 Page 中定义表格**
```html
<page title="Table Property" visibleWhen="object_type=A2_newRevision">         
    <section title="Employee Information - Definition Details"> 
        <tableProperty name="a2myTestTable">            
            <property name="a2FirstName"/>             
            <property name="a2LastName"/>            
            <property name="a2EmployeeID"/>            
        </tableProperty>    
    </section>      
</page>
```

### 二、 AWC 表格属性特殊渲染（propertyRendererTemplates）
如果需要在 AWC 中对表格控件的属性进行特别的渲染（例如：显示客户化的发布状态图标、给文字加背景颜色等），可以使用 AWC 4.2 引入的 `propertyRendererTemplates` 功能[^3]。

- **配置文件路径**：主要涉及 `stage\components\activeworkspace\repo\kit\tc-aw-framework\module.json` 文件中的模板配置[^4]。
- **配置方式**：通过配置模板（如 `release_status_template`）并指向自定义的 HTML 文件，来实现特定的图标或样式渲染逻辑[^5]。
- **XRT 替代方案**：由于 XRT 中的标准属性暂不支持直接进行此类高级配置，可以通过在 XRT 中插入 `<htmlPanel>` 标签，并编写自定义的 HTML 代码逻辑来替代实现[^6]。

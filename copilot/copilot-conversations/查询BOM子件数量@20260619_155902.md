# 1. 查询BOM子件的基本信息
要查询BOM子件的基本信息，可以使用以下SQL语句：

```sql
SELECT * FROM ppsoccurrence WHERE rparent_bvru = 'your_parent_bom_id';
```

这里的 `rparent_bvru` 是父级BOM的唯一标识符，`your_parent_bom_id` 需要替换为实际的父级BOM ID。

# 2. 查询BOM子件的数量
要查询BOM子件的数量，可以使用以下SQL语句：

```sql
SELECT COUNT(*) AS num_children FROM ppsoccurrence WHERE rparent_bvru = 'your_parent_bom_id';
```

这里的 `COUNT(*)` 会返回符合条件的记录数，即BOM子件的数量。

# 3. 查询特定BOM子件的数量
如果需要查询特定BOM子件的数量，可以使用以下SQL语句：

```sql
SELECT COUNT(*) AS num_children FROM ppsoccurrence WHERE rparent_bvru = 'your_parent_bom_id' AND rchild_itemu = 'your_child_item_id';
```

这里的 `rchild_itemu` 是子件的唯一标识符，`your_child_item_id` 需要替换为实际的子件ID。

# 4. 查询BOM子件的详细信息
如果需要查询BOM子件的详细信息，可以使用以下SQL语句：

```sql
SELECT * FROM ppsoccurrence WHERE rparent_bvru = 'your_parent_bom_id';
```

这将返回所有与指定父级BOM相关的子件信息。

# 5. 查询BOM子件的数量和详细信息
如果需要同时查询BOM子件的数量和详细信息，可以使用以下SQL语句：

```sql
SELECT COUNT(*) AS num_children, * FROM ppsoccurrence WHERE rparent_bvru = 'your_parent_bom_id';
```

这将返回BOM子件的数量和所有相关详细信息。

# 6. 查询BOM子件的数量和详细信息（带条件）

```sql
SELECT COUNT(*) AS num_children, * FROM ppsoccurrence WHERE rparent_bvru = 'your_parent_bom_id' AND rchild_itemu = 'your_child_item_id';
```

这将返回符合特定条件的BOM子件的数量和详细信息。

# 7. 查询BOM子件的数量和详细信息（带分页）

```sql
SELECT * FROM ppsoccurrence WHERE rparent_bvru = 'your_parent_bom_id' ORDER BY pseq_no LIMIT 10 OFFSET 0;
```

这里的 `LIMIT 10 OFFSET 0` 表示每页显示10条记录，从第0条开始。

```sql
SELECT * FROM ppsoccurrence WHERE rparent_bvru = 'your_parent_bom_id' ORDER BY pseq_no;
```

这里的 `ORDER BY pseq_no` 表示按 `pseq_no` 字段排序。

# 9. 查询BOM子件的数量和详细信息（带过滤）
如果需要根据特定条件过滤查询BOM子件的数量和详细信息，可以使用以下SQL语句：

```sql
SELECT * FROM ppsoccurrence WHERE rparent_bvru = 'your_parent_bom_id' AND pqty_value > 0;
```

这里的 `pqty_value > 0` 表示只查询数量大于0的BOM子件。

# 10. 查询BOM子件的数量和详细信息（带连接）

```sql
JOIN pitemrevision ON ppsoccurrence.rchild_itemu = pitemrevision.puid 
WHERE ppsoccurrence.rparent_bvru = 'your_parent_bom_id';
```

这里的 `JOIN` 语句用于连接 `ppsoccurrence` 表与其他表，以获取更多详细信息。

     ```bash
     index_verifier -u=infodba -p=infodba -g=dba -o=DRYRUN
     ```

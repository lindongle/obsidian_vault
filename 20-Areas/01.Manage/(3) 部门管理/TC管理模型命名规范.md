# <span style='color:#1E4E79'>定义原则：</span>
- 所有命名使用英文，不允许出现拼音，不允许不做翻译，使用数字或字母代替；
- 英文单词，由客户提供，我方自行翻译的，网上搜索专业词汇，不允许使用翻译工具进行硬翻译；
- 如果多个英文单词超长，则根据长度（最长16位），单词从后往前，将英文单词全拼转为单词缩写（缩写首字母大写），缩写查询网址：https://www.abbreviations.com/，或直接百度搜索XX英文 缩写；如y6_StandardSpecification，可转为y6_StandardSpec；
- 命名不能使用特殊字符，只允许使用下横线；
- POM对象最多16个字符，LOV/度量单位等对象最多32个字符，属性长度最多27个字符；
# <span style='color:#1E4E79'>前台：</span>
- **首选项、handler、查询构建器：**CUST_英文全拼，首字母大写；
- **开发用查询：**\_\_CUST_英文全拼（两个下横线），首字母大写；
- **流程模板：**10/20/30_英文全拼，首字母大写；
- **ACL：**CUST_英文全拼，首字母大写；
- **渲染：**数据集及命名引用名称：Item类型_渲染类型，如Y6_ItemRevision_Summary.xml
# BMIDE：如无特殊要求，统一Y6/y6_开头

# 定义原则：
- 所有命名使用英文，不允许出现拼音，不允许不做翻译，使用数字或字母代替；
- 英文单词，由客户提供，我方自行翻译的，网上搜索专业词汇，不允许使用翻译工具进行硬翻译；
- 如果多个英文单词超长，则根据长度（最长16位），单词从后往前，将英文单词全拼转为单词缩写（缩写首字母大写），缩写查询网址：https://www.abbreviations.com/，或直接百度搜索XX英文 缩写；如y2_StandardSpecification，可转为y2_StandardSpec；
- 命名不能使用特殊字符，只允许使用下横线；
# 前台：
- **首选项、handler、查询构建器：**CUST_英文全拼，首字母大写；
- **开发用查询：**\_\_CUST_英文全拼（两个下横线），首字母大写；
- **流程模板：**10/20/30_英文全拼，首字母大写；
- **ACL：**CUST_英文全拼，首字母大写；
- **渲染：**数据集及命名引用名称：Item类型_渲染类型，如Y2_ItemRevision_Summary.xml
# BMIDE：如无特殊要求，统一Y2/y2_开头
- **文件夹：**Y2_FD_英文全拼，首字母大写
- **零组件类型：**Y2_TY_英文全拼，首字母大写；
- **关系：**Y2_REL_英文全拼，首字母大写；
- **属性(**含常规属性、PSOCC属性、BOMLINE属性等)：y2_英文全拼，首字母大写，不同类型相同属性，使用相同名称；
- **表单：**Y2_FM_英文全拼，首字母大写；
- **数据集：**Y2_DS_英文全拼，首字母大写；
- **表对象：**Y2_TAB_英文全拼，首字母大写；
- **工具：**Y2_TL_英文全拼，首字母大写；
- **数据集引用：**Y2_DSRF_英文全拼，首字母大写；
- **LOV：**Y2_LOV_英文全拼，首字母大写；
- **条件：**Y2_COND_英文全拼，首字母大写；
- **命名规则：**Y2_NR_英文全拼，首字母大写；
- **版本命名规则：**Y2_RNR_英文全拼，首字母大写；
- **状态：**Y2_ST_英文全拼，首字母大写；
- **注释类型：**Y2_NT_英文全拼，首字母大写；
- **单位：**Y2_UNIT_英文全拼，首字母大写；
- **视图类型：**Y2_VT_英文全拼，首字母大写；

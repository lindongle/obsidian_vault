1.  规格管理：
<span style='color:#000028'>**即时提供当前规格**</span>
<span style='color:#000028'>Opcenter Specification 为企业内的所有材料和产品规格提供单一数据源和规格管理。</span>
<span style='color:#000028'>**提高搜索效率**</span>
<span style='color:#000028'>更快速、更轻松地搜索所有规格详细信息。规格管理确保规格保持更新状态，并且易于在企业的统一存储库中访问。</span>
<span style='color:#000028'>**缩短响应时间**</span>
<span style='color:#000028'>在单一数据源中使用扩展的搜索和筛选功能，大幅缩短响应时间。在某些情况下，客户反映他们能够将反馈时间从七天缩短到即时。</span>
<span style='color:#000028'>**加强供应商协同**</span>
<span style='color:#000028'>在产品开发过程中让供应商参与进来，并邀请他们在系统的安全部分填写所交付材料的规格，从而消除重复输入错误。将必填字段标记为必填，确保一次即可正确提供配方物料清单所需的所有信息。</span>
<span style='color:#000028'>**管理文档和版本**</span>
<span style='color:#000028'>将文档添加到规格或产品开发项目中，Opcenter Specification 充当文件容器。规格管理可确保每个文档的当前版本始终链接到规格。</span>
<span style='color:#000028'>**高效管理产品开发项目数据**</span>
<span style='color:#000028'>使用电子笔记本将所有与项目相关的数据和文档集中起来。在电子笔记本中设置项目团队成员、里程碑、项目开发目标和目标市场，以便在以后的配方开发工作中实现高效的重用。</span>
<span style='color:#000028'>**利用过去的经验**</span>
<span style='color:#000028'>重用过去项目中保存在电子笔记本中的所有可用信息，包括快消品物料清单，轻松启动新项目。规格管理可加快新项目的启动，并显著缩短上市时间。</span>
<span style='color:#000028'>**自动进行合规管理**</span>
<span style='color:#000028'>利用配方物料清单和所有规格详细信息来汇总成分、营养信息、过敏原、声明和任何其他所需信息，自动创建合规标签。</span>
<span style='color:#000028'>**提供完整的报告**</span>
<span style='color:#000028'>使用 Opcenter Specification 完整报告功能轻松打印产品数据表和其他类型的报告。在报告中列出要批准的规格数量。</span>

*来自 \< <https://plm.sw.siemens.com/zh-CN/opcenter/research-development-laboratory/specification/>\>*

2.  配方管理：
<span style='font-weight:bold;background:white'>缩短产品上市时间，提高产品上市成功率</span>
<span style='background:white'>Opcenter Formulation 以数字方式呈现配方变化对产品性能的影响，减少实际试验并节省时间和金钱。</span>
<span style='font-weight:bold;background:white'>模拟产品性能</span>
<span style='background:white'>从现有 BOM 开始配方开发或从头开始，并使用配方的数字孪生来查看配方变化对成本、营养价值、快消品合规等的直接影响。大幅缩短上市时间。</span>
<span style='font-weight:bold;background:white'>缩短配方开发周期时间</span>
<span style='color:#000028;background:white'>从</span>[<span style='background:white'>Opcenter Specification</span>](https://plm.sw.siemens.com/zh-CN/opcenter/research-development-laboratory/specification/)<span style='color:#000028;background:white'>中的现有配方开始，启动配方优化。利用规格管理存储库缩短产品开发项目的交付周期，包括评估配方产品性能、配方比较和快消品合规。</span>
<span style='font-weight:bold;background:white'>立即查看目标影响</span>
<span style='background:white'>在配方开发项目定义期间设定目标，并使用配方的数字孪生在仿真期间立即查看配方变化对产品性能的影响。</span>
<span style='font-weight:bold;background:white'>遵守法规</span>
<span style='background:white'>与电子笔记本中的项目定义无缝连接。在配方模拟期间，系统将检查配方变化是否符合特定目标市场的当地法规。</span>
<span style='font-weight:bold;background:white'>以数字方式比较不同的配方</span>
<span style='background:white'>通过直观的配方比较功能轻松进行多种备选方案的配方比较。通过仅使用最符合目标的替代方案来限制实际试验的时间和费用。</span>

*来自 \< <https://plm.sw.siemens.com/zh-CN/opcenter/research-development-laboratory/formulation/>\>*

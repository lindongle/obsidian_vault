<span style='color:#333333;background:white'>it is possible to use the combination of </span><span style='font-weight:bold;color:blue;background:white'>QRY\_</span><span style='color:#333333;background:white'>\<query_name\></span><span style='font-weight:bold;color:blue;background:white'>\_SortKeys</span> and  
QRY_query_name_SortOrder preference.  
Below example shows the search results based on ID and in ascending order.
«span style='color:#333333'»- Create the query and save it. i.e. ItemSortID  
- Create two preference in Edit \> Options as following:  
QRY_ItemSortID_SortKeys = current_id (make sure to use the real name)  
QRY_ItemSortID_SortOrder = 1  
- Run the query again  
Query would show based on ID and in ascending order.«/span»
«span style='color:#333333'»The Teamcenter Help docs are not clear enough and a Document PR is created -  
PR 7124540«/span»
<span style='background:white'>Additional related infomation from Help docs:</span>
When you sort an advanced search query created with Query Builder, two  
internal preferences are created: <span style='font-weight:bold;color:blue;background:white'>QRY\_</span><span style='color:#333333;background:white'>\<query_name\></span><span style='font-weight:bold;color:blue;background:white'>\_SortKeys</span> and  
<span style='font-weight:bold;color:blue;background:white'>QRY\_</span>\<query_name\>\_SortOrder. If you see a query you are using has sort keys  
that do not match the sort keys shown in Query Builder in the rich client,  
choose Edit \>Options to display the Options dialog box, and then use the  
Filters pane to select and delete the existing sort key user preferences for  
the query.

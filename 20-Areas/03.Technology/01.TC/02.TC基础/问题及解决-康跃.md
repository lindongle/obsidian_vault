**3、【未完成】怎么在个人空间汇总便签页显示分类属性，表单属性如何跟分类参数建立引用关系（添加引用属性不好使）？测试表单属性发送到分类的视图无法引用过去，只有新增的属性，且发送到存储类中才可以。**

**6、【完成】如何统一修改所有用户的默认版本规则。**
在编辑-选项-选项-产品结构面板中，可以配置默认的版本规则，但只对当前用户有效。
![image4](f5ab5ad516ee455390f0042fc68079ef.gif)
无法配置对站点级有效。
1）上述方式修改一个其他默认版本规则，如Precise only，应用。将当前首选项导出：编辑-选项，切换到搜索便签页。点击面板的导出标签页。自位置选择用户，导出所有类别首选项，选择本地导出位置，并命名进行导出。
![image5](5c0bd1cd6fd54152a1f56b060205ecbe.gif)
再按照上述方式模板版本规则改为希望统一设置的值，如last working，应用，再按照上述操作导出第二个文件。用文本比较工具（WinMerge-2.13.20-Setup，自己百度下载或用其他比较工具），比较两个导出的plmxml文件，找到差异。即默认版本规则的首选项名称及值。即首选项名称为TC_config_rule_name，类别为Product Structure.PSE.Behavior，描述为Indicates the default config rule that will be used when opening/printing Imprecise BOMView or BOMViewRevisions. If this rule does not exist, the system will default to &quot;Latest Working。
![image6](4965e9d3fea14d219c3f2a1fe7130272.gif)
按照上述内容新建一个站点级的首选项即可。（上述仅为测试，TC_config_rule_name这个首选项已经存在）
![image7](b728b4535c814d98aac52455ab47311a.gif)

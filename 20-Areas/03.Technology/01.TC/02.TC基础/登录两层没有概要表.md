**SOLUTION**
In TC13.1 / AW5.1 TAO window does not appear for 2T client login Because in the previous TC version 2T clients communicate with the server using IIOP protocol but after TC13.1/AW5.1 IIOP protocol is no longer supported in Teamcenter. The Teamcenter two-tier rich client uses TCCS (Teamcenter client communication system) instead of IIOP (Internet Inter-ORB Protocol) to communicate with the corporate server. Existing IIOP-based two-tier rich clients are automatically converted to TCCS-based during the upgrade.

Due to a change in 2T client communication method with the server (IIOP to TCCS) we have to make some necessary changes at the time of installation through tem.bat as shown below,

Client Communication system Setting:
Name: TcEnv1
TC_DATA: E:\Siemens\Teamcenter\TC_DATA
Tag: 13.1或不填
SSO App ID: (if applicable) App ID of SSO Environment ( TCEngineering )
SSO Login URL: (if applicable) login URL of SSO server ( )
TcServer Character Encoding : UTF8
Single Server: True
![image1](c91a5eec6825498ea5b9ef99770efa36.png)
==或填\*==
After TEM installation of the above step perform the following steps
\- if you have an old fcc session running. -Then Stop fcc, %FMS_HOME%\bin\fccstat -stop.

\- On the next login attempt, a value will be shown in the 5th field.

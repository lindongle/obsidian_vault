1）在Teamcenter.ini文件内容的顶端，增加下列参数：
-perspective com.teamcenter.rac.gettingstarted.GettingStartedPerspective
或
![image1](721417d33f164a82aa5870ab45e8d78c.png)

其目的是为了启动时进入Get Started用户界面，而不是进入上次用户退出系统时的Application界面，从而避免登陆时因为加载Home下的大量数据而导致登陆时间过长。通常，系统缺省登陆会进入My Navigator界面，并且PLM用户Home目录下存放了大量的数据。
2）提前启动FCC服务。在用户登陆PLM系统时，系统后台会启动FCC服务，并和FSC服务进行沟通。FCC服务是一个基于JAVA的服务，需要一定的内存，同时要加载缓存里面的数据到内存中，时间消耗较大。

echo \*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*
echo 启动FCC客户端文件缓存服务
echo \*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*
set FMS_HOME=D:\Siemens\Teamcenter11\tccs
set JRE_HOME=C:\Program Files\Java\jre7
:retry
echo Starting FCC:
call %FMS_HOME%\bin\fccstat -start
set \_EL=%ERRORLEVEL%
rem Startup failed. Output an error, wait a while, and retry.
if "%\_EL%" == "0" goto worked
@ping 127.0.0.1 -n 30 -w 1000 \> nul
goto retry
:worked
echo FCC successfully started.

修改客户端JAVA内存：
从teamcenter10以后，不再修改teamcenter.ini文件，要修改portal.bat和otwportal.bat(owt客户端)
修改内容如下：
:start_portal
cd /d %TPR%
set CLASSPATH=.;
set VM_XMX=2048m
<span style='color:red'>set VM_XMS=2048m</span>
@echo Starting Teamcenter Rich Client...
start Teamcenter.exe %\* -vm "%JRE_HOME%\bin\javaw.exe" -vmargs -Xmx2048m -Xms2048m -Xverify:none -XX:SurvivorRatio=6 -XX:+UseParallelGC -XX:+DisableExplicitGC -XX:MaxPermSize=128m -Xbootclasspath/a:"%JRE_HOME%\lib\plugin.jar";"%JRE_HOME%\lib\deploy.jar";"%JRE_HOME%\lib\javaws.jar" %DJIPJL_VMARG%

即增加set VM_XMS=2048m，修改-vmargs -Xmx%VM_XMX%为-vmargs -Xmx2048m -Xms2048m -Xverify:none -XX:SurvivorRatio=6 -XX:+UseParallelGC -XX:+DisableExplicitGC

<span style='color:black'>Create Image 解决方案由客户端应用程序和Create Image 服务器组成。</span>
<span style='color:black'>服务器是网络中的工作场所，可以是工作站或专用应用程序服务器（例如文件服务器）。创建图像服务器由各种组件组成，这些组件在创建中性格式时执行不同的子任务。原则上，该过程可以分为以下几个阶段： </span>
<span style='color:black'>1. 作为发布过程的一部分启动一个动作处理程序，它为 Create Image 服务器创建一个作业。</span>
<span style='color:black'>2. 作业在服务器上接受并按要求进行处理。</span>
<span style='color:black'>3. 处理在后台进行，因此服务器可以作为服务、AT/Cron 作业或作为 DOS/Shell 脚本启动。对于 NX，首先直接从 NX/Manager 打开 NX 零件，然后从图纸创建 HPGL/2 或 CGM 文件。也可以同时发布属性文件。对于 IDEAS，I-DEAS mdf 文件从 I-DEAS 共享目录导出到一个临时的 Create Image 目录。此导出的 I-DEAS mdf 文件将转换为带有 I-DEAS 宏的 CGM 文件。此 CGM 文件由 VisConvert 转换为 HPGL。 Create Image Server for Solid Edge 将绘图和 CAD 属性（根据映射文件中的定义）导出到临时目录。然后更新此文件中的绘图标题和 EMF 数据，并使用 VisConvert 将其转换为 TIFF、PDF、CGM 或 HPGL。</span>
<span style='color:black'>4. 现在还可以选择将此 HPGL/2 或 CGM 数据转换为 TIFF/G4、多页 TIFF/G4、PDF 和多页 PDF（使用 Acrobat Distiller）或 Postscript。 TIFF 和 PDF 等格式也可以加盖签字。</span>
<span style='color:black'>5. 在下一步中，可以从 NX 3D 模型生成 JT 文件。这是为没有 JT 文件的模块组件自动创建的。 I-DEAS 或 Solid Edge 数据不支持此功能。</span>
<span style='color:black'>6. 对于 UGPART 数据集，可以选择在单独的步骤中创建 DXF 或 DWG 格式。 I-DEAS 或 Solid Edge 数据不支持此功能。</span>
<span style='color:black'>7. 还有直接标记 TIFF 或 PDF 数据的选项，例如，为了将现有的中性格式标记为无效。</span>
<span style='color:black'>8. 最后，可以将创建的文件作为单独的对象导入回 Teamcenter 数据库，并分配给原始版本状态（修订）。或者它们被复制到操作系统级别的一个特殊目录，其他系统可以从那里使用它们。</span>
<span style='color:black'>9. 可以配置集成的通知机制，以便在出现通知或错误消息时自动向系统管理员发送电子邮件。</span>

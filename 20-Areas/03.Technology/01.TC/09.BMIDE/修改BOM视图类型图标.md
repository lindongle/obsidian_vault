In your customer.properties file define the icon
SGView.ICON=images/View_16.png - Display name of the ViewType S4SGView
S4SGView.ICON=images/View_16.png - Real name of the ViewType S4SGView
SG\\ View\\ Type.ICON=images/View_16.png - Display name of the ViewType S4SGViewType
S4SGView.ICON=images/View_16.png - Real name of the ViewType S4SGViewType

Note when you have spaces in the display name you have to escape it with the backslash character

The problem where using the embedded viewer to view Excel blocks other Excel Sessions has been investigated and the following has been found. Starting from Teamcenter 9.1.x and 10.1.x and all TC11.x releases, displaying the xls file in Viewer view will not work. . This issue is not related to the Teamcenter code but with the OLE integration. This is a Microsoft issue. At this time we don't know when Microsoft will provide fix.

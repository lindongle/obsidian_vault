In Teamcenter preferences (Edit\>Options), set these as SITE preferences:
Under preference defaultViewerConfig.VIEWERCONFIG
\>\>REMOVE \>\> PDF.PDFViewer=PDF_Reference,PDF
\>\>ADD \>\> PDF.TCTwoDViewer=PDF_Reference,PDF
Under preference TC_DIS_2D_named_ref
\>\>Add "PDF_Reference"
Under preference TC_markup_named_ref
\>\>Add "PDF_Reference"
Under preference DMI_markup_relation_primary
Add "PDF"
Under preference VMU_FileSearchOrder
Add "PDF_Reference"
Under preference VMU_Datasets
Add "PDF"
Restart the Teamcenter Rich Client.
You should be able to view and save markups in the MyTc portal viewer at
certain license levels. You can also markup in the Lifecycle Viewer.

ViewDWG files in Embedded Viewer
Symptom
---------------
How can I configure the Rich Client so that AutoCAD DWG and DXF files display
in the Embedded Viewer ('My Temcenter-\> Viewer')?
Hardware/Software Configuration
Teamcenter version 10.1.x
Embedded Viewer
All Platforms
Solution
The Teamcenter administrator must use 'Edit-\> Otions...' to modify the
following list of preferences enabling DXF and ACADDWG dataset types in the 2D
Viewer.
Add to preference "defaultViewerConfig.VIEWERCONFIG":
DXF.TCTwoDViewer=DXF,DXF
ACADDWG.TCTwoDViewer=DWG,ACADDWG
Add to preference "TC_DIS_2D_named_ref":
DXF
DWG
Add to preference 'TC_markup_named_ref':
DXF
DWG
Add to preference 'DMI_markup_relation_primary':
DXF
ACADDWG
Add to preference 'VMU_FileSearchOrder':
DXF
DWG
Add to preference 'VMU_Datasets':
DXF
ACADDWG
Restart the Teamcenter Rich Client.
1\. Open My Teamcenter
2\. Locate and select an AutoCAD file (dwg or dxf)
3\. Select the 'Viewer' tab
4\. A graphic view of the AutoCAD file opens.
For 3D viewing,
1\. Select the AutoCAD dataset
2\. Select 'Start/Open in Lifecycle Visualization

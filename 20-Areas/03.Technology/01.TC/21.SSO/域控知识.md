<span style='background:white'>1、</span>
<span style='background:white'>LDAP的存储规则</span>
<span style='background:white'>区分名（DN，Distinguished Name）</span>
<span style='background:white'>和自然界中的树不同，文件系统/LDAP/电话号码簿目录的每一片枝叶都至少有一个独一无二的属性，这一属性可以帮助我们来区别这些枝叶。</span>
<span style='background:white'>在文件系统中， 这些独一无二的属性就是带有完整路径的文件名。比如/etc/passwd，该文件名在该路径下是独一无二的。当然我们可以有/usr/passwd, /opt/passwd，但是根据它们的完整路径，它们仍然是唯一的。</span>
<span style='background:white'>在LDAP中，一个条目的区分名称叫做“dn”或者叫做区分名。在一个目录中这个名称总是唯一的。比如，我的dn是"uid=aghaffar, ou=People, o=developer.ch"。不可能有相同的dn，但是我们可以有诸如"uid=aghaffar, ou=Administrators, o=developer.ch"的dn。这同上面文件系统中/etc/passwd 和 /usr/passwd的例子很类似。</span>
<span style='background:white'>我们有独一无二的属性，在"ou=Administrators, o=developer.ch" 中uid和在"ou=People, o=developer.ch"中的uid。这并不矛盾。</span>
<span style='background:white'>CN=Common Name 为用户名或服务器名、组名，最长可以到80个字符，可以为中文；</span>
<span style='background:white'>OU=Organization Unit为组织单位，最多可以有四级，每级最长32个字符，可以为中文；</span>
<span style='background:white'>O=Organization 为组织名，可以3—64个字符长</span>
<span style='background:white'>C=Country为国家名，可选，为2个字符长</span>
<span style='background:white'>LDAP目录以一系列“属性对”的形式来存储记录项，每一个记录项包括属性类型和属性值（这与关系型数据库用行和列来存取数据有根本的不同）。</span>
<span style='background:white'>2、</span>
<span style='background:white'>CN, OU, DC 都是 LDAP 连接服务器的端字符串中的区别名称（DN, distinguishedname）</span>
<span style='background:white'>LDAP连接服务器的连接字串格式为：ldap://servername/DN</span>
<span style='background:white'>其中DN有三个属性，分别是CN,OU,DC</span>
<span style='background:white'>LDAP是一种通讯协议，如同HTTP是一种协议一样的！</span>
<span style='background:white'>在 LDAP 目录中，</span>
<span style='background:white'>·DC (Domain Component)</span>
<span style='background:white'>·CN (Common Name)</span>
<span style='background:white'>·OU (Organizational Unit)</span>
<span style='background:white'>LDAP 目录类似于文件系统目录。</span>
<span style='background:white'>下列目录：</span>
<span style='background:white'>DC=redmond,DC=wa,DC=microsoft,DC=com</span>
<span style='background:white'>如果我们类比文件系统的话，可被看作如下文件路径:</span>
<span style='background:white'>Com\Microsoft\Wa\Redmond</span>
<span style='background:white'>例如：CN=test,OU=developer,DC=domainname,DC=com</span>
<span style='background:white'>在上面的代码中 cn=test 可能代表一个用户名，ou=developer 代表一个 active directory 中的组织单位。这句话的含义可能就是说明 test 这个对象处在domainname.com 域的 developer 组织单元中。</span>

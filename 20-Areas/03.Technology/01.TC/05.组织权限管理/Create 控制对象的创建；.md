Create 控制对象的创建；
Read 控制打开和查看；
Write 控制数据进出数据库及修改；
Delete 控制从数据库中删除对象；
==Change== 控制对象修改保护的权限；
Promote 控制在工作流程过程中批准任务；
Demote 控制在工作流程过程中退回任务
Copy 控制将对象复制为新的对象，但不控制复制引用，只要复制不出新对象即可；
Change ownership 控制更改所有权，前提是必须要写权限；
==Publish== 控制对用户或组的发布特权。
Subscribe 控制订阅某对象的事件；
Export 控制从数据库导出数据；
Import 控制从外部导入数据库数据；
Transfer out 控制从数据库中导出对象时转移对象的所有权；
Transfer in 控制导入对象到数据库时指派对象的所有权；
Write Classification ICO 控制将对象保存到分类中；
Assign to project 控制将对象分配给项目；
Remove from project 控制将对象移出项目；
==Remote checkout== 控制远程签出；
==Unmanage== 使用户通过首选项TC_session_clearance规避已实施的阻止；
IP Admin 控制可以添加用户管理用户IP许可证；
ITAR Admin 使用户可以添加要管理的infodba用户 ITAR许可证；
CICO 控制用户可以覆盖签出对象的权限；
Translation 控制使用“本地化”按钮添加翻译文本的权限；
View/Markup 控制查看和创建标记的权限；
Batch Print 控制打印多个对象的特权；
Digitally Sign 控制对文档进行数字签名的特权；
Void Digital Signature 控制撤消或取消业务对象的现有PKI数字签名的特权；
Administer ADA Licenses 控制在ADA许可证应用程序中为用户创建，修改或删除ADA许可证的特权；
IP Classifier 控制对知识产权（IP）信息进行分类的特权；
ITAR Classifier 控制对国际武器交易（ITAR）信息进行分类的特权；
==Remove== Content 允许智能发现和第四代设计（4GD）的用户从协作设计（CD）中删除内容；
Add Content 允许智能发现和第四代设计（4GD）的用户从协作设计（CD）中增加内容；
Effectivity 允许用户修改释放对象的有效性；
Manage Variability 允许用户添加或删除产品结构与配置器上下文之间的关联；
PDF Control 允许用户添加系统图章和使用工作流将水印添加到现有PDF。

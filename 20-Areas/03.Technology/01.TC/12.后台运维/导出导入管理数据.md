<span style='color:#1E1E1E'>使用 TEM 导出部分管理数据</span>
您可以使用[**admin_data_export**命令行实用程序](https://docs.sw.siemens.com/en-US/product/282219420/doc/PL20190919161134969.rapid_start_admin_help_html_sc.managing_admin_data/html/xid1159898#utility)或 Teamcenter 环境管理器将管理数据导出到管理数据包中。Teamcenter 环境管理器中的部分导出和[完全导出](https://docs.sw.siemens.com/en-US/product/282219420/doc/PL20190919161134969.rapid_start_admin_help_html_sc.managing_admin_data/html/xid733784#full)过程各不相同。
<span style='color:#212529'>注意：</span>
了解[部分导出管理数据的注意事项](https://docs.sw.siemens.com/en-US/product/282219420/doc/PL20190919161134969.rapid_start_admin_help_html_sc.managing_admin_data/html/xid1152159)非常重要。
<span style='color:#212529'>您可以使用 Teamcenter 环境管理器 （TEM） 中的部分导出选项**导出**特定的管理数据组件。您可以按类别、类和特定属性/值条件选择管理数据的特定实例。</span>
<span style='color:#212529'>但是，每种管理数据类型仅支持部分导出中的特定元素，但不支持全部。例如，访问管理器仅支持部分导出**命名 ACL**和**权限**元素，而不支持规则树。</span>
<span style='color:#1E1E1E'>使用 TEM 导出部分管理数据</span>
1.  <span style='color:#212529'>启动透射电镜。</span>
    1.  <span style='color:#212529'>在“**维护**”面板中，选择“**配置管理器**”，然后单击**“下一步**”。</span>
    2.  <span style='color:#212529'>在**“**配置维护”面板中，选择对**现有配置执行维护**，然后单击**下一步**。</span>
2.  <span style='color:#212529'>选择要导出管理数据文件的站点的配置，然后单击**下一步**。</span>
3.  <span style='color:#212529'>在**功能维护**面板中，选择**Teamcenter Foundation**下的**管理管理数据**选项，然后单击**下一步**。</span>
4.  <span style='color:#212529'>在“**管理管理数据**”面板中，选择**“部分导出**”选项，然后单击**“下一步**”。</span>
5.  <span style='color:#212529'>使用**“部分管理**数据导出”面板可以指定要导出的管理数据。</span>
6.  
    1.  <span style='color:#212529'>单击“管理数据包”框右侧的**“...”**按钮，浏览到要放置**管理数据包**的位置。</span>
    2.  <span style='color:#212529'>单击“类别名称”框中的箭头以选择要导出的管理数据**类别**。</span>
    3.  <span style='color:#212529'>单击“导出”框中的箭头以选择要**导出**的管理数据类。</span>
    4.  <span style='color:#212529'>优化使用表中的行导出的管理数据。</span>
        1.  «span style='color:#212529'»键入**属性**和**值**对。  
            根据您从**“导出**”列表中选择的内容，系统可能会提供**属性**的条目。«/span»
        2.  «span style='color:#212529'»单击表右侧的添加按钮为其他属性/值对添加行，然后选择布尔**运算符**以定义属性的**添加**方式。  
            要删除属性/值对，请从表中选择一行，然后单击**删除**按钮。«/span»
        3.  <span style='color:#212529'>单击**下一步**。</span>
7.  <span style='color:#212529'>在**“Teamcenter 管理用户**”面板中，输入 Teamcenter 管理用户帐户的登录信息。</span>
8.  <span style='color:#212529'>在“**确认**”面板中，查看选项并选择**“启动**”。</span>
成功导出后，TEM 会将导出的管理数据打包到指定的打包目录中。导出包包含 TC XML 文件中的管理数据，稍后将用于[导入到另一个 Teamcenter 环境](https://docs.sw.siemens.com/en-US/product/282219420/doc/PL20190919161134969.rapid_start_admin_help_html_sc.managing_admin_data/html/xid1160243)。
<span style='color:#212529'>提示：</span>
导出完成后，您可能希望使用[**generate_admin_data_report**](https://docs.sw.siemens.com/en-US/product/282219420/doc/PL20190919161134969.rapid_start_admin_help_html_sc.utilities_reference/html/generate_admin_data_report_v1)实用程序生成包中包含的站点管理数据的报告。

- <span style='font-weight:bold;text-decoration: underline;background:white'>Solution</span>
- <span style='color:#333333;background:white'>Use the below steps to </span><span style='font-weight:bold;color:blue;background:white'>change</span><span style='color:#333333;background:white'> the </span><span style='font-weight: bold;color:blue;background:white'>RAC cache</span> folder locations:  

  The <span style='font-weight:bold;color:blue;background:white'>RAC</span><span style='color:#333333;background:white'> folder location is driven by the %TC_ROOT%\portal\configuration\config.ini file. The genregxml utility would utilize this as well. In that file you will see the </span><span style='font-weight:bold;color:blue;background:white'>PATH</span> to the location noted in this java based syntax.  

  For example: osgi.user.area=@user.home/Teamcenter/<span style='font-weight:bold;color:blue;background:white'>RAC</span>/20140103225652  
  In this case, user.home = %userprofile% Modify as desired, save, run genregxml utility, and the <span style='font-weight:bold;color:blue;background:white'>change</span> will be effective.  

  You need to update the following properties in fcc.xml file to <span style='font-weight:bold;color:blue;background:white'>change</span> the location of fcc folder and logs.  

  \<property name="FCC_LogFile" value="C:\apps\fcc.log\|/tmp/\$USER/fcc.log" overridable="true"/\>  

  \<property name="FCC_CacheLocation" value="C:\apps\FCCCache\|/tmp/FCCCache" overridable="true"/\>  

  This should update the FCC log file and FCC <span style='font-weight:bold;color:blue;background:white'>cache</span><span style='color:#333333;background:white'> location on client system.</span>

<span style='color:#333333;background:white'>To </span><span style='font-weight:bold; color:blue;background:white'>change</span><span style='color:#333333; background:white'> the file path of </span><span style='font-weight:bold; color:blue;background:white'>Teamcenter.lck</span>
«span style='color:#333333'»Edit the starttccs.bat file.  
- manually add -Duser.home=\<dir\> argument«/span»
<span style='color:#333333;background:white'>The location of the </span><span style='font-weight:bold;color:blue;background:white'>Teamcenter.lck</span> file is defined by the java setting  
-Duser.home=\<dir\> in the starttccs.bat file. The setting gives the  
starttccs.bat the home location. It will also affect other tccs settings where  
\$HOME is used like FCC_LogFile and FCC_CacheLocation.
«span style='color:#333333'»EXAMPLE:  
set TCCS_CMD="%TCCS_JAVA%\bin\java" -Duser.home="C:\Temp\TCCS_Temp"«/span»
«span style='color:#333333'»Restart the FCC/tccs process and you should now see the below folder created  
under C:\Temp\TCCS_Temp direcory«/span»
<span style='color:#333333;background:white'>1. \<Username\>\_lock\_\<HostName\>\\/span»«span style='font-weight:bold;color:blue;background:white'»Teamcenter.lck</span>  
2. FCCCache  
3. FCC_Log  
4. FCC_Log.lck

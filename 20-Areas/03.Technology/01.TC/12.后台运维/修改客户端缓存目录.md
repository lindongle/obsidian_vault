- How to change the RAC cache folder location.
- Symptom
- How to change the RAC cache folder location.
- Hardware/Software Configuration
- «span style='color:#333333'»Platform: INTL64  
  OS: WINDOW  
  OS Version: 764SP1  
  Product: TEAMCENTER  
  Application: INSTALL_CONFIG  
  Version: V11.4.0  
  Function: LOG_FILES«/span»
- Solution
- Use the below steps to change the RAC cache folder locations:  

  The RAC folder location is driven by the %TC_ROOT%\portal\configuration\config.ini file. The genregxml utility would utilize this as well. In that file you will see the PATH to the location noted in this java based syntax.  

  For example: osgi.user.area=@user.home/Teamcenter/RAC/20140103225652  
  In this case, user.home = %userprofile% Modify as desired, save, run genregxml utility, and the change will be effective.  

  You need to update the following properties in fcc.xml file to change the location of fcc folder and logs.  

  \<property name="FCC_LogFile" value="C:\apps\fcc.log\|/tmp/\$USER/fcc.log" overridable="true"/\>  

  \<property name="FCC_CacheLocation" value="C:\apps\FCCCache\|/tmp/FCCCache" overridable="true"/\>  

  This should update the FCC log file and FCC cache location on client system.

To change the file path of Teamcenter.lck
«span style='color:#333333'»Edit the starttccs.bat file.  
- manually add -Duser.home=\<dir\> argument«/span»
The location of the Teamcenter.lck file is defined by the java setting  
-Duser.home=\<dir\> in the starttccs.bat file. The setting gives the  
starttccs.bat the home location. It will also affect other tccs settings where  
\$HOME is used like FCC_LogFile and FCC_CacheLocation.
«span style='color:#333333'»EXAMPLE:  
set TCCS_CMD="%TCCS_JAVA%\bin\java" -Duser.home="C:\Temp\TCCS_Temp"«/span»
«span style='color:#333333'»Restart the FCC/tccs process and you should now see the below folder created  
under C:\Temp\TCCS_Temp direcory«/span»
1. \<Username\>\_lock\_\<HostName\>\\/span»«span style='font-weight:bold;color:blue;background:white'»Teamcenter.lck  
2. FCCCache  
3. FCC_Log  
4. FCC_Log.lck

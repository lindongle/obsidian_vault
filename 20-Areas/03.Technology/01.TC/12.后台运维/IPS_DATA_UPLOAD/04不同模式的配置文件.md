<td>SET COLON PROPS WITH POM</td>
<td><p><strong>[9.2.0]</strong> Provides a CSV list of general property fields (or ‘colon’ (:) fields) which are to have their values set with POM functions to override access and BMIDE rules on attributes. This can be used instead of, or as well as, using the <strong>.POM</strong> field modifier.</p>
<p>A value of <strong>ALL</strong> can also be supplied to set all general property fields using POM.</p>
<p>The fields defined in the list can include their object type prefix (I: for items, R: for rev etc) or not. If they do then only the attribute for that object will be set using POM and fields setting the same attribute for other objects will not. If just the attribute name is supplied then all object type fields setting that attribute will use POM.</p>
<p>For example:-</p>
<p><span style='color:#0000CC'>#SET COLON PROPS WITH POM = ALL</span></p>
<p><span style='color:#0000CC'>SET COLON PROPS WITH POM = R:ContactName,dt7subject</span></p>
<p><span style='color:#0000CC'>!~ItemID~RevID~R:ContactName~R:dt7subject~I:dt7subject</span></p>
<p>Will use POM for <span style='color:#0000CC'>R:ContactName</span>, <span style='color:#0000CC'>R:dt7subject</span> and <span style='color:#0000CC'>I:dt7subject</span>.</p></td>
</tr>

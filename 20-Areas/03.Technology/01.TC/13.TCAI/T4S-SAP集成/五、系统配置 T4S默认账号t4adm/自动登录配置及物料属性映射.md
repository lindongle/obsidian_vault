**自动登录配置：（配置后，界面上的连接列表会自动加载，不需要再配置首选项**
![image2](687636ef2ecb4278947743715270cf97.png)
**）**
<span style='color:#E84C22'>在TC登录后会自动启动SAPUI和SAPLOGON进程来连接接口。</span>
函数:: T4S :: CONNECTION2SAP :: setConnectionInfoPlain2设置SAP的连接，可以设置多行多连接。
函数:: T4X :: CONNECTION2EA :: selectActiveConnection2EA，定义如果不指明使用哪个连接时（如流程handler自动登录）设置默认的连接。

set State \[::T4S::CONNECTION2SAP::setConnectionInfoPlain2 test 211 10322320 1234567890 ZH PORTAL\]
set State \[::T4S::CONNECTION2SAP::setConnectionInfoPlain2 test 211 10322320 1234567890 ZH SCRIPTING\]
set State \[::T4S::CONNECTION2SAP::setConnectionInfoPlain2 test 211 10322320 1234567890 ZH WORKFLOW\]
set State \[::T4S::CONNECTION2SAP::setConnectionInfoPlain2 dev 113 10322320 1234567890 ZH\]
\#set State \[::T4S::CONNECTION2SAP::setConnectionInfoPlain2 \<destination\> \<client\> \<user\> \<password\> \<language\>\]
\#set State \[::T4X::CONNECTION2EA::selectActiveConnection2EA T4S "\*" \<destination\> \<client\>\]
set State \[::T4X::CONNECTION2EA::selectActiveConnection2EA T4S "\*" test 211\]
A.其中最后面的参数的PORTAL WORKFLOW、SCRIPTING 、QUERY、BATCH分别只客户端界面连接配置、工作流程自动登录配置、在GS脚本（SAP Connet）自动登录脚本、查询时、批量处理时（工作管理器）自动登录。
B.如果使用PORTAL可以定义，不同对象（ObjectType）的不同操作（Create、Update。。）使用哪个账号登录。如下图格式
![image3](f5dc7b68b0664fdfbcaec08bef71f30d.png)
如果使用QUERY，可以设置不同的查询构建器对象使用不同的账号登录。例如：
ET1 800 user passwd language QUERY T4S_DEMO_QUERY
C.可以不设置此参数，则表示除SCRIPTING （脚本）模式，其他均使用此连接配置。修改配置需要重新启动GS服务，如果想要SCRIPTING模式生效，则还需重启BGS服务。

样例：
\# Define SAP connection
\#set State \[::T4S::CONNECTION2SAP::**setConnectionInfoPlain2** test 211 10322320 1234567890 ZH\]
\#set State \[::T4S::CONNECTION2SAP::setConnectionInfoPlain2 test 211 10322320 1234567890 ZH SCRIPTING\]
set State \[::T4S::CONNECTION2SAP:**:setConnectionInfo2** test 211 517d6cc429ee972a 517f6cc22eeb9222f02b ZH\]
set State \[::T4S::CONNECTION2SAP::setConnectionInfo2 test 211 517d6cc429ee972a 517f6cc22eeb9222f02b ZH SCRIPTING\]
\#set State \[::T4S::CONNECTION2SAP::setConnectionInfoPlain2 dev 113 10322320 1234567890 ZH\]
\#set State \[::T4S::CONNECTION2SAP::setConnectionInfoPlain2 \<destination\> \<client\> \<user\> \<password\> \<language\>\]
\#set State \[::T4X::CONNECTION2EA::selectActiveConnection2EA T4S "\*" \<destination\> \<client\>\]
set State \[::T4X::CONNECTION2EA::selectActiveConnection2EA T4S "\*" test 211\]

**4）t4s_mm_mapping.sd**
[t4s_mapping_config.sd](a748164ba4a0421ea1f265edf505245f.sd)
物料传输的映射配置文件：
\# Define some relation name strings设置零组件类型定义
set Item "\$ItemRevisionType:items_tag:\$ItemType"
set ItemRev \$ItemRevisionType
set ItemRevMaster "\$ItemRevisionType:IMAN_master_form_rev:\$ItemRevisionType Master"
\# Read some attributes from Teamcenter object，设置SAP的中间映射名称与TC中属性的对应
\#
set SAPDesc \[::T4X::TC::MAPPING::FieldMapping \$ItemRev object_name\]; \# object_name is used for description
set SAPId \[<span style='color:red'>::T4X::TC::MAPPING::FieldMapping </span><span style='color:#2E75B5'>\$ItemRev </span><span style='color:#375623'>item_id</span>\]; \# contains SAP Id if data exist in SAP
set SAPMATKL \[::T4X::TC::MAPPING::FieldMapping \$ItemRev dz8_MATKL\]; \# contains SAP MATKL if data exist in SAP
set SAPSPART \[::T4X::TC::MAPPING::FieldMapping \$ItemRev dz8_SPART\]; \# contains SAP SPART if data exist in SAP
\#set SAPId \[::T4X::TC::MAPPING::FieldMapping \$ItemRevMaster user_data_1\]; \# contains SAP Id if data exist in SAP
set SAPOldMatNo \[::T4X::TC::MAPPING::FieldMapping \$ItemRevMaster user_data_2\]; \# transfer this value as OLD_MAT_NO
set T4STransferStatus \[::T4X::TC::MAPPING::FieldMapping \$ItemRevMaster item_comment\]; \# it is empty if item was never transferred before
\# Store data to the data exchange array ::SAPDat，SAP字段取值（包括取TC属性值、取t4s_mapping_config.sd定义的默认值、取固定值）
\#
set ::SAPDat(Material:HeadData:MATERIAL) \[string trim \$SAPId\] \#SAP的物料编号，获取上述SAPID，即TC的零组件ID的去掉前后空格的值
set ::SAPDat(Material:HeadData:IND_SECTOR) \$::T4S_Defaults(Industry) ;# Default value，取t4s_mapping_config.sd定义的Industry的默认值，即M
![image6](3d44fac89684463b8203b55e7f612dd4.png)
set ::SAPDat(Material:HeadData:MATL_TYPE) \$::T4S_Defaults(SAPMaterialType) ;# Default value
set ::SAPDat(Material:HeadData:BASIC_VIEW) "X" ;# Basic Data View \#取固定值X
set ::SAPDat(Material:MaktData:LANGU_ISO:1) "EN" \#语言，英文
set ::SAPDat(Material:MaktData:MATL_DESC:1) "\$SAPDesc" \#英文描述
set ::SAPDat(Material:MaktData:LANGU_ISO:2) "ZH" \#新增中文，可以将默认的DE德文直接改成ZH中文
set ::SAPDat(Material:MaktData:MATL_DESC:2) "\$SAPDesc" \#中文描述
set ::SAPDat(Material:MaraData:BASE_UOM) \$::T4S_Defaults(BaseUnit) ;# Default value
set ::SAPDat(Material:MaraData:CAD_ID) "X" ;# CAD indicator
set ::SAPDat(Material:MaraData:OLD_MAT_NO) \$SAPOldMatNo
set ::SAPDat(Material:MaraData:DIVISION) \$SAPSPART
set ::SAPDat(Material:MaraData:MATL_GROUP) \$SAPMATKL
其中HeadData、MaktData、MaraData对应SAP的不同类型的存储表，要根据SAP具体表查询

**2、生成Mapping脚本**
修改完上述文件后，该文件生效的方式：
进入GS管理控制台脚本：
<https://10.0.63.26:11321/#scripts>
找到以下脚本，选择生成manpping（File Name和Mode按下图选择，默认的会生成到E:\PLM\Siemens\T4S\tmp下，导致不起作用）

![image10](2c17c0fb471542eca2066c5529c5552c.png)
系统会自动更新E:\PLM\Siemens\T4S\lib\t4s_mapping_config.rfdt文件，TC接口使用此文件进行映射和自动登录。
注意：
1）修改Mapping文件,必须重启GS服务。且TC客户端需要重新登录。
2）E:\PLM\Siemens\T4S\var\mmap\t4s_mapping_config这个文件夹如果备份的文件，请修改后缀，不要用.sd，否则生成脚本时，也会读取，导致错误。
![image11](bdd8f9e1861a43f69808fc8ca83ecfa1.png)

配置完成后，可以通过OOTB流程模板：T4S_MM下发，对应handler：T4S-transfer-MaterialMaster

如果一直不生效，考虑缓存，重启GS和BGS服务后，删除C:\Users\PLMAdmin\AppData\Local\Temp\t4x\和C:\Windows\Temp\t4x\中的文件。

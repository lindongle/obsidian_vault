集成方案
2019年5月10日
9:52
![image1](b9d893b0dde04a9292625dcb6b34b532.png)

<span style='color:black'>以下是场景概述： </span>
1.  <span style='color:black'>销售人员在SAP输入订单信息，利用T4S传递到Teamcenter </span>
2.  <span style='color:black'>设计人员可以在Teamcenter查看订单信息，进行产品研发，创建/ 修改产品的设计数据，利用T4S传递到SAP </span>
3.  <span style='color:black'>制造、物流、财务等人员在SAP针对传递过来的设计数据进行操作，新生成的部分SAP数据可以利用T4S传递到Teamcenter </span>
4.  <span style='color:black'>设计人员可以在Teamcenter中查看T4S传递过来的设计数据在</span>
<span style='color:black'>SAP的信息，也可以利用T4S查看在SAP的实时属性 </span>
5.  <span style='color:black'>工艺人员根据设计数据，在Teamcenter中编制工艺，创建/修改产品的工艺数据，利用T4S传递到SAP </span>
6.  <span style='color:black'>制造、物流、财务等人员在SAP对传递过来的工艺数据进行操作 </span>
7.  <span style='color:black'>设计和工艺人员可以在T4S查看工艺数据在SAP的实时属性 </span>
<span style='color:black'>同理，采购人员可以根据Teamcenter通过T4S传递到SAP的采购视图，创建采购订单；SAP的采购信息也可以在T4S中实时查看 </span>

![image2](d3fcec1c3eb84fcd8e4de2650c877503.png)
8.  <span style='color:black'>**集成内容** </span>
    1.  <span style='color:black'>**T4S主要的设计使用用例** </span>
- <span style='color:black'>零件和装配处理：在SAP 应用程序中创建和更新产品数据；在</span>
<span style='color:black'>Teamcenter 中访问最新的SAP 产品信息。 </span>
- <span style='color:black'>文档处理：创建产品数据的二维和三维中性表示，并将其传送到SAP 应用程序中。在图纸标题栏中填写SAP 物料ID、状态和其它信息。 </span>
- <span style='color:black'>变更管理：在SAP 应用程序中创建或者更新工程变更通知（ECN），用于更新SAP 应用程序中的产品信息。 </span>
- <span style='color:black'>分类：基于Teamcenter 数据，为存储在SAP应用程序中的物料和文档创建分类信息。 </span>
- <span style='color:black'>状态同步：在Teamcenter 和SAP 软件之间传播状态变更。 </span>
- <span style='color:black'>保留关联：在Teamcenter 数据中现有关系的基础上，在SAP 应用程序中创建对象链接 </span>
<span style='color:black'> </span>
<span style='color:black'>支持的Item类型： </span>
- <span style='color:black'>Item master/item revision </span>
- <span style='color:black'>Product structure </span>
- <span style='color:black'>Dataset with files </span>
- <span style='color:black'>Change master </span>
- <span style='color:black'>Classification information </span>
- <span style='color:black'>Status information </span>
<span style='color:black'> </span>
1.  <span style='color:black'>**T4S主要的工艺使用用例** </span>
- <span style='color:black'>零件和装配过程规划。在Teamcenter内创建过程规划，并将其传送到SAP ERP系统，进行制造执行和成本/质量汇总。 </span>
- <span style='color:black'>生产资源工具。使Teamcenter和SAP ERP之间的、关于工作区和其它生产设备有关的信息保持同步。 </span>
<span style='color:black'> </span>
<span style='color:black'>支持的实体类型： </span>
- <span style='color:black'>Process plan </span>
- <span style='color:black'>Operation </span>
- <span style='color:black'>Activity </span>
- <span style='color:black'>Consumed item (part/assembly) </span>
- <span style='color:black'>Resource </span>
- <span style='color:black'>Work area </span>
- <span style='color:black'>Work instruction </span>
- <span style='color:black'>Collaboration context </span>
<span style='color:black'> </span>
9.  <span style='color:black'>**主要功能特征** </span>
- <span style='color:black'>在SAP和Teamcenter之间双向传递产品和规划信息 </span>
- <span style='color:black'>面向实体和属性的映射引擎 </span>
- <span style='color:black'>支持Teamcenter Portal GUI、SAP GUIs、工作流或者批量传递 </span>
- <span style='color:black'>支持在SAP 中查看Teamcenter 对象或者将其作为Teamcenter 运行时的属性 </span>
- <span style='color:black'>在Teamcenter 和SAP之间自动调度Item 或者属性信息的更新 </span>
- <span style='color:black'>把Teamcenter 工作流扩展到SAP 之中，比如产品发放；反之亦然，比如ECR </span>
- <span style='color:black'>易于安装和配置 </span>
<span style='color:black'> </span>

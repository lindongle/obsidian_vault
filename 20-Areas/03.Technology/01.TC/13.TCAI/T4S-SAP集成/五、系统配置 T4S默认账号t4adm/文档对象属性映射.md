Document Info Record (DIR)：凭证
T4S支持两种方式：
1、选择数据集，
会把数据集上面关联的DocumentRevision作为一个凭证，此数据集中的物理文件作为凭证的原始文件。如果再选择同一个item版本下的另一个数据集，也会将改数据集作为同一个凭证的附件传到SAP。
![image1](db48691dc88548f39b3503ba3b13aa77.png)
2、选择文档版本，在SAP中作为一个凭证，不管文档版本下面多少个数据集，每个数据集下面多少个原始文档。都放在一个凭证的附件里。
![image2](99020f185d9545228c79dc6c5500180d.png)
TC和SAP中文档的对应关系：
![image3](83285fa0a914406e8a0fb3c28368015f.png)
这次只选择第二种方式，选择ItemRevision（图纸）或DocumentRevision（技术规范）。下发的凭证类型只有PDF和JT（DirectModel）
ItemRevision下的JT和PDF
DocumentRevision下的PDF，三种关系，渲染、规格、附加。

**为便于设置，只保留两种关系，与PDF的关系，为附加关系，与JT的关系为渲染关系。**
**务必记得修改完首选项和mapping文件后，重启BGS和GS服务。**

**如果传JT，则把DesignRevision当成DocumentRevision一一样处理，下面的JT跟DocumentRevision下的PDF一样处理。只是与PartRevision的关系不一样（DocumentRevision向上反查对应的是规范文件关系，DesignRevision必须向下查找表示关系下的PartRevision--因为向上的被表示为Runtime属性，不是Relation），其他配置与PDF相同。**

首选项：
T4S_DocumentInfoRecordTypeList
设置可以发送的DocumentRevision类型或数据集（即允许选择的数据集或item版本）。
如果是Document版本下发，则配置DocumentRevision，如果选择下面的PDF数据集下发，则需要配置PDF。
两种方式取一种即可，一般取选择文档版本。

注：如果关联的物料在SAP中不存在，系统不会报错，会在对象链接中直接添加此不存在的物料号。


物料与文档，一对多关系：

\#获取文档关联的物料号，可以设置多个物料号，如果物料为多个类型，可以拼接传入。

set MMSAPId \[::T4X::TC::MAPPING::getObjectsValueList \$SAPMM item_id\]
set PartSAPId \[::T4X::TC::MAPPING::getObjectsValueList \$SAPPart item_id\]
\#将获取到值取值为空格隔开的方式，并转为大写，便于SAP识别
set MMSAPIds \[string toupper \[dict get \$MMSAPId ValueList\]\]
set PartSAPIds \[string toupper \[dict get \$PartSAPId ValueList\]\]
\#将获取的多个类型的item_id，拼起来传给SAP的属性
set ::SAPDat(Document:ObjectLink:MATERIAL) "\$MMSAPIds \$PartSAPIds"

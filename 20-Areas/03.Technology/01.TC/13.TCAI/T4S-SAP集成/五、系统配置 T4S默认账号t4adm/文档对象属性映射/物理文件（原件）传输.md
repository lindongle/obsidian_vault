二、首选项设置：
<span style='color:red'>配置多个数据集，接口会自动循环遍历多个数据集下的物理文件，如工程图和明细表。</span>
<span style='color:red'>另外上发厂，做了限制，物理文件名必须要包含文档的编号，否则无法保存。</span>
新增首选项（参考OOTB的SAP2_T4S_Item Revision和word的样例），中数据集类型均要单独配置和新增。以下以DocumentRevision下的TC_ATTACHES关系下的PDF为例。共6个。
1）新建首选项：T4S_DocumentInfoRecordMappingNamedFileList4DocumentRevision，用于找到Document下的数据集中的物理文件。
![image5](48e950453c8f4888a5370d3ad0deca5a.png)
2）新增发送SAP前缓存物理文件路径的首选项，增加JT和PDF的，三个。使用脚本验证，会自动放到C:\temp\t4x文件夹中。
命名规则：
T4S_DIR_DataCarrierPath4与Item版本的关系:数据集类型名称:ref_list/数据集对应的引用名称:ImanFile
如果是选择的文档版本（而不是数据集），则T4S_DIR_DataCarrierPath4必须加上DocumentRevision与数据集的关系，如TC_Attaches
注：**路径中要使用反斜杠/。**
T4S_DIR_DataCarrierPath4IMAN_Rendering:DirectModel:ref_list/JTPART:ImanFile
T4S_DIR_DataCarrierPath4IMAN_specification:PDF:ref_list/PDF_Reference:ImanFile
T4S_DIR_DataCarrierPath4TC_Attaches:PDF:ref_list/PDF_Reference:ImanFile
![image6](35bf483e92064da59b5031fe766ef0a4.png)

![image7](501de85919f7473caba26e4891f9c8f0.png)
3）新增T4S_DIR_DataCarrierName4TC_Attaches:PDF:ref_list/PDF_Reference:ImanFile，文件名称，默认空着就行。
![image8](ce02ae69675144c08dbc4260644ff6af.png)
4）新增T4S_DIR_FileExtension4TC_Attaches:PDF:ref_list/PDF_Reference:ImanFile，文件的后缀，值不区分大小写。
![image9](242b1162bcbf44819ed87724cf62fe31.png)
5）新增T4S_DIR_KproName4TC_Attaches:PDF:ref_list/PDF_Reference:ImanFile，物理文件在SAP中存储的卷。
![image10](9ee65fd92c03490b8699725ca48d0336.png)
6）新增T4S_DIR_WorkstationApplication4TC_Attaches:PDF:ref_list/PDF_Reference:ImanFile，SAP中打开此物理文件的应用程序。
![image11](1d9f0625559f49ec9502742d650e901d.png)
三、Mapping文件修改
E:\PLM\Siemens\T4S\var\mmap\t4s_mapping_config\t4s_dir_mapping.sd
增加以下内容，修改完后，务必重启BGS和GS服务。
![image12](248406758fdf45f2b2da9257d7d237fa.png)

\#删除旧的原始文件
set ::SAPDat(Document:Parameter:DeleteOldFileSystemFiles) "TRUE"
\#传完后删除临时文件夹中的物理文件
set ::SAPDat(Document:Parameter:DeleteTempOriginals) "TRUE"
\#获取原始文件名
set ::SAPDat(Document:Parameter:GenerateOriginalFileName) "USE_TC_ORIGINAL_NAME"
::T4S::DIR::MAPPING::checkSAPDocumentKey \$ObjectTypeName
::T4S::DIR::MAPPING::getDocumentInfoRecordOriginals \$ObjectTypeName
\#获取原始文件的个数
set OriginalNumbers \[::T4S::DIR::MAPPING::getDocumentInfoRecordOriginals "\$ObjectTypeName"\]

\#启用物理文件流机制传输，非FTP方式--新增部分。（不适用）
set ::TPSAP::DIR::CtrlDat(UseRfcDirectFileCheckin) "TRUE"
\# Disable retry to check-in originals if DIR is locked (default FALSE, disabling not recommended):
set ::TPSAP::DIR::CtrlDat(DirectFileCheckinLockedCheckSkipped) "TRUE"
\# Number of retry loops (default 60)
set ::TPSAP::DIRCtrlDat(DirectFileCheckinLockedCheckLoopCounter) "60"

\# Note that this is filled by T4S itself, not explicitly in the mapping
if {\$OriginalNumbers == 0} {
\# Maybe it is ok, but this warning might be useful for error tracking
tpwrite -logchannel \[::T4X::CORE::getSessionLogChannel\] -mtype WARNING "::T4S::DIR::CUSTOM::MAPPING::TC_Object2SAP_DocumentInfoRecord: The number of files is zero! -----------------------------"
::T4X::TRANSLOG::writeCustomMappingLog \$TransactionId INFO "+++++ The number of files is zero! +++++"
}

foreach FileId \[array names ::SAPDat Document:FileNames:DatacarrierPath:\*\] {
set FileIndex \[lindex \[split \$FileId ":"\] end\]
::T4X::TRANSLOG::writeCustomMappingLog \$TransactionId INFO "+++++ TC Dataset file \$::SAPDat(Document:FileNames:ImanFilename:\$FileIndex) +++++"
\#set ::SAPDat(Document:FileNames:UserDefinedFilename:\$FileIndex) "My_file_name"
}

--解决，在bom的mapping脚本中注释掉：set ::SAPDat(Bom:BomHeader:BomAlternativeText) \$REV_ID;即不传输BOM的可选文本即可。此问题通过将以下参数(启用旧功能)打开后，日志提示：字段RC29K-STKTX.不是一个输入字段，将可选文本不再传输，重新将以下设置关掉
set ::SAPDat(Bom:Parameter:useOldBomChangeFunction) TRUE
set ::SAPDat(Bom:Parameter:useOldBomCreateFunction) TRUE
set ::SAPDat(Bom:Parameter:useOldBomFunctions) TRUE

控制 "CAD 标识"的三个不同参数：
• 您可以在函数 TC_Object2SAP_BillOfMaterial 中为新创建的 BOM 头和 BOM 行定义整体默认设置：

• 如果设置此参数到""，所有新BOM头和所有BOM行都将不会进行勾选"CAD 标识"。
set ::SAPDat(Bom:Parameter:FL_CAD) ""
进行BOM修改时，将修改勾选或不勾选 "CAD 标识"的 BOM 头和不勾选 "CAD 标识"的 BOM 行。
--即对BOM头和BOM行都不会勾选CAD标识，会修改所有不管勾不勾选CAD标识的BOM头，但只会修改不勾选CAD标识的BOM行；
• 如果将此参数设置为 X，所有新BOM头和所有BOM行都将勾选"CAD 标识"。
set ::SAPDat(Bom:Parameter:FL_CAD) X
进行BOM修改时，将修改勾选 "CAD 标识"的 BOM 头和勾选"CAD 标识"的 BOM 行。
--即对BOM头和BOM行都会勾选CAD标识，会修改只勾选了CAD标识的BOM头和只勾选了CAD标识的BOM行；
• 如果将此参数设置为 D，则新BOM头和所有BOM行的"CAD 标识"的控制权将移交给BOM头和BOM行的专用参数。这是默认值。
即set ::SAPDat(Bom:BomHeader:CADKZ) X和set ::SAPDat(Bom:Position:CADPO:\$BomLineIndex) X这两个参数（如果为X，则勾选"CAD 标识"，如果为""，则不勾选"CAD 标识"）
set ::SAPDat(Bom:Parameter:FL_CAD) D
进行BOM修改时，将修改勾选或不勾选 "CAD 标识"的 BOM 头和勾选或不勾选 "CAD 标识"的 BOM 行。
--即勾不勾选CAD标识有参数单独控制，且不管勾不选CAD标识的BOM头和BOM行均会修改；
--如果set ::SAPDat(Bom:Parameter:FL_CAD)设置为X或""时，set ::SAPDat(Bom:BomHeader:CADKZ) X和set ::SAPDat(Bom:Position:CADPO:\$BomLineIndex) X这两个参数将不再起作用；
==出于历史数据考虑，建议set ::SAPDat(Bom:Parameter:FL_CAD) ""，因为历史数据均为勾选CAD标识，进行更改时会作为差异项进行变更；但对于在SAP中原有的BOM，进行新的变更下发时，仍然会全量停用；==
==set ::SAPDat(Bom:Parameter:FL_CAD) ""的效果与set ::SAPDat(Bom:Parameter:FL_CAD) D并且==set ::SAPDat(Bom:BomHeader:CADKZ) “”+set ::SAPDat(Bom:Position:CADPO:\$BomLineIndex) “”的效果是一样的
==set ::SAPDat(Bom:Parameter:FL_CAD) D并且==set ::SAPDat(Bom:BomHeader:CADKZ) X +set ::SAPDat(Bom:Position:CADPO:\$BomLineIndex) x，可以加CAD标识，对新的BOM后面变更只更新差异部分，但历史数据也是全量停用。
上述问题是因为set ::SAPDat(Bom:Position:SANKO:\$BomLineIndex) "X"，给BOM行属性“工程/设计”打了勾造成的，需要改成跟历史数据一致的不打勾状态，set ::SAPDat(Bom:Position:SANKO:\$BomLineIndex) ""

**产生以上设置的原因：**
- 如果您在 SAP GUI 中手动修改 BOM，然后使用 T4S 再次修改它，您可能会发现重复的行或其他意外影响。这是 SAP“CAD 指示器”的结果——SAP 使用一个标志来区分对象（可能只是 BOM 行）是从 SAP GUI 中创建的，还是使用 T4S 等外部工具创建的。
- 在 SAP GUI 中手动创建的任何 BOM 行都没有设置此标志；
- 由 T4S 或类似工具创建的 BOM 行。该行为的原因是允许在 SAP 中手动添加未反映在 Teamcenter 中的 BOM 位置。在更新期间，它们不会被 T4S 更改，尤其是不会被删除，尽管它们不存在于 Teamcenter BOM 中。
- 一个典型的例子是技术产品的手册。这通常不是 Teamcenter BOM 的一部分，但在 SAP BOM 中需要用于正确打包，因此它是在 SAP 中手动添加的。因此，如果产品本身在 Teamcenter BOM 中进行了修改，并且此 BOM 通过 T4S 传输到 SAP，则不会从 SAP BOM 中删除手册的 BOM 位置，因为 SAP 会检查该位置没有设置“CAD 指示器”并且防止其修改。要检查此标志，请双击 SAP BOM 中的项目编号，然后 SAP 将打开视图“BOM：项目：所有数据”，在此处激活选项卡“基本数据”并在“常规”部分中找到“CAD 指标”数据”。

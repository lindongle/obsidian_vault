流程模板名称本地化（冷部署）
2021年4月14日
9:50
Solution For this specific case perform below steps
1\. In BMIDE open EPMTaskTemplate
2\. Select the Property "template_name"
3\. Select the Property Constant "Localizable" and click the "Edit" Button. Set it to "true" and click Finish 4. Save your Datamodel and deploy it
5\. Startup Workflow Designer
6\. Create a new Root Template, give it some name and perhaps add an "Add Status" Task.
7\. Select the Root Template in the left tree structure
8\. Right click -\> View Properties and scroll to the "Template Name"
9\. Click the "Localization" button
10\. Fill in a value for another Language

通过条件过滤过滤流程模板
2018年12月14日
0:12
![image1](0ad9da653121468587c9724461a4c940.png)

从11.2后工作流程过滤器功能已被废弃，讲从12开始移除功能。
1）首选项WRKFLW_use_legacy_template_filter，确保为False(默认就是false)
CR_allow_alternate_procedures首选项改为None
设置后，新建流程界面不再显示指派的和全部的单选框。
2）修改BMIDE配置：
找到动态LOV对象：Fnd0FilterCondition
此LOV的值默认查询名称中包含WF的条件，可以增加查询条件。
![image2](f33404f79cc04079a07af094e2fca190.png)
3）根据需要配置条件，自定义的名称中要包含WF。必须只包含Workspaceobject或自定义的Item类型，imantype,usersession，且Workspaceobject必须在第一个，可以换成自定义的Item类型。否则会提示“该语法不适用于模板过滤器的条件 "Y2_Cond_WF01"。”
<span style='color:#333333;background:white'> The </span><span style='font-weight: bold;color:blue;background:white'>condition</span><span style='color:#333333; background:white'> needs to have the following in it's Signature</span>

<span style='background:white'>  WorkspaceObject</span>
<span style='background:white'>  ImanType</span>
<span style='background:white'>  UserSession</span>

<span style='background:white'> ) For example,</span>

<span style='background:white'>  Signature : GT5WFsp ( WorkspaceObject o , ImanType t , UserSession u )</span>

<span style='background:white'> ) Note the order of the parameters. </span>
<span style='background:white'> If WorkspaceObject is \*not\* first, you may see the same error.</span>

[[条件创建]]
4）部署BMIDE。
5）选择流程模板-改为编辑模式。
6）选择视图-任务属性，打开属性编辑界面。
![image5](d7d3163633df474197e74ddadd52af34.png)

![image6](42344de5dc8043f58f2fa368e3c6f2d1.png)
7）在过滤条件中选择对应的条件。系统将会根据是否满足条件进行过滤。

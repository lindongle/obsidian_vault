- ANALYSIS  
  -----------------  
  Steps for Async configuration in a SSO environment.  

  SOLUTION/WORKAROUND  
  -------------------  
  1. Start RAC go to Organization section under that click on Sites  
  a. Add the SOA URL (e.g [<span style='font-size:8.25pt;background: white'>http://hostname:portnumber/tc</span>](http://hostname:portnumber/tc))  
  b. Site Node/ URL : hostname  
  2.Please follow the Dispatcher ACL settings  
  Has Class (POM_application_object)-to add rule Under Working  
  Condition = Has Class  
  Value = DispatcherRequest  

  ACL Name = DispatcherRequest  

  ACE Type of Accessor = User  
  ACE ID of Accessor = DC-Proxy-User-ID  

  ACE Privilege = Write  
  ACE Privilege Value = Grant  

  ACE Privilege = Delete  
  ACE Privilege Value = Grant  

  3. Update the following Preferences  
  a.ASYNC_connection_retries=1  
  b.ASYNC_connection_retry_interval=10  
  c.ASYNC_subscribe_to_background_task=BOTH  
  d.TC_subscription=ON  
  e.Mail_server_name= your mail server value  
  f.TC_notification_msg_ext= tmp change it to txt  
  g.EPM_task_execution_mode value is “CONFIGURABLE”  

  4.Modify the \<dispatcher_root\>/Dispatcher/Module/conf/translator.xml file with  
  following information from  
  \<AsyncService provider="SIEMENS" service="asyncservice" isactive="false"\>  
  TO  
  \<AsyncService provider="SIEMENS" service="asyncservice" isactive="true"\>  
  5. By default, the Dispatcher client polls for new requests in the database  
  every 60 seconds. This value can be configured in  
  \<dispatcher_root\>/Dispatcher/DispatcherClient/conf/Service.properties. The  
  following line sets it to poll every 10 seconds.  
  Service.PollingInterval= 10  

  6. You need to request a new Async SSO App. The ID will be your usual SSO App  
  ID with “Async” suffixed to it (Ex Tc8S55Async).  

  7. To set the mediator password for Identity services run the following command  
  in a sourced shell or command window  
  install_encryptionkeys -u=infodba -p=infodba -g=dba -f=install_mediator_key

Further requirements
---------------------------
\- Teamcenter 11.6.0 or higher

\- Requirement for the IMM NX Plugin on Windows Platform
The IMM NX1855 Plugin requires Microsoft .NET Framework 4.6
The IMM NX12 Plugin requires Microsoft .NET Framework 4.6
The IMM NX11 Plugin requires Microsoft .NET Framework 4.0

\- Active Workspace 4.1 or higher minor release

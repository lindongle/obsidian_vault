created: 2026-07-05T17:04:49

1.将首选项EP_ProcessTreeAssemblyPlanningColumnConfiguration保护范围设为【站点】
2.中添加需要的行属性，例：ImanItemBOPLine.bl_sequence_no.200.false.300
false：代表显示在行中
100/200/300为排列顺序（排序后自动刷新）
Value Format:objectType.propertyName.columnWidth.hiddenFlag.columnOrder
Optional Values: columnWidth,hiddenFlag,columnOrder
Valid values for hiddenFlag : true(default) - column will be hiddden from table
false - column will be visible in table

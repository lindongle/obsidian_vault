首选项EP_ShowProductBOPInProcessPlanning
With the value of this preference set to "true", if the Work Package contains a Product BOP, the Process Planning page will display the Product BOP tree instead of the BOM tree.
Note: Work Instructions Authoring page will not contain the BOM tree.

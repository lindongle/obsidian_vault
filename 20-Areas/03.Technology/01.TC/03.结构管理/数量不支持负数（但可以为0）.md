Is possible to configure a BOM line to have a negative value entered in the Quantity (Qty) field?
If not, is there any other special value other than A/R for Qty that is allowed? and/or can we configure our own A/R type value for Quantity?

Use case: When we send this data to Oracle they would like to have a negative value. The reason is they use this to designate a core return on a part.

**SOLUTION**
The current quantity validation for BOMlines is hardcoded to validate either a valid number \>= 0 or "A/R"

There is no configuration point possible here and the "A/R" matching is only for the localization of "k_asReqStr" key value, so multiple as-required strings are not supported.

Suggested workaround for use case: A custom occurrence note indicating the need to convert the quantity to a negative quantity in the Oracle system can be used during their export to Oracle. This assumes that they have a way of customizing their data before it is sent to Oracle.

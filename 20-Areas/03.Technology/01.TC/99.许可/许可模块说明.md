**TCM055019-**Advanced Assembly Planning
A SAASOPS7000 or SAASOPS7001 product must be included when an -XT product is included in an order. -XT products and SAASOPS7000/SAASOPS7001 are inseparable.-This module enables users to define the associated planning-functions: ProductBOP and PlantBOP for the purpose of process planning. -It also enables methods of assigning operations to workstations along an assembly line, in such a way that the assignment be optimal. -The functionality provided by this product is as follows:-- Create a Product BOP (to manage the list of Process/Operations to build a product) functioning as template or library-- Create a Plant BOP (to define the build sequence of multiple products/it's variants per plant.) -- Identifies processes and operations logically to enable compare and to-find equivalence.-- Create logical consumptions of parts and resolve them-- Propagate updates from Product BOP to Plant BOP
该模块使用户能够定义相关的规划功能：ProductBOP 和 PlantBOP，用于工艺规划。-它还支持将操作分配给装配线上的工作站的方法，以使分配达到最佳状态。-该产品提供的功能如下：-- 创建产品 BOP（管理构建产品的流程/操作列表）作为模板或库-- 创建工厂 BOP（定义多个产品/每个工厂的变型的构建顺序。-- 逻辑识别流程和操作，以便进行比较和查找等效性。-- 创建零件的逻辑消耗并解决它们-- 将更新从产品 BOP 传播到工厂 BOP

**TC030401-**Classification User
Classification UserClassification facilitates reuse of existing parts, products, processes, and the knowledge captured in their designs by making those objects easy to find via their classification. It provides a means to catalog standard parts, products and processes as well as avoid proliferation of duplicates.Classification User allows a named user to: create and modify classification hierarchies, define classification attributes and the allowable values, define classification views, and classify objects in the classification hierarchy which includes assigning attribute values. A Classification User license is NOT required to view or search the classification hierarchy (which includes finding classified objects and viewing associated attribute values).

NX Mach 2 builds on the entry-level capabilities of the NX Mach 1 bundle with additional features to boost design efficiency and quality.

\- Top-down and bottom-up assembly modeling and design in assembly context
\- Freeform construction of lofted, swept or curve network-based shapes
\- Support for automation programs and custom functions developed from a variety of languages
\- Numerous data exchange tools for working with and sharing Multi-CAD data with NX (IGES, DXF/DWG, STEP 203/214)
\- Rapid Prototyping
\- Tools for designing parts manufactured with Straight Brake Sheet Metal forming
\- NX Drafting for efficient creation of engineering drawing compliant with major national and international drafting standards

NX Mach 2 includes:

\- User-definable, reusable feature templates

\- Specific tools for designing flexible printed circuit boards (PCBs)
\- Baseline design of routed systems and straight break sheet metal

**TC10411-Linked Data Framework (LDF)**
Linked Data Framework enables integration of Teamcenter with other applications, while keeping data federated across applications. It allows Teamcenter to expose functionalities as REST based services and allows Teamcenter to access services exposed by other systems. LDF provides the capabilities to create meaningful relations to resources or artifacts residing in remote systems, without the need to copy the data, using data linking. It also provides the ability to view and modify data in other systems through UI delegation. Linked Data Framework is licensed based on Named User. A Teamcenter Author, Consumer or Occasional Author license is a prerequisite for LDF named user license.
Linked Data Framework 支持将 Teamcenter 与其他应用程序集成，同时保持数据在应用程序之间联合。它允许 Teamcenter 将功能公开为基于 REST 的服务，并允许 Teamcenter 访问其他系统公开的服务。LDF 提供了与驻留在远程系统中的资源或工件创建有意义的关系的功能，而无需使用数据链接复制数据。它还提供了通过 UI 委派查看和修改其他系统中的数据的功能。链接数据框架基于指定用户进行许可。Teamcenter Author、Consumer 或 Occasional Author 许可证是 LDF 指定用户许可证的先决条件。Linked Data Framework 是一个集成框架，允许您集成不同的 应用程序或企业信息系统，例如 Product Lifecycle Management 使用数据链接的 （PLM） 系统和应用程序生命周期管理 （ALM） 系统技术
Linked Data Framework 有助于解决以下业务问题：
您如何实施跨不同域的变更管理等流程 比如 PLM 和 ALM？
您可以在流程的各个部分之间创建链接，例如在更改请求之间 在 PLM 中，在 ALM 中是一个缺陷。您还可以扩展 Linked Data Framework 以增强其 能力。
如何避免创建新的 UI 来集成不同的应用程序，以及帮助 用户避免学习新的 UI？
使用基于 UI 的服务（UI 委派），您可以重用现有 UI、验证和 主机应用程序已从外部强制实施的业务规则 应用。
如何在无需学习新技术的情况下自定义集成？
使用 REST、JSON、RDF 和基于 Web 的 API 等标准。
如何使用户能够在不学习 PLM 概念或 新工具？
您可以使用熟悉的工具，并使用 UI 委派

\- NX Drafting for efficient creation of engineering drawing compliant with major national and international drafting standards

<span style='color:black'>**TC10411-Linked Data Framework (LDF)**</span>
<span style='color:black'>Linked Data Framework enables integration of Teamcenter with other applications, while keeping data federated across applications. It allows Teamcenter to expose functionalities as REST based services and allows Teamcenter to access services exposed by other systems. LDF provides the capabilities to create meaningful relations to resources or artifacts residing in remote systems, without the need to copy the data, using data linking. It also provides the ability to view and modify data in other systems through UI delegation. Linked Data Framework is licensed based on Named User. A Teamcenter Author, Consumer or Occasional Author license is a prerequisite for LDF named user license.</span>
Linked Data Framework 支持将 Teamcenter 与其他应用程序集成，同时保持数据在应用程序之间联合。它允许 Teamcenter 将功能公开为基于 REST 的服务，并允许 Teamcenter 访问其他系统公开的服务。LDF 提供了与驻<span style='background:#EFF6FF'>留在</span>远程系统中的资源或工件创建有意义的关系的功能，而无需使用数据链接<span style='background:#EFF6FF'>复制</span>数据。它还提供了通过 UI 委派查看和修改其他系统中的数据的功能。链接数据框架基于指定用户进行许可。Teamcenter Author、Consumer 或 Occasional Author 许可证是 LDF 指定用户许可证的先决条件。Linked Data Framework 是一个集成框架，允许您集成不同的 应用程序或企业信息系统，例如 Product Lifecycle Management 使用数据链接的 （PLM） 系统和应用程序生命周期管理 （ALM） 系统技术

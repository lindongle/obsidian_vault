1.  确认如下首选项设置：
| Mail_server_port | 465 |
|----|----|
| Mail_server_name | smtp.qiye.163.com |
| Mail_server_connection_security | SSL/TLS |
| Mail_server_charset | UTF-8 |
| Mail_server_authentication_passwd_location | D:\Siemens\Teamcenter2406\security\email.pwf |
| Mail_server_authentication_id | plm@lckt.com.cn |
| Mail_server_authentication_activated | TRUE |
| Mail_OS_from_address | plm@lckt.com.cn |
| <span style='color:red'>Mail_server_ssl_protocol</span> | <span style='color:red'>TLSv1_2</span> |
2.  生成密码文件：
打开tc命令窗口；后面是明文密码
set TEM_SEENVA=Lckt@369
install.exe -encryptpwf -e=TEM_SEENVA -f="D:\Siemens\Teamcenter2406\security\email.pwf"
3.  测试：
tc_mail_smtp -to=plm@lckt.com.cn -server=smtp.qiye.163.com -port="465" -charset="UTF-8" -auth="true" -authId=plm@lckt.com.cn -pf="D:\Siemens\Teamcenter2406\security\email.pwf" -connSecurity="SSL/TLS" -ssltlsProtocol="TLSv1_2" -user="plm@lckt.com.cn" -subject="邮件测试"
tc_mail_smtp -to=plm@lckt.com.cn -server=smtphz.qiye.163.com -port="994" -charset="UTF-8" -auth="true" -authId=plm@lckt.com.cn -pf="D:\Siemens\Teamcenter2406\security\email.pwf" -connSecurity="SSL/TLS" -ssltlsProtocol="TLSv1_2" -user="plm@lckt.com.cn" -subject="邮件测试"
开通smtp.qiye.163.com 的465端口后，服务器执行卡住，管理员放开网络通用策略可以（深信服中策略，加密邮件发送被禁用，启用即可）。

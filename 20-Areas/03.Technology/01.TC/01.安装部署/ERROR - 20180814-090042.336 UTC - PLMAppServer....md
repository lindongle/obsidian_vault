ERROR - 2018/08/14-09:00:42.336 UTC - PLMAppServer.94046.01.plm.00086.Mux.Svr - FMS key is not available in database - Teamcenter.Organization.sa at D:\workdir\tc1140x_win64\src\core\sa\encryption.cxx(2151)

解决：
Review the log files. The following error may occur:
Ticket failed isValid() check.

In this case, the problem was due to the fact that the QA installation was
previously part of a GMS installation and had been configured with a custom
FMS key file. We were able to confirm this by listing the current FMS key by
doing the following from a Teamcenter shell:

:# install_encryptionkeys -u=infodba -p=\<PASSWORD\> -g=dba -f=list
install_encryptionkeys -u=infodba -p=infodba -g=dba -f=list

This will list the key. We did this for all FSC's that are masters in this
configuration and found that the QA is mismatched.

In their case it was, the QA install FMS key was deleted by doing this:

:# install_encryptionkeys -u=infodba -p=\<PASSWORD\> -g=dba -f=delete
install_encryptionkeys -u=infodba -p=\<PASSWORD\> -g=dba -f=delete

From here, we need to restore the default FMS key as follows:

:# install_encryptionkeys -u=infodba -p=\<PASSWORD\> -g=dba -f=install
install_encryptionkeys -u=infodba -p=infodba -g=dba -f=install

After this was done, we repeated the -f=list command above to verify that they
are now matching. With this, we restarted the FSC for the QA installation and
retested the client behavior. Issue resolved.

介质：不在单独介质，放在tc的介质**install\DeploymentCenter文件夹**中；
1.  In the Teamcenter 2406 software directory, change to theinstall\DeploymentCenterdirectory (on Windows systems) or theinstall/DeploymentCenterdirectory (on Linux systems).

*来自 \< <https://docs.sw.siemens.com/documentation/external/PL20231129261301184/en-US/teamcenter/tc/2406/teamcenter/en-US/deployment_center/xid1162543/xid1171011.html>\>*

2.  D:\Media\tc\deployment_center\deployment_center\install_config.properties，修改配置参数；
    1.  serverDir：指定部署中心 Web 服务器和数据库目录的完整路径。 此目录路径必须启用写访问权限；
    2.  repoDir：指定主部署中心软件存储库目录的完整路径。部署中心安装脚本会在此路径中创建一个软件子目录。 此路径必须是本地路径。主存储库目录不支持 UNC 路径和映射驱动器；
    3.  user/passwords:用户名/密码，默认情况下，密码未加密。 要对部署中心使用加密密码：a. 使用 dc_encrypt 实用程序创建加密密码。 b. 将 useEncryptedPassword 参数设置为 true。 c. 在 password 参数中输入加密密码，或将加密密码保存到文件并在 dcpasswordFile 参数中指定其位置。
    4.  ![image1](fe2c3662dabf4a78bf02c92299c455dc.png)
    5.  建议修改8080端口，以避免后续端口冲突；
    6.  ![image2](6ec092c4a4b442e88692057d56fa9db9.png)
3.  打开管理员命令提示符并切换到展开部署中心软件包的目录。然后，切换到此目录中的部署中心目录。
    1.  管理员身份运行cmd；
    2.  cd /d D:\Media\tc\deployment_center\deployment_center，回车；
    3.  执行命令：deployment_center.bat -install -inputFile=install_config.properties，回车；
    4.  输入Y，回车；
    5.  ![image3](5f30170ed78344deae54a08e845104df.png)

6.  ![image4](8889b2dca9024860902894f82d8be5d9.png)
4.  输入http://PLMSERVER:9999/deploymentcenter/，打开部署中心，使用上述用户名登录；
    1.  ![image5](2adcec60d8b0463a98583ccda2d76fc1.png)
5.  卸载部署中心：
    1.  管理员运行cmd；
    2.  net stop DC_RepoService_Publisher
net stop DC_RepoService
net stop DC_Service
net stop DC_Vault_Service
3.  sc delete DC_RepoService_Publisher
sc delete DC_RepoService
sc delete DC_Service
sc delete DC_Vault_Service
4.  关闭窗口
5.  删除软件存储目录及部署中心安装目录；

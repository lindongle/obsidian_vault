测试：runTcFTSIndexer -task=objdata:index
创建：runTcFTSIndexer -task=objdata:index
恢复索引：runTcFTSIndexer -task=objdata:recover
设置同步频率，25秒一次：runTcFTSIndexer -task=objdata:sync -interval=25

配置搜索索引属性
TcFTSIndexer 搜索属性存储在 TcFtsIndexer_objdata.properties 文件中，该文件位于
TC_ROOT\TcFTSIndexer\conf。
大多数搜索属性都在安装TcFTSIndexer 客户端期间定义。但是，您可以在
TcFtsIndexer_objdata.properties 文件中定义其他几个属性，如 indexDatasetFileContent。
该属性控制数据集文件内容的索引编制。将该属性设为 true（对数据集文件内容编制索引）
或 false（不对数据集文件内容编制索引）。

要重新索引现有数据：
1\. 如果运行了 runTcFTSIndexer -task=objdata:sync -interval=seconds 命令，则应使用以
下命令临时关闭它：
runTcFTSIndexer –task=objdata:sync -stop
2\. 请执行以下任一操作：
• 要清除现有的全文搜索数据并执行新的索引，请打开Teamcenter 命令提示符，导览至
TC_ROOT\TcFTSIndexer\bin，然后键入以下命令：
runTcFTSIndexer -task=objdata:clear
runTcFTSIndexer -task=objdata:index
• 要执行新的索引而不删除已编制索引的现有数据，请键入以下命令：
runTcFTSIndexer -task=objdata:index
默认情况下，索引器使用当前的日期和时间作为终止点。要指定不同的日期和时间，请使
用TEM 中的TcFTSIndexer 设置。
注释
要对 TC_FTS_INDEXER_HOME\conf\TcFtsIndexer_objdata.properties 文件中
所定义日期的数据编制索引，必须从 TC_FTS_INDEXER_HOME\cache 中删除
TcFtsIndexerSessionobjdata.cache 文件。

选择编辑→选项并找到 AW_FullTextSearch_TypeCategories 首选项。将值字段设为所有类别的
完整值。例如，File、Documents、Parts 和 Changes 类别的默认值可设置如下：
Files:MSExcelX,MSPowerPointX,MSWordX,PDF,Text,JPEG
Documents:DocumentRevision,RequirementSpec Revision
Parts:DesignRevision,PartRevision
Changes:ChangeItemRevision
警告
使用这种方法更改类别可能导致意外结果。对象的内部名称不明确，并且值字段内容未
经拼写检查或者其他错误检查。

胖客户端关键字搜索：
build_fts_index -u=infodba -p=infodba -g=dba -f=update
build_fts_index -u=infodba -p=infodba -g=dba -type=Text, -f=update
-type
Specifies the dataset type to index. Specified dataset types must be defined
by the TC_fts_indexed_types preference.
If this argument is not specified, all dataset types defined by the
TC_fts_indexed_types preference are indexed.
This argument can be specified multiple times to index multiple dataset
types in a single utility session, for example:
-type=Text -type=HTML
Note
If the TC_fts_indexed_types preference is used, the
WSOM_find_list_separator value must be set in the tc_env file.

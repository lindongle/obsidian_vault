Error logging into the Solr Admin console 'HTTP ERROR 401 Unauthorized'

At this time, the same 'Unauthorized' error is likely being seen when attempting to run any indexing actions as well. If so, this is a strong indication there is a password problem with the solr_admin account.

There are three files that contain the password for solr and these 3 files must match. If the passwords within these files become out of sync, the 'Unauthorized' error will result.
原因：solr_admin的密码修改了

[*https://support.sw.siemens.com/zh-CN/product/282219420/knowledge-base/PL8530830?pid=sc%3Asearch&pid_context=%27401%27%2C%20Unauthorized%2C%20attempts%3A&index=content-external&audience=external*](https://support.sw.siemens.com/zh-CN/product/282219420/knowledge-base/PL8530830?pid=sc%3Asearch&pid_context=%27401%27%2C%20Unauthorized%2C%20attempts%3A&index=content-external&audience=external)

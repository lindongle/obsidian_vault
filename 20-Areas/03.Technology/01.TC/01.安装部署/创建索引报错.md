解决：
1\. Update Teamcenter Index Schema Files
bmide_modeltool.bat -u=infodba -p=infodba -g=dba -tool=all -mode=upgrade -target_dir="%TC_DATA%"

2\. Update Solr Schema
From the Solr server in an cmd tool run:
TC_ROOT\solr-5.0.1\TcSchemaToSolrSchemaTransform.bat
TC_DATA\ftsi\solr_schema_files

If the Solr server is on a separate server to your TC_DATA directory, copy the
directory TC_DATA\ftsi locally

3\. Update FTSIndexer Schema
From the Indexer server run the following in any cmd tool:
TC_ROOT\TcFTSIndexer\bin\runTcFTSIndexer.bat -task=objdata:test

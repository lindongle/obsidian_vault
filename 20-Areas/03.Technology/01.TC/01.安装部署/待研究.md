**搜索分类数据设置：**
1、添加分类视图
smlutility -create_indexing_views -u = infodba -p = infodba -g = dba -recursive
设置首选项ICS_searchindex_view_visible为true
2、设置查询索引
BMIDE中设置业务对象Workspaceobject对象常数wp0SearchClassifSearchEnabled为true
设置分类对象，如ItemRevision，业务对象常数Awp0SearchIsClassifyDataIndexed为true，不要将Workspaceobject对象常数Awp0SearchIsClassifyDataIndexed也设置为true。
bmide_modeltool.bat -u=infodba -p=infodba -g=dba -tool=all -mode=upgrade -target_dir=％TC_DATA％

3、获取索引状态
gettypeconstantvalue -u=infodba-p=infodba-g=dba -typename=WorkspaceObject -constantname=Awp0SearchClassifySearchEnabled

4、和并Teamcenter和Solr方案
停止solr 和索引编制器服务
和并索引：D:\Siemens\Teamcenter11\solr-6.2.1\>TcSchemaToSolrSchemaTransform.bat "%TC_DATA%\\
ftsi\solr_schema_files
启动solr 和索引编制器服务
5、重新编制索引
停止runTcFTSIndexer服务
Cd /d D:\Siemens\Teamcenter11\TcFTSIndexer\bin
清除索引命令：runTcftsIndexer -task=objdata:clear 4 ---输入4，然后输入Y，3次
创建索引命令：runTcftsIndexer -task=objdata:index

GTAC:

- Solution
- Indexing Configuration for Classification properties:  

  1) Add 'Search Index' views to the Classification Classes, whose  
  Attributes are to be indexed  
  -To enable this in RAC, set preference ICS_searchindex_view_enable =  
  TRUE  
  2) Mark 'Filter' property of Search Index View attributes  
  - Alternatively, use 'smlutility -create_indexing_view' command  
  3) Turn ON Classification feature by setting following Type Constant in  
  BMIDE:  
  - On WorkspaceObject, set Awp0SearchClassifySearchEnabled = TRUE  
  4) Follow Post Configuration steps to generate the necessary SOLR schema  
  artifacts  

  5) Verification  
  - Verify that Classification Attributes are represented in the extracted  
  TC schema %TC_DATA%\ftsi\solr_schema_files\\  

  - Verify that Classification Attributes (containing string  
  "0Y0_CLASSIFICATION_0Y0") are transformed into the SOLR schema  
  %SOLR_HOME%\\...\schema.xml  

  Filter panel Configuration for Classification properties:  

  1) Classification Filtering must be turned ON by setting following Type  
  Constant in BMIDE:  
  -On WorkspaceObject, set Awp0SearchClassifySearchEnabled = TRUE  
  -Follow Post Configuration steps to generate the necessary SOLR schema  
  artifacts  

  Indexing Configuration for Classified WSOs:  

  1) Objects that are classified (e.g. Item Revisions) must also be marked  
  as Indexable  
  - (Note: it does not help to mark the Items as Indexable, if Revisions  
  are classified)  
  2) Set Type Constant Awp0SearchIsIndexed = TRUE  
  - For these Object Types, Classification data must also be  
  configured to be indexed.  
  3) Set Type Constant Awp0SearchIsClassifyDataIndexed = TRUE  
  - Follow Post Configuration steps to generate the necessary SOLR  
  schema artifacts  
  4) If Classified WSOs were already indexed, then they must be  
  're-indexed' after above configuration steps  

  Post Configuration steps:  

  1) Generate TC schema  
  \>\> bmide_modeltool.bat -u= -p= -g=dba -tool=all -mode=upgrade  
  -target_dir=%TC_DATA%  

  2) Transform TC schema to SOLR schema  
  \>\> solr-5.1.0\TcSchemaToSolrSchema.bat%TC_DATA%\ftsi\solr_schema_files

**Creo集成安装指南**
**集成程序版本11.3.0**
**客户端系统要求：**
1、支持 Window 7, Windows 8 and Windows 10
2、64位操作系统，必须安装 Microsoft Visual C++ Redistributable Package (x64)组件，下载地址： <https://www.microsoft.com/en-us/download/search.aspx?q=redistributable%20package&p=0&r=10&t=&s=Relevancy~Descending>
<span style='color:#393939'>**服务端系统要求：**</span>
· Windows
· HP Itanium
· Sun Solaris
· IBM AIX
· Linux
<span style='color:#393939'>客户端及服务端支持的具体版本，参考西门子认证矩阵表，网站如下。</span>
<http://www.plm.automation.siemens.com/zh_cn/support/gtac/certifications.shtml>
<span style='color:#393939'>**Teamcenter版本要求：**</span>
Teamcenter 10.1.5.1或更高补丁版本
Teamcenter 11.2.1或更高补丁版本
必须对Teamcenter胖客户端的安装目录的具有写入权限才能安装文件，并配置从胖客户端启动Creo。
**PTC软件版本要求：**
Creo2.0 M110或更高版本，Creo3.0 M080或更高版本。
Teamcenter版本要求必须安装jre7.0以上版本，对于64位的Creo必须安装64位的jre。
注意：要从Teamcenter将JT文件导入Creo，也必须安装PTC的JT接口，并可从用户的Creo会话访问（需要额外的PTC许可）， 客户应直接通过PTC支持来验证JT接口的可用性（提前验证JT接口的可用性）。

**停止所有活动会话：**
在执行服务器安装之前，所有用户必须从Teamcenter中注销，所有服务器进程都必须
停止，所有锁必须从数据库中清除。 步骤如下：
1、通知所有用户注销Teamcenter。
2、四层环境中，关闭 pool manager服务。（停止服务端所有TC相关服务即可）。
3、打开TC的命令窗口，输入以下清除数据库会话锁的命令：
clearlocks –assert_all_dead infodba infodba dba
注：服务端安装，如果不执行上述步骤，将会导致集成服务安装失败，集成功能不能正常使用。如果是客户端安装，则不需要上述步骤。

When trying to start NX, the user receives the following error,
"NX Initialization Error - Failure in xerces_sax_parse attempting to parse
file: [File:///C:\Program](File:///C:/Program)
Files\Siemens\NX\12.0\ugii\materials\physicalmaterialdefinations.xml"
**SOLUTION**
As a workaround,
- Open "Control Panels"
- Select the "Region and Language" Control Panel
- Select the "Formats" pane
- Change the Format to "English (United States)".
- Close the Control Panel (a Reboot might be necessary)
- Restart NX

<span style='background:white'>When trying to start NX, the user receives the following error,</span>
<span style='background:white'>"NX Initialization Error - Failure in xerces_sax_parse attempting to parse</span>
<span style='background:white'>file: </span>[<span style='background:white'>File:///C:\Program</span>](File:///C:/Program)
<span style='background:white'>Files\Siemens\NX\12.0\ugii\materials\physicalmaterialdefinations.xml"</span>
**SOLUTION**
<span style='background:white'>As a workaround,</span>
<span style='background:white'>- Open "Control Panels"</span>
<span style='background:white'>- Select the "Region and Language" Control Panel</span>
<span style='background:white'>- Select the "Formats" pane</span>
<span style='background:white'>- Change the Format to "English (United States)".</span>
<span style='background:white'>- Close the Control Panel (a Reboot might be necessary)</span>
<span style='background:white'>- Restart NX</span>

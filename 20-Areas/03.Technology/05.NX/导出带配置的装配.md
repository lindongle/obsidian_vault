Currently there is a below workaround for the same-

You can use the functionality "<span style='color:#FA0000'>Export Configured UGNX Assembly</span>" available under Structure Manager \> Tools \> Export Configured NX Assembly.

To enable this functionality, set "TC_ExportConfigUGNXAssembly" site preference to "TRUE" and applied a variant configuration to existing structure in Structure Manager.

The structure, as configured in Structure Manager, was exported and maintained in a native format (i.e., only those components that were shown in Structure Manager were exported). On opening the assembly in native NX, the Assembly Navigator shows all missing components and NX complains that it can't find the missing components (in TCIN these components would have been suppressed if the structure had been sent to NX due to effectivity or variants). This is because in native NX, the structure is being read from the assembly part file. The Export Configured NX Assembly utility utilizes ug_clone - it does not make changes to the part files internal assembly structure when the assembly is exported to its native format.

设置首选项Export Configured UGNX Assembly设置为true，结构管理器会出来Tools \> Export Configured NX Assembly菜单，用此菜单导出，但数据量太大的话会造成内存溢出，大数据最好在服务器端导出

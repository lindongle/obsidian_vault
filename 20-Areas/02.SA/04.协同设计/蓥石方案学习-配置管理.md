1、几个Option Family的区别。
Package Option Family属于特殊的Option Family；
Package Option Value其所包含的值，是多个普通的Option Value的集合，但需来源于不同的Option Family；
执行选配置，当选择具体Package Option Value后，应用默认配值设置后，自动将该Value下包含的Option Value带出来；
Package Option Family是多个普通选项值的集合，用于市场、配色等场景下，方便打包一次性选择多个Value。
Package Option Family：只一组有关联的选项，如当一个选项为值1时，另几个选项必须选择值N，这种，各个选项之前选择不同值时，对应关联选择对应的值的情况。
Summary Option Family：基于某个选项衍生出的选项，建立原始选项的选项值与衍生选项的选项值质检的强关联关系。在SOS配置时，使用衍生出的选项关联代替原始选项，如普通选项国家，值为中国、英国。新建汇总选项：驾驶方向，选项值为左方向驾驶和右方向驾驶，并将左驾关联国家的选项值中国，右驾关联国家的选项值英国。

2、Configurator Rule：CR配置规则，约束。
Variant Rule：VR，SOS，配置规则。配置单。
3、配置器关联对象的概念。
几个概念：
配置器字典：一组标准的规范的选项族组的结合，如某配置器字典包含300个选项。可以分不同的组。
选项族组：某配置器字典下的一组选项。
选项：即变量，如发动机排量。
选项值：变量的值，如2.0T
车型配置器关联：类似于配置器字典的实例，即针对不同车型，可以建立车型配置器关联这个对象，对象的选项可以从配置器字典中抽取，如抽取了200个选项。
构建配置器关联与车型的关系：将上面车型配置器关联对象 与具体车型的顶层建立关联。同一个车型配置器关联对象可以与同车型多个BOM形态（如EBOM，DBOM，POBM）关联。
优势：配置器字典可以让多个车型做配置时进行选项的引用，减少维护量。

<span style='color:#1F204C'>**车辆出口模式分类**</span>
<span style='color:#1F204C'>  根据各个国家法律法规，贸易关税不同，汽车出口到不同国家地区的主要模式有：**整车模式出口CBU**（Complete Built Unit），全**散件模式出口CKD**（Completely Knock Down），**半散件模式出口SKD**（Semi Knocked Down）。</span>
<span style='color:#1F204C'>  1.**CBU（Complete Built Unit）整车形式出口**</span>
<span style='color:#1F204C'>  整车模式出口的车辆非常简单。在这种形式里，车辆是在完全组装和运行的状态下进行出口的。一家汽车制造商在本国制造汽车，汽车以成品状态运往海外，并在出口市场上出售给最终客户。</span>

![image1](9b5032c96e924b298280de1663d805fc.png)
<span style='color:#1F204C'>   如果我们谈论缺点，CBU 的汽车可能更贵，因为它们在目的地国家/地区要缴纳高额进口关税和税收。但是，另一方面，它提供了高质量的材料和可靠性，并附带保修，这为消费者提供了使用先进技术的附加产品，这些都是在受控环境下制造的。</span>
<span style='color:#1F204C'>   CBU 汽车不在目的国消耗生产制造时间，而且它们不需要任何特殊的专业知识来组装，因为它们已经在工厂进行了完全组装和测试。消费者可以享受高品质汽车的好处，而无需担心 CBU 汽车的任何技术问题或组装。大多数情况下，人们更喜欢重视便利性、质量和可靠性的 CBU 汽车。</span>
<span style='color:#1F204C'>   2.**SKD（Semi Knocked Down）半散件组装形式出口**</span>
<span style='color:#1F204C'>   SKD的意思是半散件组装，是指汽车总成（发动机，驾驶室，底盘等）向目的国出口，在目的国工厂进行组装。相当于人们把汽车做成“半成品”进行出口。自汽车工业发展初期以来，汽车制造商就一直依赖 SKD 组装，福特很早就开始将车辆散件装箱，运往国内和海外偏远地区进行最终组装。第二次世界大战期间，SKD 运输工具的使用进一步增加，美国和加拿大制造的军用车辆被分解成模块并运往海外，以便在更靠近前线的地方组装。随着汽车行业的分散化，SKD出口的做法在今天仍然非常普遍，</span>
<span style='color:#1F204C'>   一般来说，一辆功能齐全的车辆是完整的，在本国的制造厂建造，然后被运到车间被拆卸或“打散”。打散程度取决于进口国的法规；更高的打散水平需要更多的工作来重新组装，这反过来又会在进口市场上创造更多的就业机会和价值创造。然后将拆下的零件装入集装箱，如车身、发动机、变速器、排气系统、轮胎、配电板和属于同一车辆的任何其他零件都在同一集装箱中，或与不同类型的零件一起装载在单独集装箱中。</span>

![image2](c9667857672c491098653d2e7f69ba6e.png)
<span style='color:#1F204C'>   打散的车辆被运往进口国，在那里它们通常享受优惠进口税，而不是 CBU 进口。汽车在当地组装厂重新组装，主要通过不涉及喷漆或焊接的组装程序。这种 SKD 流程在没有本地供应商基础且进口车辆数量相对较低的全新市场中最为常见。</span>
<span style='color:#1F204C'>   SKD进口对于进口商来说，既可以节省运费，利用进口国的廉价劳动力，又可以享受一些低于整车的进口关税。对于进口国来说，可以促进国内产业发展，增加就业机会，占领国内市场。</span>
<span style='color:#1F204C'>**  3.CKD（Complete Koncked Down）全散件组装形式出口**</span>
<span style='color:#1F204C'>  CKD出口和组装是汽车制造发展的最后阶段，然后才转向全面的本地化制造和采购。在 CKD形式中，大部分零件将装在箱子和板条箱中运输，然后在进口国进行焊接、喷漆和组装。这需要进口商对冲压厂、焊接设施和涂装车间等专业制造设施进行高额财政投资。</span>

![image3](3e0d21681f9c4776aa2facb3fbc4ff0a.png)
<span style='color:#1F204C'>   CKD 总成的国产化率通常会远高于 SKD，一系列零部件可以从当地供应商处采购，而更多高价值和先进技术的车辆零部件将由本国供应。根据进口国的汽车行业状况，CKD 进口通常会在不同的进口方式中提供最大的税收优惠，但一些国家可以选择哪些类型的零件有资格获得此类奖励，哪些不会。</span>
<span style='color:#1F204C'>   比如，泰国在当地拥有强大的发动机制造商供应基础，他们可能更愿意看到发动机本地化而不是进口。</span>
<span style='color:#1F204C'>  与直接 CBU 出口相比，SKD、CKD的出口/进口和组装需要一些额外的程序。无论是打散车辆，还是直接运输车身和其他部件，然后再从中等打散状态进行组装，都必须解决生产，运输和目的国进口规则的要求等问题，以便运行具有成本效益的解决方案。</span>

**A样件**：Prototype， 被称作原型样件，或者手工样件，零件设计初期，手工样件，验证“关键尺寸和基本功能”，关键尺寸要求，加工周期短，用于基本性能试验及mule car造车，EVT；
<span style='font-weight:bold;font-family:Calibri'>B</span>«span style='font-weight: bold;font-family:"Microsoft YaHei"'»样件«/span»«span style='font-family:"Microsoft YaHei"'»：Softtooling， 手工样件，验证“«/span»«span style='font-family:"Microsoft YaHei";color:#FA0000'»产品功能«/span»«span style='font-family:"Microsoft YaHei"'»”，全尺寸要求，零件材料与结构都与量产件一致，要对产品的功能进行全面的开发及验证，问题被识别并更正。可以是手工样件、机加工件，可以细分为B1、B2……样件，但模具为«/span»«span style='font-family:"Microsoft YaHei";color:#FA0000'»软钢模«/span»«span style='font-family:"Microsoft YaHei"'»，用于设计验证«/span»<span style='font-family: Calibri;color:#FA0000'>DV</span>«span style='font-family:"Microsoft YaHei"; color:#FA0000'»，可以是手工件或者模具件«/span»«span style='font-family:"Microsoft YaHei"'»；«/span»
<span style='font-weight:bold;font-family:Calibri'>C</span>«span style='font-weight: bold;font-family:"Microsoft YaHei"'»样件«/span»«span style='font-family:"Microsoft YaHei"'»：Hardtooling批量样件，«/span»«span style='font-family:"Microsoft YaHei";color:#FA0000'»OTS（Off Tooling Sample ）工装样件，验证“批量生产工装”«/span»«span style='font-family:"Microsoft YaHei"'»，尺寸以及老化验证，量产用的«/span»«span style='font-family:"Microsoft YaHei";color:#FA0000'»模具«/span»«span style='font-family:"Microsoft YaHei"'»，用于工艺和生产试验验证«/span»<span style='font-family:Calibri;color:#FA0000'> PV</span>«span style='font-family: "Microsoft YaHei";color:#FA0000'»，也成为“硬模件”，必须是模具件，并从供应商的量产生产线上做出来的零件«/span»«span style='font-family:"Microsoft YaHei"'»。只是产线的一些指标和最终的批量生产状态允许存在差异，比如过程能力、生产节拍等。«/span»
**D样件：**PPAP样件，验证“批量生产能力”。D样件这个称呼用得比较少，一般都叫PPAP样件，需要在批量产线制作，产线的各项指标必须达到批量生产状态，而且必须按照产线设计的生产节拍连续生产。客户的质量工程师也常常会到现场监督PPAP样件的生产过程。样件生产完成后，需要随机挑选5个以上的样件封样，具体数量会由客户决定。供应商将这5个样件、相应的检测报告及这个产品的相关文档提交到客户那里，也就是PPAP文件包。文件包里的文档都是按照APQP的流程要求在项目各个阶段输出的交付物，每个客户的要求会略有差异，但大同小异。PPAP报告一旦得到批准，零件就可以进入SOP。
**SOP：**（Start of Production）PPAP批准通过，即批量生产了。

**A样：**prototype，被称作原型样件或试制样，或者手工样件，是产品设计初期用于实现用户需求而开发的不太成熟的方案；主要用于工程验证和试制验证，验证设计方案和关键技术； A样一般可以通过手工制造，也可以通过对现有产品进行改制而获得。A样的外观尺寸和功能等可以在设计过程中不断优化完善，也可以用于对客户进行送样，来验证产品是否满足客户市场的需求；设计A样件的好处是可以及时了解产品的改进方向，无需按照完善的流程进行生产，从而可以缩短开发周期，避免无意义的浪费。但是A样仅可用于对产品进行简单的性能验证，无法实现长期性能验证(如疲劳实验和寿命试验等)。
**B样(Softtooling)：**也叫验收样件或设计样件，是根据A样试制结果优化后的样件，外观、功能达到设计要求，B样可以是手工样件或者模具件，B样件的全维度产品功能和尺寸参数已经固化下来，并需要和最终的量产产品保持一致。B样件能够满足长期性能验证的需求，如耐久试验和疲劳强度试验。
**C样(Hardtooling)：**为批量样件或生产样件、展示样件，是在A/B的基础上完善结果，此时的产品状态已经完全定型，并能够满足客户和市场提出的各类需求。从生产角度来说，C样件已经可以采用生产线进行制造，并有专用的工装器具以及对应的工艺路线文件。与最终交给客户的基本一致。
**D样：**C样的下一个阶段，一般指的是达到交付客户标准的产品。D样产品可用于进行相关的审核(如整车进行公告验证)及强制检测等，并提供质保说明和使用手册，以到达产品释放标准；样件生产中所有可能出现的问题和故障都应该在D样之前关闭。
**SOP：**StartofProduction，即开始量产；指产品已经开发设计完成且进行过各类测试检验，并且生产线也已经建设完成，可以实现大批量供货，SOP标识着产品已经到了D样件的状态。

<span style='color:#212121'>A 样：原型器件（Prototype）</span>
<span style='color:#212121'>**一般被称作原型器件，能够实现基本的功能并进行相关验证**</span>
<span style='color:#212121'> 特点：</span>

<span style='color:#212121'>**  ① 手工样件**</span>
<span style='color:#212121'>**  ② 外观、尺寸、功能等尚未完善**</span>
<span style='color:#212121'>****</span>
<span style='color:#212121'>B 样：手工样件（Soft Tooling）</span>
<span style='color:#212121'>**   一般被称作为手工样件，使用辅助工具制成的功能性、可驾驶的样品，用于设计验证 DV（Design Verfication，验证设计出来的产品是否符合标准要求）**</span>
<span style='color:#212121'>   特点：</span>

<span style='color:#212121'>**① 手工或者模具件**</span>
<span style='color:#212121'>** ② 软硬件功能要求均已满足**</span>
<span style='color:#212121'>** ③ 外观尺寸已经固化**</span>
<span style='color:#212121'>** ④ 能够满足性能验证要求**</span>
<span style='color:#212121'></span>
<span style='color:#212121'>OTS：工装样品（Off Tool Sample）</span>
<span style='color:#212121'>**被称作为工装样品，主要用于性能、制造可行性及品质可行性方面的评价，目的就是验证大规模生产零件供应商的硬工装的能力**</span>
<span style='color:#212121'> 特点：</span>

<span style='color:#212121'>**   ① 非生产节拍条件下生产的工装样品**</span>
<span style='color:#212121'>**   ② 有对应的工程认可报告（如尺寸、性能、外观合格报告等）**</span>
<span style='color:#212121'></span>
<span style='color:#212121'>C 样：批量样件（Hard Tooling）</span>
<span style='color:#212121'>**使用生产工具制造的部件，主要用于验证 PV（Product VerificatIon，验证使用批量生产工艺生产的产品是否符合要求）**</span>
<span style='color:#212121'> 特点：</span>

<span style='color:#212121'>**   ① 使用生产工具制造的批量件**</span>
<span style='color:#212121'>**   ② 有专门的工装器具和对应的工艺路线文件**</span>
<span style='color:#212121'>**   ③ 可用于实车测试**</span>
<span style='color:#212121'></span>
<span style='color:#212121'>SOP：开始量产（Star of Production）</span>
<span style='color:#212121'>**该阶段的产品可用于进行相关的审核（如整车进行公告验证）及强制检测等，并提供质保说明和使用手册，以到达产品释放标准。**</span>
<span style='color:#212121'> 特点：</span>

<span style='color:#212121'>**   ① 满足所有质量要求**</span>
<span style='color:#212121'>**   ② 适合全面生产**</span>
<span style='color:#212121'>**   ③ 有配套的车间产线**</span>

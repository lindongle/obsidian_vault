# DevSidecar

提起GitHub，大家第一反应是什么？访问慢？经常打不开？克隆个项目要么等半天，要么就是超时，很是烦躁！！！

今天给大家介绍一款开源神器——DevSidecar（开发者边车），让你直连GitHub，解决访问速度慢的问题。

![[99-Assets/8c2872c1c84b42f01871fbd43bec202a_MD5.png]]

目前在Github上已收获21.6k Star！

![[99-Assets/f0dafb92528dff0eecf74ebe5c153893_MD5.png]]

## 为什么需要它

GitHub是全球最大的代码托管与开源协作平台，对于开发人员来说必不可少，但访问问题会困扰大多数开发者：

-   • 页面加载转圈转半天
    
-   • git clone 几KB/s
    
-   • release下载中断
    

## 核心功能

### 直连GitHub

无需配置VPN/代理，DevSidecar自动优化访问路径：

-   -   **网页浏览**：GitHub页面秒开
-   -   **Git操作**：git clone/push/pull速度起飞
-   -   **Release下载**：大文件下载满速

### GitHub增强

-   -   **GitHub加速**：修改SNI实现直连
-   -   **图片加速**：解决头像、图片加载不出来
-   -   **Release/Source/Zip下载加速**

### 镜像加速

-   -   **NPM加速**：npm/yarn/pnpm命令加速
-   -   **PIP加速**：Python包下载加速
-   -   **Go模块加速**：Go依赖加速

### 附加功能

-   • StackOverflow加速
    

## 使用方法

### 下载安装

从GitHub releases页面下载对应平台的安装包：

-   • Windows：exe安装包
    
-   • macOS：dmg安装包
    
-   • Linux：AppImage/deb

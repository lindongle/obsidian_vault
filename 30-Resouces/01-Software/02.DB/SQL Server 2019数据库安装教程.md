<span style='color:white;text-align:center'>安装教程</span>
<span style='background: white'>注意：安装过程需要电脑连接网络，中途不能断网</span>
<span style='color:#3E3E3E'>1、鼠标右击【SQL Server 2019】选择【解压到当前文件夹】</span>
![image2](03edff79ee874093a048e381dfa5f445.png)
<span style='color:#3E3E3E'>2、双击进入解压后的【SQL Server 2019】文件夹</span>
![image3](3811e5f37f1d47b78584c8a08af2ffb4.png)
<span style='color:#3E3E3E'>3、选中【Setup】可执行文件，鼠标右击选择【以管理员身份运行】</span>
![image4](59ffe36eecd7423080fe2947763fcefd.png)
<span style='color:#3E3E3E'>4、点击【安装】</span>
![image5](99fbefde5c0549c5838a18d45913f6e5.jpg)
<span style='color:#3E3E3E'>5、点击【全新SQL Server独立安装向现有安装添加功能】</span>
![image6](7378e75818a547f0b81b7b3f79c5014e.jpg)
<span style='color:#3E3E3E'>6、密钥自动输入，点击【下一步】</span>
![image7](11fe617acff14f21b3042e7983125ee3.jpg)
<span style='color:#3E3E3E'>7、选择【接受许可条款】点击【下一步】</span>
![image8](81396d9339194fd8a667390890bcbf9c.jpg)
<span style='color:#3E3E3E'>8、点击【下一步】</span>
![image9](9c2d24eea5fe4783ad5e7b1bc27c5142.png)
<span style='color:#3E3E3E'>9、稍等一下</span>
![image10](c0c2ce34af044f43af6172bd415f0c67.png)
<span style='color:#3E3E3E'>10、点击【下一步】</span>
![image11](15019e7440674a37bba7f5c94f7b675f.jpg)
<span style='color:#3E3E3E'>11、点击【全选】，然后取消勾选【机器人学习服务】，建议把SQL软件安装到除C盘以外的磁盘，我安装到D盘，所以只需要把字母C改为D即可选择好安装路径，点击【下一步】</span>
![image12](84d6785f7b214580b5ec9e2240b2bd7d.jpg)
<span style='color:#3E3E3E'>12、点击【下一步】</span>
![image13](84990c878d7044d0b15490dee00bd89d.jpg)
<span style='color:#3E3E3E'>13、点击【下一步】</span>
![image14](77ac6f2c9ac444e4bf4805954dc5e9b8.jpg)
<span style='color:#3E3E3E'>14、点击【下一步】</span>
![image15](1266ce7ad75f466596d056d605b71656.jpg)
<span style='color:#3E3E3E'>15、账户名选择【NT AUTHORITY\NET..】点击【下一步】</span>
![image16](50238ecb624847b5a69099e6d304c275.jpg)
<span style='color:#3E3E3E'>16、点击【添加当前用户】再点击【下一步】</span>
![image17](3a0fbb8943b641f29428699cef36627d.jpg)
<span style='color:#3E3E3E'>17、点击【添加当前用户】再点击【下一步】</span>
![image18](f213df36507e40cb9abf9857afbe0119.jpg)
<span style='color:#3E3E3E'>18、点击【下一步】</span>
![image19](b38b7d71f68d4126825d2db94317c0ec.jpg)
<span style='color:#3E3E3E'>19、点击【添加当前用户】再点击【下一步】</span>
![image20](2bf852e9aa6b41909db1df99b801771b.jpg)
<span style='color:#3E3E3E'>20、建议把SQL软件安装到除C盘以外的磁盘，我安装到D盘，所以只需要把字母C改为D即可选择好安装路径，点击【下一步】</span>
![image21](06021c59da1540ff9eb0f739d58a34ad.jpg)
<span style='color:#3E3E3E'>21、点击【安装】</span>
![image22](4a49509d0b55406fbde1d7ec4882fd8e.jpg)
<span style='color:#3E3E3E'>22、安装中，等待即可</span>
![image23](5c39d23959874ee9bd4e6c7b57cf0297.png)
<span style='color:#3E3E3E'>23、点击【确定】</span>
![image24](23f93f8e0910456aa80cdfe48fbc7b8e.png)
<span style='color:#3E3E3E'>24、安装成功点击【关闭】</span>
![image25](7ab63ed4591b4b7e92360547213bf924.jpg)
<span style='color:#3E3E3E'>25、双击打开压缩包解压后的【SQL Server 2019】文件夹，鼠标右击【SSMS】选择【以管理员身份运行】</span>
![image26](6b09476bed00450f910bda54810f00f6.png)
<span style='color:#3E3E3E'>26、建议把SQL软件安装到除C盘以外的磁盘，我安装到D盘，所以只需要把字母C改为D即可，选择好安装路径后点击【安装】</span>
![image27](0f1dc741db0c4d45bccfcdb256509081.jpg)
<span style='color:#3E3E3E'>27、正在安装中</span>
![image28](6b782776377d48c88bcf7b49d1615fd3.png)
<span style='color:#3E3E3E'>28、点击【关闭】</span>
![image29](1612c9074a6b45ada4ddf5596a63051e.png)
<span style='color:#3E3E3E'>29、点击【开始】图标。找到【SQL Server Management】点击运行</span>
![image30](39eb5c868856429cab01f2de736859df.png)
<span style='color:#3E3E3E'>30、点击【连接】</span>
![image31](92eef3a103b743ae944cf1358f437224.png)
<span style='color:#3E3E3E'>31、安装完成,管理工具界面如下</span>

# 破解

[](#破解)

1.  修改hosts

hosts文件路径：`C:\Windows\System32\drivers\etc\hosts`

```sql
127.0.0.1       dbeaver.com
```

2.  将系统文件显示模式改为显示隐藏项目（使用默认路径安装需要）

![[99-Assets/91e5777e9730e12a9307c1cfe9d72fc5_MD5.png|1704258735057]]

3.  双击打开破解文件

Patch路径为：`C:\Users\Users\AppData\Local\DBeaverUltimate\plugins`（默认路径，按照实际修改）

![[99-Assets/61afa6e3223eb1e99435372d32d93cb5_MD5.png|120fe08bedb87022d51816f4fff442f]]

![[99-Assets/ebe60a8865534ca4e5309652a7c60138_MD5.png|b7f4bf24b1beb042827a7476d466e11]]

3.  打开DBeaver

![[99-Assets/6667bbe842c66da6122c7870e57fdc85_MD5.png|96d95dfd4af84a3a3ebac9b5294832b]]

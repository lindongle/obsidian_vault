需求：设置自定义状态C8MasssProduction的图标为自定义图标  

![image1](06559eac44164f9c9a6da1c92f82eccf.png)
环境：tc2312  
配置方法：1.将svg格式图标文件放置到\$TC_ROOT\aws2\stage\src\image目录，并做好命名，命名规则为  
indicator+状态真实名称+16.svg，如下图：
![image2](87a7e46be1424613a74a3b0a6c765fc3.png)
2.使用initenv.cmd命令和npm run generateModule命令生成module(如果项目已有module，此步骤可忽略)
![image3](42c4d332b7754f038ecb557088584718.png)
moduletest为模块的名称，可以自定义
![image4](ea109b117402435e877c40d36ae09a8b.png)
3.在模块目录下新建indicators.json，并输入如下信息
{

  "fx_release_status_list_C8MasssProduction": {
    "iconName": "C8MasssProduction",

    "tooltip": {
      "showPropDisplayName": false,

      "propNames": \[
        "object_name",

        "date_released"
      \]

    },
    "prop": {

      "names": \[
        "release_status_list"

      \],
      "type": {

        "names": \[
          "ReleaseStatus"

        \],
        "prop": {

          "names": \[
            "object_name"

          \],
          "conditions": {

            "object_name": {
              "\$eq": "C8MasssProduction"

            }
          }

        }
      }

    },
    "modelTypes": \[

      "WorkspaceObject"
    \]

  }
}

![image5](0d262f35b1cc48f4a54ee50e2dc7e2cd.png)
4.修改\$TC_ROOT\aws2\stage\src\repo\tc-aw-framework\src\assets\propRenderTemplates目录下 releaseStatusRendererService.js(releaseStatusRenderer.html这个文件已经过时，不需要修改)，如下图所示  

![image6](91d87d61aeb44c89a034a8139be70df2.png)
const releaseStatusName = releaseStatusBO.props.object_name ? releaseStatusBO.props.object_name.dbValues\[ 0 \] : '';  
5.使用awbuild.cmd命令，编译awc客户端
![image7](ad5718c58a2e4d86936b1de0b28b33f3.png)

![image8](a5c83b4d94ec4ab092507d2f36faa2ca.png)
6.启动TC服务，清理浏览器缓存，重新登录awc，查看效果  

![image9](ab71734b6e2749c0aba7c8d13bad2089.png)
![image10](332b7f7d5efa4c30a45657ab7e5c77b1.png)

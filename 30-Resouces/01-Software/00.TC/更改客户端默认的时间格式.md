更改客户端默认的时间格式
2019年7月10日
0:35

## Teamcenter 技术技巧 
***1. 无法从TC中拷贝和粘贴到外部文件***
问题：
在富客户端中拷贝一个对象到粘贴板，粘贴到其他的外部应用（比如notepad），正常情况下url 没有生成。
解决办法：
在site_specific.properties 文件中的属性portalWebServer 和 portalCGI 没有设置。
当从富客户端中拷贝和粘贴一个Teamcenter 对象时，使用这两个属性用来生成对应的url 。
系统更新时会覆盖原有的对
\<TC_ROOT\>\portal\plugins\configuration_xxxx\site_specific.properties 的修改。因此需要在相同的位置创建或者编辑已存在的该属性文件customer.properties
修改示例如下：
\###################################
\# Portal Web Server location
\###################################
portalWebServer=http://myplmserver:8080
portalCGI=tc/launchapp
打开一个命令窗口中，在%TC_ROOT%\portal\registry 下运行genregxml.bat
在%FMS_HOME%\bin 下重启， fccstat -restart.
登录4 层客户端。
拷贝一个零组件，然后粘贴在Notepad 中，URL 创建成功。

***2. 如何修改胖客户端默认的时间格式***
问题：
目前Teamcenter 胖客户端默认的时间格式精确到了分钟，如：2018-9-19 10:45。如何修改默认的时间格式精确到秒？如：2018-9-19 10:45:25。
方法：
打开文件tc_root\lang\textserver\zh_CN\timelocal_locale.xml。
定位至：
\<key id="DefaultDateFormat"\>%Y-%b-%d %H:%M\</key\>
修改为：
\<key id="DefaultDateFormat"\>%Y-%b-%d %H:%M:%S\</key\>
保存修改后，执行以下操作生效。
停止所有Teamcenter 服务。
删除Shared Memory。
删除RAC 缓存。
启动所有Teamcenter 服务。
执行以下命令：
generate_client_meta_cache -u=infodba -p=infodba -g=dba -t delete all
generate_metadata_cache -u=infodba -p=infodba -g=dba -force
generate_client_meta_cache -u=infodba -p=infodba -g=dba -t generate all

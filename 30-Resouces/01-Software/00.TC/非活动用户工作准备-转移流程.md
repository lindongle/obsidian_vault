非活动用户工作准备-转移流程
2019年7月10日
0:50

## <span style='color:#2E75B5'>Teamcenter 技术技巧 </span>
**<u>设置用户为非活动并改变零组件所有者为新的用户</u>**
<span style='color:#333333'>问题**/**症状</span>
<span style='color:#333333'>需要非活动一个用户，并更改零组件的所有者为新的用户，旧用户有很多的零组件和工作流任务</span>
<span style='color:#333333'>方案</span>
<span style='color:#333333'>为了最小化生产系统的影响，GTAC建议在非工作时间来设置用户为非活动，并执行下面的步骤。</span>
<span style='color:#333333'>1. 运行clearlocks -assert_all_dead来释放所有可能的对象锁.</span>
<span style='color:#333333'>2. 根据文档运行global_transfer工具来重新指派任何未决定的工作流</span>
<span style='color:#333333'>比如：</span>
<span style='color:#333333'>global_transfer –u=infodba –p=password–g=dba -f=demo1 -t=demo22</span>
<span style='color:#333333'>它会转移用户demo1下的所有任务到用户demo2.</span>
<span style='color:#333333'>3. 最后，在组织应用中，设置用户为非活动，选择更改所有者选项来为零组件重新指派新的所有者到需要的用户。</span>

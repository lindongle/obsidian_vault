## <span style='color:#2E75B5'>根据不同组显示不同模块的配置方法 </span>
![image1](b130bcdcac254b958283d304786ed1ac.jpg)
«span style='font-weight:bold;background: \#59C3F9'»作者：卢景豪 审校：夏春飞«/span»
**测试版本：Teamcenter11**
<span style='color:black;text-align:center'>Teamcenter系统包含很多不同的模块，为简化用户界面和方便用户使用，经常使用首选项HiddenPerspectives来隐藏一些不相关的模块。</span>
<span style='color:black'>对于不同组的用户尤其对于管理员和普通用户来说，需要关注和使用的模块也不尽相同，仅仅使用站点级的</span><span style='font-weight:bold;color:#FF2941'>HiddenPerspectives</span><span style='color:black'>首选统一设置时只能初步简化显示模块，并不能进一步提升。这个时候可使用组级别的</span><span style='font-weight:bold;color:#FF2941'>HiddenPerspectives</span><span style='color:black'>首选项来分别对不同组的用户进行设置。本文将讲述组级别的</span><span style='font-weight: bold;color:#FF2941'>HiddenPerspectives</span><span style='color:black'>首选项设置方法.</span>
<span style='color:black'>例子：为对所有用户隐藏不常用模块，单独对管理员dba组增加显示管理员相关模块，具体配置的操作过程如下：</span>

<span style='color:black'>登陆管理员账号，点击菜单“**编辑**”**--\>** “**选项**”</span>
![image2](72c0bf35aee34bb3856151c23c08b61a.jpg)
<span style='color:#FF2941;text-align:center'>**图1**</span>

<span style='color:black'>通过搜索找到首选项HiddenPerspectives</span>
![image3](f8e349c433104dabb2366397b3b021df.jpg)
<span style='color:#FF2941;text-align:center'>**图2**</span>

<span style='color:black'>选择首选项后点击“**编辑**”</span>
![image4](ce53c33161e046a1b90f51f7f696256c.jpg)
<span style='color:#FF2941;text-align:center'>**图3**</span>

<span style='color:black'>输入需要隐藏的模块名称（包括管理员相关模块），**保护范围**选择为“**站点**”，完成后点击“**保存**”</span>
![image5](f6b5676666a94230abdf246574ca1df8.jpg)
<span style='color:#FF2941;text-align:center'>**图4**</span>

<span style='color:black'>检查所有用户都只能访问未隐藏的模块</span>
![image6](b3e561c3195d41f8bb30f3a98f330601.jpg)

<span style='color:#FF2941;text-align:center'>**图5**</span>

<span style='color:black'>编写组级别的**HiddenPerspectives**定义，具体内容见附件一</span>
![image7](bc073498b50c4ebf8fba77b1a1bfa65c.jpg)
<span style='color:#FF2941;text-align:center'>**图6**</span>

<span style='color:black'>在“**选项**”--\>“**组织**”中选择**dba**组节点</span>
![image8](5217a420fd2f4fceacbd5da139fceb3b.jpg)
<span style='color:#FF2941;text-align:center'>**图7**</span>

<span style='color:black'>将组级别的首选项定义文件导入到位置“**组：dba**”，点击**导入**执行</span>
![image9](4f6d0a9e576f46a6871244b7b7a4d3a9.jpg)
<span style='color:#FF2941;text-align:center'>**图8**</span>

<span style='color:black'>点击**确定**关闭导入状态提示</span>
![image10](d3855e3c29604cb1b5bf569022c18aa0.jpg)
<span style='color:#FF2941;text-align:center'>**图9**</span>

<span style='color:black'>检查**dba**组位置的首选项定义正确</span>
![image11](1ff3d05a9bd5410a9daff9442df3511c.jpg)
<span style='color:#FF2941;text-align:center'>**图10**</span>

<span style='color:black'>重新登陆系统，检查dba组用户可显示管理员相关模块</span>
![image12](4cebd786449e404e9e837c33a5af0a22.jpg)
<span style='color:#FF2941;text-align:center'>**图11**</span>

<span style='color:black'>检查其他组用户只能访问部分应用模块</span>
![image13](38699e9ff8f4419e91ae35f6ab6a4c1f.jpg)
<span style='color:#FF2941;text-align:center'>**图12**</span>
<span style='color:black'>通过以上方法能实现根据组来过滤不同的可用显示模块。</span>
<span style='color:black'>附件一：组级别HiddenPerspectives首选项定义</span>
![image14](70cfd789c01e4400bfdc8b3333306f85.jpg)
![image15](651b7a5216a74510a224bce002b8a37c.jpg)

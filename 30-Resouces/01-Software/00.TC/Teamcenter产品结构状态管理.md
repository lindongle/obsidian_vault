# 1.说明

Teamcenter中的产品结构的形态，即产品的视图，在Teamcenter中可以创建、编辑、查看、管理不同的产品结构。如何管理产品结构的状态，Teamcenter提供了不同的管理方式，包括静态的精确BOM，动态的非精确BOM，BOM加载的版本规则，以及快照、基线等不同的方式。本文主要介绍Teamcenter中管理产品结构的状态的不同方式的概念和用法。

# 2.精确和非精确

精确BOM：BOM中使用具体的零组件版本的事例（可以理解为链接），并且只对选择的视图生效，BOM行显示为绿色底色，从加载零组件版本角度精确BOM是一个静态的BOM结构；

非精确BOM：BOM中使用的是零组件事例，根据版本规则确定使用的版本，BOM行底色为白色，从加载零组件版本角度非精确BOM是一个动态的BOM结构。

在结构管理器中，可以将产品结构的视图设置为精确BOM，切换精确和非精确使用菜单【编辑】\-【切换精确/非精确】

![[99-Assets/bcfc3673b6795e89dc0eac2f224f2b3c_MD5.png]]

精确BOM中版本规则识别的是“精确”，非精确BOM中，版规则识别的是“工作中”。

![[99-Assets/5aabbb5c89d5e8c1073230d4499de293_MD5.png]]

非精确BOM视图中显示的零组件，精确BOM视图中显示的零组件版本

# 3.版本规则

版本规则：是BOM视图中加载零组件版本的过滤规则，过滤规则中可以包含多个版规则条目，按照自上而下顺序进行匹配。

# 3.1.查看或者设置版本规则

在结构管理器中打开产品结构视图时，产品结构中加载显示零组件的哪个版本，主要是根据版本规则决定，如果版本规则不能过滤出需要使用的版本，在产品结构中BOM行版本将显示为问号？，表示无法确定使用哪个版本。

![[99-Assets/71d9b525dbfc27bd5b0bb3c2e93afaa3_MD5.png]]

要查看或设置版本规则，点击菜单【工具】\-【版本规则】\-【查看/设置当前】

![[99-Assets/6a59ac1a24090721c814e388a29b68d7_MD5.png]]

打开版本规则窗口，可以查看当前产品结构使用的版本规则（高亮显示的选中的规则），可以切换选择不同的版本规则。

版本规则中条目包含多个规则，规则的顺序代表了使用时的优先级，每一个规则条目都可以作为一个独立的版本规则使用。

![[99-Assets/e9361ef504c06a117c30077fe37766ad_MD5.png]]

TC的产品结构由于是依据版本规则，过滤显示产品结构中BOM行的零组件的版本，因此选择精确和非精确BOM就尤为关键。

# 3.2.创建版本规则

版本规则的查看设置、编辑、创建，都是在结构管理器中，通过菜单【工具】\-【版本规则】

常用的版本规则说明：

1.  工作中：工作中状态版本，还可以配置用户或者组；
    
2.  状态：具有状态（任意状态或某个具体状态，配置依据：发布日期或单元编号）：具有任意状态或某个具体状态的版本，并且发布日期为最新发布日期，或者单元编号为设置的单元编号；
    
3.  替代：替代文件夹，BOM快照使用，快照文件夹中存放的版本
    
4.  日期：可以配置日期时间；
    
5.  单元编号：可以配置单元编号值；
    
6.  精确：精确BOM专用，加载精确的版本，在搭建BOM结构时，使用的版本；
    
7.  最新：可以配置按照字母数字版本ID、数字版本ID、字母+数字版本ID、创建日期；
    
8.  顶层零组件：可以配置顶层零组件对象。
    

  

点击【创建】，打开创建版本规则界面

编辑版本规则的条目，可以移除已有条目，可以上移、下移条目，选择并附加版本规则到条目列表中。条目中顺序代表了版本规则使用时的优先级。

点击【确定】按钮，创建新的版本规则

# 4.快照

  

快照：是TC中的一个特殊文件夹（快照文件夹）。用于捕获当前产品结构信息，可以存放当前产品结构中的零组件版本。

由于快照文件夹中只是引用零组件版本，因此不会消耗额外的存储空间。注意：如果是对工作中的产品结构创建快照，当编辑修改产品结构时，快照文件夹中引用的零组件版本信息也会同步变化，因此快照适合用于在产品结构发布后创建，可以保存产品结构的状态。

在结构管理器中打开产品结构，通过菜单【文件】\-【新建】\-【快照】打开创建快照界面。

![[99-Assets/173001dd79d97b2c0e39ab7289320450_MD5.png]]

输入快照的名称和描述，点击【确定】按钮

![[99-Assets/7c9efc0414b4cd607e29f7488f8cc248_MD5.png]]

默认存放在Newstuff文件夹下，生成快照文件夹，包含产品结构中所有的零组件版本。

![[99-Assets/3820e56cb307130b1f74052f1d27477b_MD5.png]]

将快照文件夹通过右键菜单【发送到】\-【结构管理器】中打开，查看快照数据

![[99-Assets/a479057757d012904af7bf51f07d2fc6_MD5.png]]

结构管理器中打开后，版本规则默认使用的是替代文件夹的版本规则，即加载快照文件夹中的零组件版本。

![[99-Assets/5e086e35601e9e0bdfd0e359f3614f5f_MD5.png]]

如果产品结构使用的是非精确最新有效的版本规则，对产品结构修订新版本编辑修改后，由于版本规则是最新有效，当打开旧版本产品结构时，并不能查看到旧版本产品结构，加载显示的还是最新有效的版本。

如果已经对已发布的旧版本产品结构创建快照，打开产品结构快照和新版本产品结构比较，快照中保存着旧版本产品结构状态，与新版本产品结构不同。并且在新版本产品结构中编辑修改，并不影响快照的产品结构。

新版本产品结构中对子对象修改数量，快照中数量没有变化

# 5.基线

基线：是TC中零组件的一个特殊版本，有单独的版本号、状态。用于捕获当前产品结构状态，基线类似于对工作中数据版本生成一个小版本，如在版本号为：A.001

由于基线是对工作中数据生成一个基线版本，因此需要消耗额外的存储空间。基线适合对工作中数据创建，会保存工作中数据的状态，并且工作中数据变化时，不影响基线版本。

在结构管理器中打开产品结构，通过菜单【工具】\-【基线】，打开创建基线界面

![[99-Assets/68d3910bb97be0c6aad6d2aa986f9d39_MD5.png]]

选择基线发布流程模板、选择精确基线（注意如果不选择，将创建非精确基线），点击【确定】按钮，自动创建基线。

![[99-Assets/1ca4d1c7a83969afd04c441df827433a_MD5.png]]

创建基线后，在零组件下，可以查看生成的基线版本。注意：当产品结构中使用的是已发布的零组件版本时，将不会再生成基线版本，直接使用已发布的零组件版本。

创建基线时，会按照深层复制规则，复制与零组件版本关联的数据集、表单和其他附件。

![[99-Assets/0ec5b969a6401066e91e59ae9e2beea5_MD5.png]]

打开基线产品结构后，可以查看精确状态的产品结构。并且对原产品结构修改，不会影响精确状态的基线产品结构。

![[99-Assets/d05562610dff7ec7aa53ee2f723a6b8e_MD5.png]]

修改产品结构子对象数量，基线中数量没有变化

![[99-Assets/1fd303df1f8b97d188fe9e9ab6096150_MD5.png]]

移除产品结构中的子对象，基线中包含子对象

![[99-Assets/0e41e21d0f88c8b433f4ce412cc65d58_MD5.png]]

修订子对象零组件版本，基线中使用的是旧版本

# 6.总结

Teamcenter

中通过视图管理产品结构，通过版本规则加载显示视图中事例，通过快照、基线捕获产品结构状态，而精确和非精确则用于设置静态和动态产品结构。​使用精确产品结构时，产品结构中使用的都是具体的零组件版本，产品结构发布后，如果子项发生变更升版，必须同时对父项修订新版本，才能对结构中的子项版本进行移除，再添加新的子项版本。​如果使用非精确产品结构时，产品结构中使用的零组件版本由选择的版本规则过滤确定，当产品结构发布后，如果子项发生变更升版，而父项不需要修改时，打开产品结构时，根据版本规则，可以自动加载最新的子项版本。​所以精确和非精确，适用于不同的业务场景。​如果企业的产品结构是多版本有效，即同一产品，多个版本都是在用、在产有效的数据，则比较适合使用精确

BOM，对每个版本的产品都是独立有效的管理。如果产品结构是最新有效，即同一产品始终使用最新的版本，则适合使用非精确BOM，方便获取最新有效的数据。

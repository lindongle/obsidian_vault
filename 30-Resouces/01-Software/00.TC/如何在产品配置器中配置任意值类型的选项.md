## <span style='color:#2E75B5'>如何在产品配置器中配置任意值类型的选项 </span>

![image1](eb5e70b576914400bde37804241051d7.gif)
<span style='color:white'>**作者：段虎彪 审校：陈泓希**</span>
**适用版本：Teamcenter11**
![image2](ba38d339f545405c8fe9f8339fc83bd7.png)
<span style='color:#333333'>在TC中使用产品配置选配时，有时候需要通过直接输入数值根据设定的范围来筛选出符合规则的BOM，这样就需要在产品配置器中配置，同时在配置变量公式时配置相对应的范围，这样就能在选配时，通过输入数值根据设定的范围来筛选BOM。</span>

![image3](0583c8f007ad4636ae03e43b62f0dfe3.gif)
**具体操作**
![image3](0583c8f007ad4636ae03e43b62f0dfe3.gif)
<span style='background:#59C3F9'>1</span>
<span style='color:black'>点击产品配置器，创建字典以及配置器：</span>

![image4](c09b022ad2ec4875b3139c9e30b8c2b8.png)

<span style='background:#59C3F9'>2</span>
<span style='color:black'>添加组和族：</span>

![image5](a526be42b51b4911be90ce8f0895a35a.png)

<span style='background:#59C3F9'>3</span>
<span style='color:black'>添加选项族时点击任意形式，将否改为是，根据需求设置值数据类型（此处不能选择字符串类型）：</span>
![image6](e9f1f25e31774a5088aea10abd7d3a12.png)

<span style='background:#59C3F9'>4</span>
<span style='color:black'>设置最大值最小值（可选）：</span>

![image7](8011b3c64d82434da2d3de7cb155ecbd.png)

<span style='background:#59C3F9'>5</span>
<span style='color:black'>点击保存，将字典保存，将字典添加到配置器且关联到BOM中：</span>

![image8](2b356ad9b81a4e79ac4d73fa31a5f473.png)

<span style='background:#59C3F9'>6</span>
<span style='color:black'>进入结构管理器配置变量公式，点击编辑变量公式按钮：</span>

![image9](28ba80443f624bb1ad17a3bd47d6ac6d.png)

<span style='background:#59C3F9'>7</span>
<span style='color:black'>根据需求设置规则的范围值：</span>

![image10](e4b1457f2b744b44a2c88a39d682786a.png)

<span style='background:#59C3F9'>8</span>
<span style='color:black'>点击确定后，将勾选设置的变量：</span>

![image11](1a5b81b1c662424ea7ba0e0a3836354c.png)

<span style='background:#59C3F9'>9</span>
<span style='color:black'>点击空白处可继续添加变量规则：</span>

![image12](5546ac50f7074213bbdf6fd920ca026a.png)

<span style='background:#59C3F9'>10</span>
<span style='color:black'>变量公式设置完成后即可进行选配：</span>

![image13](5916b817355d4fa1b33be7816c440e9c.png)
<span style='background:#59C3F9'>11</span>
<span style='color:black'>选配时可直接输入具体的数值：</span>

![image14](0f86b33a21d94972858fe6937c05b423.png)

<span style='background:#59C3F9'>12</span>
<span style='color:black'>点击应用即可选配出符合规则的BOM结构：</span>

![image15](fb0d79dc89674df2ac945d76fdb8cb42.png)

这样就能满足通过直接输入数值根据设定的范围来筛选出符合规则的BOM。

![image16](a83b74dcca494fa9bfe764c9d7345b3c.jpg)

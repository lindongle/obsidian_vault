<span style='background:white'>“珍妮，OneNote，是什么东东。”</span>
<span style='background:white'>“微软云笔记。”</span>
<span style='background:white'>“哦。那是什么？”</span>

<span style='background:white'>无论是一个准备新菜谱的厨师，还是实地考察拍摄记录的学生，或检查患者病历的医生，都可以通过OneNote呈现高效直观的效果，感觉燃爆了！有没有！</span>

<span style='background:white'>嗯，你刚才看到的是微软发布的OneNote 5年后的技术发展愿景的视频。</span>

<span style='background:white'>（EXO？</span>

<span style='font-weight:bold;color:#FF837E'>【1】</span><span style='font-weight:bold; color:black'>基础功能</span>

<span style='background:white'>Microsoft OneNote是office全家桶里面的一员。只要你装了Office，应该都能找到它。</span>

<span style='background:white'>而OneNote更为人熟知的是它的笔记本功能，是电子版的笔记本。</span>

<span style='background:white'>它的操作界面就是</span><span style='font-weight:bold;background:white'>带有标签的三环活页夹的电子版本</span><span style='background:white'>，架构为「笔记本」、「分区」、「页面」。</span>
![image3](938f38f097f14dc08ab03360b0e2b0c5.jpg)

<span style='background:white'>OneNote的定位是一套用于自由形式的信息获取以及多用户协作工具：</span>

<span style='font-weight:bold;background: white'>1.随处可以记录笔记。</span><span style='background:white'>OneNote的页面如同一块创作画布，可以在页面上任意排版。例如左边是文字，右边插入图片，像在笔记本一样随意地记录思绪。</span>

![image4](31a68d3cf3fd4c6b8432c583c85852b2.jpg)

<span style='font-weight:bold;color:#3E3E3E;background:white'>2.收集页面。</span><span style='color:#3E3E3E;background:white'>作为Office全家桶的一员，完美的整合其他套件</span><span style='color:#B2B2B2;background:white'>（仅限2013版+）</span>«span style='color: \#3E3E3E;background:white'»。«/span»<span style='font-weight:bold;color:#3E3E3E; background:white'>在Office软件里可以任意发送或贴入文件到Onenote，实现预览效果。</span>

![image5](bb27e7717edd43dfb54b901ed6f24af6.jpg)

<span style='background:white'>更棒的是，除了可以直接复制粘贴内容以外，还可以连接其他应用程序。</span>

![image6](ad77ca67aa2c437bb46e040284fa6851.jpg)

<span style='background:white'>①</span><span style='font-weight:bold;background:white'>微信关注公众号 【微软云笔记】</span><span style='background:white'>，在微信里看到的文章保存到微软云笔记，就会把当前的内容一键云同步到【微信保存】分区。</span>

<span style='color:#3E3E3E;background:white'>②</span><span style='font-weight: bold;color:#3E3E3E;background:white'>Chrome扩展-OneNote Clipper</span><span style='color:#B2B2B2;background:white'>（类似于印象笔记·剪藏）</span><span style='color:#3E3E3E;background:white'>，可以一键轻松摘取网页中的内容到OneNote保存。</span>

<span style='font-weight:bold;background: white'>在OneNote，无论是复制或者剪辑内容都会自带网址和出处。</span>

<span style='background:white'>虽然印象也可以记录网址和出处，但同一个页面只能抓取最早储存的那一个网址和出处。相反Onenote，可以</span><span style='font-weight:bold;background:white'>把剪辑的内容的所有出处都集合在一个页面上</span><span style='background:white'>，对于需要经常摘录文档和查找资料的人来说，这太重要了！</span>

![image7](bb9fa32827fb4379b16565aa54924e04.jpg)

<span style='font-weight:bold;color:#3E3E3E;background:white'>3.通过绘图实现手绘效果。</span><span style='color:#3E3E3E;background:white'>搭配手写操作的平板电脑，Onenote可以发挥更强大的绘图功能。除了多种色彩选择，还可以选择不同的笔的种类，笔头的粗细等</span><span style='color:#B2B2B2;background:white'>（会手绘的人感觉最棒了）</span>

![image8](56543b591374487092e87d248be91fd3.jpg)

<span style='font-weight:bold;color:#3E3E3E;background:white'>4.插入音频与视频。</span><span style='color:#3E3E3E;background:white'>对于常常要做课堂或会议记录的珍妮来说，这个功能简直暖心。可以实现边录音和做笔记。还能在笔记里插入视频连接，自动生成播放器</span><span style='color:#B2B2B2;background:white'>（不过仅限YouTube..）</span>

![image9](0b03217e60384a0a926932f4018a3939.jpg)

<span style='font-weight:bold;background: white'>5.实现多人协作。</span><span style='background:white'>可以和其他人一起</span><span style='font-weight:bold;background:white'>同步协同合作文档</span><span style='background:white'>，不需要再反复的文件传送，可以共享整个笔记本，允许编辑或只查看。</span>

![image10](9f704005ed7b4c5c9605a7057823aacb.png)

<span style='background:white'>当内容被共享人编辑后，笔记本中的内容会变绿，被编辑的部分会显示被分享人（编辑者）的名字。</span>

![image11](b3dccf6808fd488588a47b300aaa7ce1.jpg)
@Esor Huang  

<span style='background:white'>还可以分享单个所选页面的查看链接，让别人在浏览器中直接查看而无需打开OneNote。</span>

![image12](14ec237f276d4db6b8bb1a88da53111d.jpg)

**【2】玩转OneNote**‍  

<span style='font-weight:bold;background: white'>还以为，OneNote只是一款简单记录笔记的一款工具。</span>

**==事实上，OneNote这些功能让我对它欲罢不能。==**‍  

<span style='font-weight:bold;background: white'>1.录音关键词定位</span>
<span style='background:white'>我们经常会对会议、分享或者老师上课内容进行录音，方便后期的回顾，如果只是想找其中的一个知识点，往往需要反复的重听录音N遍。（心累）</span>
<span style='background:white'>而OneNote的录音关键词定位功能可以完美解决：</span>

![image13](f784a93654b74706b0f158fb151e0f08.jpg)

<span style='background:white'>① 在录音的时候，一边记录笔记或关键字</span>
<span style='background:white'>② 记录在对应的笔记区，就会自动记录对应关键字时间</span>
<span style='background:white'>③ 点击对应的关键字前的播放键，播放</span>

<span style='font-weight:bold;background: white'>在回听的时候，就可以快速定位写下这个笔记的对应录音时间。</span>

<span style='background:white'>更人性化的是，考虑到打字的时候，会有一点打字的时间和大脑思考的时间。所以，在实际播放音频的时候，时间会稍微提前一点也就是在关键词前面一点点。</span>

<span style='font-weight:bold;background: white'>2.光学字符识别OCR</span>
<span style='color:#3E3E3E;background:white'>Onenote具有光学字符识别OCR功能。</span><span style='color:#B2B2B2;background:white'>（最爱分享的功能，没有之一）</span>
<span style='background:white'>有时会在网上摘取文字，苦于不能复制。于是，只能辛苦码字。</span>

<span style='background:white'>其实，截取图片贴入到Onenote,图片右键【复制图片中文本】，就可以实现图片转文字。</span>
![image14](934bb938e2f04ca38186bf8cf8a3602f.jpg)

<span style='background:white'>而且，图片贴入笔记后，</span><span style='font-weight:bold;background:white'>如果上面有印刷文字，Onenote会自动做文字辨识。</span><span style='background:white'>上面的文字可以通过搜索被搜到。</span>
![image15](a730bff3009d47ffb2f03a19368fc0ee.jpg)
<span style='color:#3E3E3E;background:white'>结合</span><span style='font-weight:bold; color:#3E3E3E;background:white'>Office Lens</span><span style='color:#3E3E3E; background:white'> </span><span style='color:#B2B2B2;background:white'>（类似于印象的全能宝）</span><span style='color:#3E3E3E;background:white'>，效果更佳。它可以直接拍摄图片并导入Onenote，并且可以识别照片中的文字。</span>

![image16](547c8f29d34545a5bd94aff063c2d089.jpg)

<span style='color:#3E3E3E;background:white'>Office Lens，具备一款手机扫描仪该有的功能例如拍摄名片、笔记文件、黑板等，自动调整及裁剪。但是身为微软爸爸的亲儿子，它可以</span><span style='font-weight:bold;color:#3E3E3E;background:white'>直接导出Office常用软件。</span><span style='color:#B2B2B2;background:white'>（厉害了~）</span>

<span style='font-weight:bold;background: white'>3.形状和公式的转换</span>

<span style='background:white'>对于手残党和理工汪，在电脑上做笔记绘图或者是写公式，总会苦恼如何打出来或者画出来。那么，你一定很喜欢下面这个功能。</span>

<span style='color:#3E3E3E;background:white'>①</span><span style='font-weight:bold; color:#3E3E3E'> 转换为形状。</span><span style='color:#3E3E3E;background:white'>Onenote的Ink Shape Recognition（墨水形状识别）功能，能够</span><span style='font-weight:bold;color:#3E3E3E'>自动将手绘的一些图形转换为更规则的形状</span><span style='color:#B2B2B2;background:white'>（好犀利~）</span><span style='color:#3E3E3E; background:white'>。这样，对于绘制流程图、思维导图等图来说更加方便了。</span>
<span style='background:white'>还可以直接选中单独的绘图元素，像图片一样进行任意缩放、分层叠放或旋转。</span>

![image17](34d73443fc2543eb9c2c7a715864cc2a.jpg)

<span style='background:white'>② </span><span style='font-weight:bold;background:white'>将墨迹转换为数学公式。</span><span style='background:white'>只要在绘图工具里使用画笔画出公式，就可以选中公式，【将墨迹转换为数学公式】并在插入墨迹公式框里，进行更正。</span>

![image18](6852dd02970d47aabd51698e7e33bda2.jpg)

<span style='color:#3E3E3E;background:white'>除了可以转换数学公式以外，Office 365版的OneNote</span><span style='color:#B2B2B2;background:white'>（仅限Win10系统）</span><span style='color:#3E3E3E;background:white'>有款逆天的功能：只要在里面</span><span style='font-weight:bold;color:#3E3E3E;background:white'>书写方程式，就可以求解方程式！</span><span style='color:#3E3E3E;background:white'>不仅可以看到解答结果，还可以通过“显示步骤”来看解决方法，天啊！</span>
![image19](0d8b44b3954b4bf0b05b44b99814076f.gif)
<span style='color:#D6D6D6'>（学渣珍妮感动的泪盈满眶...可惜已经毕业了）</span>

<span style='font-weight:bold;background: white'>4.停靠到桌面</span>

<span style='background:white'>做笔记时，尤其多个窗口同时使用时，经常面临空间不够用，需要反复的调整窗口大小。</span>

<span style='background:white'>其实，在Win系统可以通过使用【Win+左右方向键】实现分屏功能。</span>

<span style='background:white'>而OneNote的【停靠到桌面】更为强大。只要应用了这个功能，就会默认停靠在右侧。当打开另外一个窗口的时候，该窗口会自动缩小。</span><span style='font-weight:bold;background:white'>无论怎么移动窗口，onenote都是置于最顶部。</span>
![image20](eb2a6bd81f3b463db9c2bb7d1f532a80.jpg)
<span style='color:#D6D6D6'>@曹将</span>

<span style='font-weight:bold;background: white'>5.保护隐私</span>

<span style='background:white'>身为忠实的大象粉，忍不住吐槽一下印象的密码保护太反人类，居然只能对文字部分进行加密。</span>

![image21](64fbb030ffee49adbad14c962fe2e38b.jpg)

<span style='background:white'>而对比，OneNote的密码保护就略强大。</span><span style='font-weight:bold;background:white'>可以对重要的内容进行设定密码，不用担心被人偷看文件。</span><span style='background:white'>而且，受密码保护的分区是不能够进行搜索的。</span>

<span style='background:white'>好了，这波安利就到这里了。</span>

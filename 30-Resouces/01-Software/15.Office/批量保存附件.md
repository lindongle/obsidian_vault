<th><p>有时候，很多邮件里面带有的附件需要存起来，但是一个个点击存取比较费时间，所以偶作了下面这样一个小macro。都是从这个论坛上学到的，然后自己做了小小的修改，发现真得很好用，和大家分享一下。</p>
<p></p>
<p>1)«span style='font-family: "Microsoft YaHei";color:#444444'»在«/span»“Inbox”«span style='font-family:"Microsoft YaHei"; color:#444444'»里面创建一个文件夹，命名为«/span» “For Download”«span style='font-family:"Microsoft YaHei";color:#444444'»（这个可以更改，但下面代码标成蓝色的地方也要做相应更改）«/span»</p>
<p></p>
<p>2)«span style='font-family: "Microsoft YaHei";color:#444444'»在«/span»D«span style='font-family:"Microsoft YaHei";color:#444444'»盘创建一个文件夹，命名为«/span»“Email Attachment Temp”«span style='font-family:"Microsoft YaHei"; color:#444444'»（这个可以更改，但下面代码标成蓝色的地方也要做相应更改）«/span»</p>
<p></p>
<p>3)打开outlook，按住Ctrl+F11，粘贴如下代码：</p>
<p></p>
<p>Sub Savetheattachment()</p>
<p>  Dim olApp As New Outlook.Application</p>
<p>  Dim nmsName As Outlook.NameSpace</p>
<p>  Dim vItem As Object</p>
<p>  Set nmsName = olApp.GetNamespace("MAPI")</p>
<p>  Set myFolder = nmsName.GetDefaultFolder(olFolderInbox)</p>
<p>  Set fldFolder = myFolder.Folders("For Download")</p>
<p>  </p>
<p>  For Each vItem In fldFolder.Items</p>
<p></p>
<p>   '-----Save Attachment-------</p>
<p>  For Each att In vItem.Attachments</p>
<p>    att.SaveAsFile "D:\Email Attachment Temp\" &amp; att.FileName</p>
<p>  Next</p>
<p>  '------Save Attachment--------</p>
<p>  Next</p>
<p> </p>
<p>  Set fldFolder = Nothing</p>
<p>  Set nmsName = Nothing</p>
<p>End Sub</p>
<p></p>
<p>4) 把需要批量下载附件的email拖到在Inbox里面建立的那个文件夹"For Download"中，运行macro，就能在D盘"Email Attachment Temp"里面下载所有邮件的附件</p></th>

<th><p><span style='color:#444444'>有时候，很多邮件里面带有的附件需要存起来，但是一个个点击存取比较费时间，所以偶作了下面这样一个小macro。都是从这个论坛上学到的，然后自己做了小小的修改，发现真得很好用，和大家分享一下。</span></p>
<p></p>
<p><span style='font-family:Tahoma;color:#444444'>1)</span>«span style='font-family: "Microsoft YaHei";color:#444444'»在«/span»<span style='font-family:Tahoma; color:#444444'>“Inbox”</span>«span style='font-family:"Microsoft YaHei"; color:#444444'»里面创建一个文件夹，命名为«/span»<span style='font-family:Tahoma;color:#444444'> “</span><span style='font-family:Tahoma;color:blue'>For Download</span><span style='font-family:Tahoma;color:#444444'>”</span>«span style='font-family:"Microsoft YaHei";color:#444444'»（这个可以更改，但下面代码标成蓝色的地方也要做相应更改）«/span»</p>
<p></p>
<p><span style='font-family:Tahoma;color:#444444'>2)</span>«span style='font-family: "Microsoft YaHei";color:#444444'»在«/span»<span style='font-family:Tahoma; color:#444444'>D</span>«span style='font-family:"Microsoft YaHei";color:#444444'»盘创建一个文件夹，命名为«/span»<span style='font-family:Tahoma;color:#444444'>“</span><span style='font-family:Tahoma; color:royalblue'>Email Attachment Temp</span><span style='font-family:Tahoma; color:#444444'>”</span>«span style='font-family:"Microsoft YaHei"; color:#444444'»（这个可以更改，但下面代码标成蓝色的地方也要做相应更改）«/span»</p>
<p></p>
<p><span style='color:#444444'>3)打开outlook，按住Ctrl+F11，粘贴如下代码：</span></p>
<p></p>
<p><span style='color:#444444'>Sub Savetheattachment()</span></p>
<p><span style='color:#444444'>  Dim olApp As New Outlook.Application</span></p>
<p><span style='color:#444444'>  Dim nmsName As Outlook.NameSpace</span></p>
<p><span style='color:#444444'>  Dim vItem As Object</span></p>
<p><span style='color:#444444'>  Set nmsName = olApp.GetNamespace("MAPI")</span></p>
<p><span style='color:#444444'>  Set myFolder = nmsName.GetDefaultFolder(olFolderInbox)</span></p>
<p><span style='color:#444444'>  Set fldFolder = myFolder.Folders("</span><span style='color:blue'>For Download</span><span style='color:#444444'>")</span></p>
<p><span style='color:#444444'>  </span></p>
<p><span style='color:#444444'>  For Each vItem In fldFolder.Items</span></p>
<p></p>
<p><span style='color:#444444'>   '-----Save Attachment-------</span></p>
<p><span style='color:#444444'>  For Each att In vItem.Attachments</span></p>
<p><span style='color:#444444'>    att.SaveAsFile "</span><span style='color:blue'>D:\Email Attachment Temp\</span><span style='color:#444444'>" &amp; att.FileName</span></p>
<p><span style='color:#444444'>  Next</span></p>
<p><span style='color:#444444'>  '------Save Attachment--------</span></p>
<p><span style='color:#444444'>  Next</span></p>
<p><span style='color:#444444'> </span></p>
<p><span style='color:#444444'>  Set fldFolder = Nothing</span></p>
<p><span style='color:#444444'>  Set nmsName = Nothing</span></p>
<p><span style='color:#444444'>End Sub</span></p>
<p></p>
<p><span style='color:#444444'>4) 把需要批量下载附件的email拖到在Inbox里面建立的那个文件夹"For Download"中，运行macro，就能在D盘"Email Attachment Temp"里面下载所有邮件的附件</span></p></th>

# <span style='color:#1E4E79'>解决办法，很刚很猛烈。</span>
# <span style='color:#1E4E79'>1、打开Xbrowser.exe之后，点击最上面的工具。</span>
# <span style='color:#1E4E79'>2、点击Xconfig 开始。打开如下界面：</span>
![image1](db4ea4c94ebe4b6faf1675f677d5f727.png)
# <span style='color:#1E4E79'>3、右键点击Default Profile ，选择属性。</span>
# <span style='color:#1E4E79'>4、在打开的界面里面选择高级。在如下界面中可以看到红圈里的XKEYBOARD，本来是打上对勾的，点一下对勾，取消选择这个选项。然后问题解决。</span>
![image2](be15871cb00542929e400960ca9ec1e3.png)

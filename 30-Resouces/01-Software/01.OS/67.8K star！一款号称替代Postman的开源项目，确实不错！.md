大家好，我是开源君！

咱程序员的日常工作里，API 打交道那是家常便饭。可每次调试 API，面对那些杂乱无章的响应数据和复杂的请求格式，真的让人忍不住想 “摔键盘”。Postman是一个广受欢迎的工具，但它并不是免费的，而且有些功能可能过于复杂。

不过别担心，最近开源君挖到了一个超厉害的 “宝藏” 工具 - `Hoppscotch`，它是个开源的 API 开发生态系统，用起来特别顺手，让我们的API开发之路变得轻松又有趣。

![[99-Assets/3d48da8c492d5abb5ccbd246f04aeec7_MD5.png]]

# 项目简介

`Hoppscotch` 是​一个开源的 API 开发工具，定位是 Postman 的开源替代品。它把 API 管理、调试和协作这些功能都整合到了一块儿，为开发者们打造了一个超便利的开发环境，可以帮助开发者轻松地发送 HTTP 请求、调试 API、管理接口文档，还能支持 WebSocket、GraphQL 等多种协议。简单来说，就是一款让你调试 API 更加轻松愉快的工具。

![[99-Assets/7f84016548ca36442fd3285b62007978_MD5.png]]

目前在Github上收获了67.8K star！

![[99-Assets/6cb40cdc1a5dcc036a0f9a9710cf617b_MD5.png]]

# 性能特色

-   轻量级：界面简洁，不占内存，运行流畅。
    
-   多种协议支持：除了 HTTP，还支持 WebSocket、Socket.IO、MQTT、GraphQL 等多种协议。
    
-   功能丰富：支持常见的HTTP方法，如GET、POST、PUT、DELETE，还有不常见的HEAD、CONNECT、TRACE，甚至支持自定义请求方法。
    
-   主题切换：提供多种主题模式，满足不同用户的审美需求。
    
-   PWA 支持：可以安装为 Progressive Web App，离线使用，加载速度快。
    
-   团队协作：支持创建团队、共享集合和成员管理，方便团队协作。
    
-   环境变量：支持无限的环境和变量，方便在不同环境之间切换。

# 项目体验展示

![[99-Assets/031f39196d37f2bad82f347b201701b3_MD5.png]]

使用hoppscotch进行API测试非常简单。你只需要打开hoppscotch应用程序，点击“新建请求”按钮，输入API的URL并选择请求方法，然后在请求头部添加所需的头信息，输入请求的参数，最后点击“发送”按钮即可。hoppscotch会向该API发送请求，并显示响应结果。

![[99-Assets/f95891732d24729d500274c214febcc7_MD5.png]]

![[99-Assets/38687951b97e98481eb2bf999188e451_MD5.png]]

  

WebSocket 调试也很给力，之前用其他工具调试 WebSocket 时，总是需要写额外的代码，现在用 Hoppscotch，只需要简单配置一下，就能实时查看消息。

不过，有时候也会遇到一些小问题，比如某些复杂的请求头格式不支持，但总体来说，体验还是非常不错的。

![[99-Assets/4f067b0893016b006159976a4c7eb52d_MD5.png]]

如果你需要更高级的操作，如设置身份验证、使用环境变量等，也可以在hoppscotch中轻松实现。你可以在hoppscotch的官方文档中找到更多详细的使用说明和功能介绍。

`Hoppscotch`不仅仅是一个API调试工具，更是一个集API管理、调试和协作于一体的开发生态系统。它轻量、快速、功能丰富，不仅支持常见的REST API，还可以处理实时通信和GraphQL请求。对于团队协作和多环境调试，它的各种功能和工具让开发者可以更高效地完成工作。

我觉得，不论你是一个API调试新手，还是一名资深的后端开发者，Hoppscotch都能带给你很好的使用体验。

1.1打开服务器管理器，右键点击角色，选择“添加角色”，在“添加角色向导”窗口左侧面板选择“服务器角色”，然后勾选“Active Directory证书服务”，如下图：

![image1](c119817eea8242f7bf315ba50ad95459.png)
1.2点击下一步，继续点击下一步，在“添加角色向导”窗口选中“证书颁发机构”和“证书颁发机构Web注册”，如下图：
![image2](cdbcbe83979c40128bb19e187e85f5dd.png)

1.3一直点下一步，直到“确认安装选择”，如下图：
![image3](3e5492a0f4344466ba01f5e23634ee2f.png)

1.4然后点击安装，等待安装完成，关闭窗口即可，如下图：
![image4](4b8f5591cd75410aaf0bef4992b607e9.png)

### <span style='color:#5B9BD5'>2创建证书申请</span>
2.1启动IIS管理器，在连接中选择服务器，选中功能视图，选中服务器证书，如下图：

![image5](df02753b93f24963ad23141e4bcec935.png)

2.2双击打开服务器证书，在右侧操作中选择“创建证书申请”，在“可分辨名称属性”窗口中填入相应信息，如下图：
![image6](560edb1993fb410eb03d9b1f9c489051.png)

2.3点击下一步，继续点击下一步，在打开的窗口中，点击“..”，为证书申请文件选择一个位置，如下图：

![image7](b4b6fbddb8074374ac580d76d7679208.png)

![image8](1ea8862664fe4a6285d4de29b7c3ee84.png)
2.4点击完成，在指定位置生成了证书申请文件ca_apply.txt。
### <span style='color:#5B9BD5'>3提交申请、批准申请</span>
3.1在开始-程序-管理工具，打开Certification Authority，如下图：

![image9](7622441a748249568e01e43b8ada2d4e.png)
3.2在打开窗口左侧，选中本机，右键单击，选择“所有任务”下的“提交一个新的申请”，如下图：
![image10](573ce397a78941e78366c4dda7279f50.png)

3.3选择刚生成的证书申请文件，点击打开，如下图：

![image11](7db428705d30484c9009ec1495f35499.png)
3.4点击左侧“挂起的申请”，选中证书申请（申请ID最大的那个），如下图：
![image12](4a2914e1ab754b3cbef3e962db4c279a.png)

3.5在申请上点右键，选择“选择任务”下的“颁发，如下图：
![image13](dd9186054b6349c58409760bb3fa32a0.png)

3.6点击左侧“颁发的申请”，可在右侧列表中看到刚刚颁发完成的证书，如下图：
![image13](dd9186054b6349c58409760bb3fa32a0.png)

3.7双击证书，在弹出打开的“证书”窗口点击“详细信息”标签页，点击“复制到文件”，弹出证书导出向导，如下图：
![image14](61829d165a5b4294bb5a54b7a19da711.png)

3.8点击下一步，继续点击下一步，为证书文件选择导出位置，如下图：
![image15](adadc5e334ca4f5ba3787ecdbc1b5750.jpg)

3.9点击，直到完成，提示“导出成功”，如下图：

![image16](0308a4b19f62487e81f2c778d34abb85.jpg)
### <span style='color:#5B9BD5'>4完成申请</span>
4.1启动IIS管理器，在连接中选择服务器，选中功能视图，点击打开服务器证书，如下图：
![image17](cca548002b074945ad2e93504b4afd1f.jpg)

4.2点击“操作”区域的“完成证书申请”，选择证书文件，输入“好记名称”，如下图：

![image18](bcd3631a51db465fa9ebc9ad697c7241.png)
4.3点击确定，完成证书申请，如下图：

![image19](68af794387614322b53382b9e07fd9f1.png)
### <span style='color:#5B9BD5'>5网站SSL设置</span>
5.1启动IIS管理器，选中网站-Default Web Site,在功能视图的IIS区域下，选择并打开SSL设置，选中“客户证书”下的“忽略”，点击应用，如下图：

![image20](798fd8f44b7b4dc9997164d27ba9b466.png)
5.2选中网站-Default Web Site-CertSrv,在功能视图的IIS区域下，选择并打开SSL设置，选中“客户证书”下的“忽略”，点击应用，如下图：
![image21](db743d0d258e4c7e8f53a03f936f6e79.png)

5.3选中网站-Default Web Site-tmci,在功能视图的IIS区域下，选择并打开SSL设置，选中“要求SSL”，选中“客户证书”下的“忽略”，点击应用，如下图：

![image22](5993427fd83447e9a5c6dc3eeafcdf4b.png)

**前言：**此为搭建共享磁盘的一种方式，并非唯一
**目的：**为安装Oracle RAC准备共享磁盘
操作系统：Windows Server 2012 R2
**准备：**
准备两台服务器，能够通过网络ping通
一台用作磁盘服务器(安装Windows Server 2012，提供iSCSI磁盘服务)
一台用作客户机(安装Windows Server 2012，用于访问磁盘服务器提供的iSCSI磁盘服务）
客户机可以使用多台，当设置多台客户机时，需要在磁盘服务器上增加多个访问服务器
**相关知识：**
iSCSI，SCSI，请自行百度
**术语：**
访问服务器，访问目标，iSCSI目标，客户机，四个词为同一概念，即客户机

**主要步骤如下：**
**一、磁盘服务器上操作**
**1.安装iSCSI服务**
1.1.打开服务器管理器\>\>添加角色和功能
![image1](eaea24e8c6804e7595b21e57afc38279.png)

1.2.基于角色或基于功能的安装
![image2](ab580996d2ab4926b771424ea58c4d6b.png)

1.3.选择安装iSCSI服务的服务器，默认选择本机
![image3](34bb871af4fd41638d517b444d4b244f.png)

1.4.选择iSCSI开头的两个选项和文件服务器
![image4](64beff8310624e7499466d4c97e7a601.png)

1.5.按需要选择功能，或者直接下一步
![image5](1feafef92448439992ad921a536dd61e.png)

1.6.确认后安装
![image6](915a07d1f0e14df38fd46861e2cce845.png)

1.7.安装成功
![image7](d213cdbc967f47b2876ec5d55b896437.png)

**2.创建iSCSI虚拟磁盘**
2.1.打开服务器管理器\>\>文件和存储服务\>\>iSCSI\>\>任务\>\>新建iSCSI虚拟磁盘
![image8](8800fba42fc448dc87001d736bd08ac4.png)

2.2.选择服务器(默认本机），键入自定义路径（用于存放虚拟磁盘文件），也可以使用按卷选择
![image9](6a1aa1aab65440728fba6192c7c90eb3.png)

2.3.填写虚拟磁盘名称，路径中可以看到是作为虚拟磁盘文件名的
![image10](b45b7ce8c5a2439391342951a9c24587.png)

2.4.设置磁盘大小及类型
![image11](ecf1c355e0f346c9ad0c59f488127c7e.png)

2.5.新建iSCSI目标
![image12](6e984d76453746f383e28664f3b01619.png)

2.6.填写目标名称
![image13](2b1b60ed6ff94989b3fedf26db22b861.png)

2.7.访问服务\>\>添加，访问服务器即客户机
这里使用ip的方式设置客户机，其他几种方式可以自己尝试一下，可以设置多个访问服务器
![image14](bf31596c1e2641fd95d05ef726cab31b.png)

2.8.启用身份验证，也可以不启用，直接下一步
![image15](582b01a7dc494c349d9660db664ebc4c.png)

2.9.确认后创建虚拟磁盘
![image16](c866f60dc1f0420d88237548960dba14.png)

2.10.创建成功
![image17](87b6bffae4d44f5eb7cc4dd224c47e1e.png)

**3.访问服务器配置**
3.1.打开服务器管理器\>\>文件和存储服务\>\>iSCSI，右键iSCSI目标，点击属性
在弹出框中可以添加发起程序（即访问服务器，即客户机），也可以启用身份验证
![image18](39f3c376994442158507dc395a40b2aa.png)

![image19](aa84eb60b8944d09ab1bb62306f4b0cd.png)

**二、在客户机上的操作**
**1.连接iSCSI虚拟磁盘**
1.1.打开控制面板
![image20](6636c3050e594a26ae1000b25d832257.png)

1.2.在查看方式为“类别”时，点击系统和安全\>\>管理工具，双击iSCSI发起程序(iSCSI Initiator)
![image21](c7a2ec5dac4248748776b3058243795a.png)

1.3.在目标中输入磁盘服务器的IP地址，点击快速连接（其他连接方式请自己尝试）。
![image22](dc361a05ef63454aa0c3d4e8186a4c03.png)

1.4.连接成功
![image23](67ff29dedec845bcb1283c40dd9d5137.png)

1.5.在iSCSI发起程序 属性中 选择卷和设备选项卡，点击自动配置，将卷列表加入
![image24](1d68a5acbaa6419ab4e13e4d9f784ef2.png)

1.6.打开服务器管理器\>\>文件和存储服务\>\>磁盘，可以看到多了一块iSCSI总线类型的磁盘，右键该磁盘，选择联机
之后就可以像本地磁盘一样管理这个iSCSI虚拟磁盘了
![image25](76913607f0924167a96d32af0edc0208.png)

1.7.右键开始菜单\>\>磁盘管理，也能看到刚加上的磁盘，联机状态时可以右键选择联机
![image26](756d5dea93704d88b0b7fc99aff7f376.png)

**2.开启包含iSCSI的服务，启动类型“自动”，磁盘服务器和客户机上都要开启**
![image27](a0c8f0d70727460cb8a40d00ed6e7dd4.png)

挂载Linux共享：
\[root@PLMResource1 ~\]# mount -t nfs 10.0.1.51:/plmdata/plmdatabackup /plmdata/plmdatabackup
注：挂在10.0.1.51下的/plmdata/plmdatabackup文件夹到本地/plmdata/plmdatabackup文件夹。
挂载windows共享：
已废弃\*\*\*\*mount -t nfs 10.2.1.6:/tcdata_bmideproject_temp /plmdata/plmdatabackup_temp/tcdata_bmideproject_temp

mount -t cifs -o username=infodba,password='Hrytplm!@#2018',uid=500,gid=501 //10.2.1.6/tcdata_bmideproject_temp /plmdata/plmdatabackup_temp/tcdata_bmideproject_temp
---windows共享路径：\\10.2.1.6\tcdata_bmideproject_temp，uid/gid作为挂在共享的所有者给哪个用户哪个组。

开机自动挂在共享：
\[root@PLMResource1 ~\]# vi /etc/fstab
打开的文件中，添加以下内容，保存退出。
//10.2.1.6/tcdata_bmideproject_temp /plmdata/plmdatabackup_temp/tcdata_bmideproject_temp cifs username='hryt\infodba',password='Hrytplm!@#2018',uid=500 0

10.0.1.51:/plmdata/plmdatabackup /plmdata/plmdatabackup nfs defaults 0 0

移除挂载：
umount 挂载到本地的文件夹路径
umount /plmdata/plmdatabackup

查看挂载：
直接输入mount

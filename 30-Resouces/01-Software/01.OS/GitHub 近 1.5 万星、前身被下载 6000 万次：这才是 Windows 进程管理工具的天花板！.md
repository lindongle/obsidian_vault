你有没有遇到过这种情况：想删一个文件，提示"文件被另一个程序占用，无法删除"。

你把所有看得见的程序都关掉了，依然删不了。

折腾了半小时，最后只能重启电脑，祈祷重启之后能删掉。

或者这种情况：你的电脑 CPU 突然莫名其妙飙升到 90%，整台机器变得奇慢无比。打开任务管理器一看，前几名的进程里你全都认识，加起来占用才 20%……剩下那 70%，去哪里了？

或者这种：你安装了一个不太信任的软件，心里总觉得它在后台联网，但任务管理器里看不出来它在做什么。

我遇到过不下 40 次，身边的朋友遇到的次数更多。

问题的根源只有一个：**Windows 自带的任务管理器，从来不把系统真实情况告诉你。**

它只给你看一个经过过滤的、为普通用户简化过的视图：进程名、CPU 占用率、内存用量。

但那些真正有价值的信息——这个进程在联哪个服务器、它锁住了哪些文件、它加载了哪些 DLL、它有哪些隐藏的子线程——任务管理器一概不显示。

这不是能力问题，这是微软刻意的设计选择。

**但有一个工具，从 2008 年起就在做一件事：把任务管理器故意不显示的东西，全部展示给你。**

![[99-Assets/046d623bd3312bb4400fc739163bed76_MD5.png]]

GitHub 上有个叫 **System Informer**（前身是大名鼎鼎的 Process Hacker）的开源工具，目前已经拿到了 **14,900+ Star**，其前身 Process Hacker 的历史下载量超过 **6000 万次**。

这是安全工程师检测恶意软件、开发者调试程序、系统极客掌控 Windows 底层的终极工具。

先说结论：用上它之后，你的 Windows 在你面前将没有任何秘密。

![[99-Assets/505910145a7fe693040020f1b95e59ab_MD5.png]]

打开 **System Informer** 的那一刻，和打开任务管理器的感觉完全不同。

**第一，找到删不掉的文件被谁锁住了——10 秒钟搞定。**

这是让无数人发现它的功能。

当某个文件提示"被占用无法操作"时，打开 **System Informer**，在搜索框里输入这个文件名，它会立刻列出所有持有该文件句柄的进程。

你可以直接在界面里关闭那个句柄——不需要重启，不需要第三方工具，文件立刻可以操作。

以后再也不用为"文件删不掉"苦恼了。

**第二，实时查看每个进程的真实网络连接。**

**System Informer** 有一个"网络"标签，实时显示你电脑上所有程序正在维持的 TCP/UDP 连接：

远程 IP 是什么？连的是哪个国家的服务器？端口号是什么？是哪个进程发起的？

这个功能对那些"总觉得某个软件在后台联网"的用户来说，就是一张明牌——你安装的任何程序，它的网络行为在 **System Informer** 面前都是透明的。

**第三，显示任务管理器看不到的隐藏和可疑进程。**

普通的 Windows 任务管理器会被某些恶意软件欺骗，让自己"消失"在进程列表里。

**System Informer** 使用了内核驱动级别的访问权限，可以绕过这些隐藏技巧，把系统里真正运行的所有东西都显示出来——这是安全研究人员和病毒分析工程师把它视为核心工具的关键原因。

**第四，完整的服务与驱动管理。**

比 Windows 自带的 `services.msc` 更强大：你可以在 **System Informer**里查看、启停、编辑所有 Windows 服务和已加载的驱动程序，包括那些默认不显示的底层内核模块。

具体怎么用？3 步搞定：

1.  去 GitHub 或官网下载 **System Informer** 安装包，无需注册，直接安装（或便携版直接运行）。
    
2.  以管理员权限启动，打开后即可看到比任务管理器丰富得多的进程、网络、服务信息。
    
3.  遇到文件删不掉，用 Ctrl+F 搜索文件名，找到锁定进程，右键关闭句柄，问题立解。
    

没有广告，没有会员，没有任何收费功能。完全开源，MIT 许可证，代码公开透明。

可以直接设置为替代 Windows 默认任务管理器——按 Ctrl+Shift+Esc 就能打开 **System Informer**。

写在最后

回到开头的问题：为什么 Windows 自带的任务管理器要刻意隐藏那么多信息？

因为微软面向的是最广泛的用户群体——大多数人不需要、也不想知道系统底层在发生什么，显示太多细节只会让他们感到困惑和恐惧。

但对我们这些想要真正掌控自己电脑的人来说，那些被隐藏的信息，恰恰是最有价值的。

**System Informer** 告诉我们：**一台电脑到底在做什么，你有权利知道全部真相，而不只是被允许看到的那部分。**

如果你身边也有朋友是 Windows 折腾党、对系统安全敏感的用户，或者正被"文件删不掉"这种问题折腾，把这篇分享给他，这个工具能帮他从根本上拿回对自己电脑的控制权。

【需求分析】：如果总是用FTP每次都得打开FTP软件，而且有时还会超时，并且存在代码冲突的问题，所以使用SVN替代FTP是个很不错的选择  

【注意事项】：在使用此功能之前先确保的你的本地客户端和服务器端的版本不能相差太大，否则可能会提示客户端版本太旧等问题  

【具体细节】：至于svn的安装和部署，这里就不赘述了，这里主要讲述怎么实现本地svn提交后服务器项目代码自动更新的问题  

【实现细节】：在你服务器端项目仓促下里面有一个hooks文件，在这个文件夹里面新创建一个bat文件，文件名自己命名为post-commit.bat(注意后缀是.bat)，这个bat文件里面写入以下内容  

1.  @echo off
2.  set REPOS="%1"
3.  set TXN="%2"
4.  "D:/svn/server/bin/svn.exe(这个就是你svn安装的目录，你参考自己的具体目录)" update "D:/phpStudy/WWW/edu(这个就是你网站项目的目录，你参考自己的具体目录)" --quiet --username 用户名("用户名"换成你svn配置好的用户名) --password 密码("密码"换成你svn配置好的密码)

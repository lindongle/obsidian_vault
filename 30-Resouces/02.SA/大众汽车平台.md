## <span style='color:#2E75B5'>大众汽车平台 </span>
<span style='color:#1A1A1A'>**大众汽车的平台化简介**</span>
<span style='color:#1A1A1A'>**●什么是平台？**</span>
<span style='color:#1A1A1A'>一款车的头部骨架的基础设计，也就是前舱壁（驾驶舱与机器仓的隔板）前的部分，包括转向机构、前悬架和前车轴，他们的相对位置一经确定不可更改。而舱壁之后的部分则可因设计而改变，如拉长轴距、展宽轮距、变化后桥悬挂方式等。**说白了就是利于大规模生产，降低汽车的制造成本。**</span>
![image1](87300667ec8e4590be9044f52cebdde6.jpg)
<span style='color:#1A1A1A'>世界上第一个轿车平台在德国大众诞生，大众公司通过平台战略的实施，整合了产品系列，大大降低了成本，同时提高了产品的竞争力，加快了新产品推出的速度，这使德国大众取得了巨大的成功。 而大众对于自己的平台命名有着独特的解释，大众现在所采用的PQ平台的含义：</span>
<span style='color:#1A1A1A'>“PQ”是平台号;</span>
<span style='color:#1A1A1A'>“P”表示平台（也有说代表“前轮驱动”）；</span>
<span style='color:#1A1A1A'>“Q”代表发动机横置（纵置的表示是“L”）；</span>
<span style='color:#1A1A1A'>第一位数字“2”代表A0级车,“3”代表A级车,“4”代表B级车；</span>
<span style='color:#1A1A1A'>第二位数字是代表第几代平台。</span>
<span style='color:#1A1A1A'>**例如**，PQ24是大众A0级第4代平台，PQ25是大众第五代A0级车平台；同理，PQ34以及PQ35分表大众A级车的第4代和第5代平台，PQ45和PQ46则分表代表大众第5代和第6代B级车平台。</span>
<span style='color:#1A1A1A'>由此可以看出，后面的第二位数字越高，平台越先进。</span>
<span style='color:#1A1A1A'>目前中国国内南北大众沿用的生产平台有：</span>
<span style='color:#1A1A1A'>PQ24： POLO（上海大众）</span>
<span style='color:#1A1A1A'>PQ24平台是大众比较老的平台之一，诞生在该平台的Polo也是有年头的车型了，在10万元的小车市场中Polo的保有量比较高，也成为品质车的代言词。PQ24平台的Polo值得骄傲的是其车身激光焊接技术和缝隙注腊技术，在2002年上市之初就已经应用，而直到如今该技术依然领先。</span>
<span style='color:#1A1A1A'>PQ25： 新POLO（上海大众）、晶锐（上海大众斯柯达）</span>
<span style='color:#1A1A1A'>PQ25平台是大众专为生产小型车而开发的全新平台，在这个平台诞生的车型主要有斯柯达Fabia晶锐以及新POLO和奥迪A1。法比亚采用大众最新的PQ25底盘，最先投入中国市场的法比亚将装配大众的1.6升EA111发动机，这是一款大家很熟悉的发动机了，其最大功率77/5600kW/rpm，扭力达到155/3800N·m/rpm。</span>
![image2](a3b5ae68be2f4a12ae47699db78ead3e.jpg)
<span style='color:#1A1A1A'>PQ32： 桑塔纳、捷达（这些都是大众20多年前的淘汰生产线）</span>
<span style='color:#1A1A1A'>PQ34： 朗逸（上海大众）、老宝来（一汽大众，已停产）、新宝来（一汽大众）</span>
<span style='color:#1A1A1A'>PQ35： 明锐（上海大众斯柯达）、途观（上海大众）、途安（上海大众）、开迪（一汽大众）、速腾（一汽大众）、高尔夫6（一汽大众）</span>
<span style='color:#1A1A1A'>PQ35是在PQ34平台的基础上进化而来的。它具有4轮独立悬挂，也就是前麦弗逊后四连杆系统，在提高操控性的同时有效提升驾驶乘坐的舒适性和平顺性。极大的衰减了振动的传递，延长了车辆的使用寿命。另外，PQ35平台还采用了激光无缝焊接技术、双面镀锌高强度钢板、Can-bus全车信息控制网络和全车多道涂装工艺等技术。目前在国内生产的大众速腾、开迪、途安、斯柯达明锐以及进口的奥迪TT、A3都是来自PQ35平台。目前产自PQ35平台的车型主要有速腾、途安、开迪、斯柯达明锐，第六代高尔夫也将出自这一平台。</span>
<span style='color:#1A1A1A'>PQ45： 帕萨特B5、老领域、新领域（都是上海大众基于PQ45平台的产品）</span>
<span style='color:#1A1A1A'>PQ45平台迄今为止已经有10余年的历史了，从技术上讲PQ45平台与其他新的中型车有着一定的差距。虽然大众产自大众先进平台PQ46的迈腾在性能上高于领驭，但是销量上却不及领驭的一半，这也说明了领驭的优势是很大的，并不一定先进技术就能得到好的回报。</span>
<span style='color:#1A1A1A'>PQ46: 昊锐（上海大众斯柯达）、迈腾（一汽大众）、新帕萨特</span>
<span style='color:#1A1A1A'>PQ46平台是生产中高级车的平台，在同级别车中首先采用全球同步先进的底盘技术。前优化麦弗逊、后多连杆独立悬挂。四轮独立悬架设计，后多连杆加横向稳定杆的独立悬架。PQ46平台的特点主要体现在运动性能更加卓越，可以提供更高的驾驶时速。更“软”的悬架系统、更轻便的电动助力转向系统、电子驻车系统的应用令驾驶舒适性更加完美。此外，PQ46平台令主动安全性表现更加优异。   代表车型迈腾诞生于大众B级车最先进的PQ46平台，采用很多C级车装备，如EPB电子停车制动系统、AutoHold功能等。迈腾外形动感而流畅，车身整体工艺给人印象深刻，包括焊接、钣金和喷漆在内一系列工艺的水平在国产同级别车型中处于领先地位。定位于商务与运动市场的迈腾在整体工艺上高于帕萨特领驭。</span>
<span style='color:#1A1A1A'>**目前大众的PQ平台正在向MQB平台转变**</span>
<span style='color:#1A1A1A'>MQB平台是大众提出的新一代造车理念，通过大量的数据模块支持来完成对车辆的设计。经过MQB平台整合之后，未来大众的车型平台将由现在的PQ2、PQ3和PQ4整合为一个统一的MQB平台，该平台上将诞生A0级、A级、B级甚至A00级的车辆。就紧凑型而言，大众将推出奥迪A3、高尔夫7代、途观2代以及新明锐。</span>
![image3](d501ed7758aa40c8b02f7178a0abf2ec.jpg)

<span style='color:#1A1A1A'>**● 什么是MQB平台？其特点是什么？**</span>
![image4](ea0a428878e9467fac7eb03fad300128.jpg)

<span style='color:#1A1A1A'>　　MQB属于大众汽车未来模块化平台之一，用于开发小型至中型轿车，覆盖大众、奥迪、斯柯达和西亚特等多个品牌。该平台的发动机采用横向前置布局，在此基础上可调整轮距、轴距和悬挂，开发出不同车型。不同车型可共线生产，从而大幅提高了生产灵活性并缩减了成本。</span>
![image5](bfbcf539cf1b4f3ab98ddc2875b1c55a.jpg)
<span style='color:#1A1A1A'>**● MQB平台将会生产什么样的车型？**</span>
<span style='color:#1A1A1A'>　　大众第一款使用MQB平台技术打造的车型将是新奥迪A3，已于3月份的日内瓦车展上发布。</span>
![image6](2024eda69c894bcbae7425c2fd785f45.jpg)
<span style='color:#1A1A1A'>　　而大众目前横置平台的所有小型、紧凑和中型车，诸如POLO、新甲壳虫、捷达、帕萨特等，新一代型号均将以MQB平台作为基础。</span>
<span style='color:#1A1A1A'>**● MQB平台搭载的动力系统一览：**</span>
<span style='color:#1A1A1A'>　　MQB平台搭载的动力系统包括三大种类：1.传统汽柴油动力系统、2.电动系统、3.非传统动力系统。</span>
![image7](f2916fcf58f24528a41111e8f750c63b.jpg)
<span style='color:#1A1A1A'>**总结：**加强模块通用性是MQB平台的主要目的，这将使得车辆设计成本大为降低，使得最终产品价格更低，受惠的还是我们消费者。</span>

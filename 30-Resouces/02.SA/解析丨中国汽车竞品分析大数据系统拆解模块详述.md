## <span style='color:#2E75B5'>解析丨中国汽车竞品分析大数据系统拆解模块详述 </span>
<span style='background:white'>作为竞品车对标分析数据中的重要组成部分，拆解数据对于整车深度解析有着重要的作用。在将对标车拆解至均质材料的过程中，对标分析人员可以从中获得对标车的整车及零部件尺寸、装配工艺、整车布置方案、零部件结构、用材等信息。这些拆解数据贯穿整车、系统、零部件多个层级，数据类型涵盖表格、图片、点云、系统等多种类型。同一数据文件具有类型和层级等多种属性使得数据不易归类整理，从而也带来了一系列的数据存储、使用等诸多问题。日前，数据资源中心开发的中国汽车竞品分析大数据系统已完成了拆解模块的开发工作，并已对拆解数据的存储、管理及应用等提出了整体解决方案。下面，我们会以左前门车门逻辑总成为例，向大家对中国竞品系统拆解模块的主要功能进行展示。</span>

<span style='font-weight:bold;background:white'>拆解模块首页</span>

![image1](c7b64a8c8d3a4f0babc36648a2318498.jpg)

<span style='background:white'>拆解模块首页展示有车型信息，通过点击对应车型的图片会进入到车辆的拆解信息展示界面。在选择车型时，用户可以直接在右侧的列表中选取，也可以在左侧的检索栏和车辆结构树中对车辆信息进行筛选。在拆解模块中也可以对不同车辆间的信息进行对比。</span>

<span style='background:white'>（1）整车-系统-零部件的三级数据展示方案</span>
<span style='background:white'>拆解数据以结构树的形式按级别进行存储，不同级别所对应的数据类型也有所区别，以途观L为例，其各级别所展示的数据分别如下所示：</span>
<span style='background:white'>整车级别：</span>

![image2](08a99332f98c4f22ae3d52712981ac39.jpg)

<span style='background:white'>整车级别的数据在结构树的【概览】节点中进行展示，展示的信息主要有车辆生产企业、型号、上市时间、重量、尺寸等基本信息，车身外观图片，性能试验文档以及特征参数。</span>

<span style='font-weight:bold;background:white'>系统级别</span>

![image3](4448539a7f0743db8442b5f924856660.jpg)

![image4](62e1648b474f457aae53fd9e8d323b41.jpg)

![image5](4923906f57c14363b5a38f448ad95b72.jpg)

<span style='background:white'>系统级别零部件对应结构树中的一级、二级节点，一般为车辆的分总成。除概览内的基本信息外，系统级别部件展示的数据还有拆解过程记录及外观等图片、拆解过程记录报告等文档、系统爆炸图、零部件清单以及分析图表等。其中，系统爆炸图除可以展示系统内的装配关系外，还可以展示零部件的概览信息（鼠标悬停后展示），点击对应零部件的图片后，还可跳转到对应零部件的信息展示节点。</span>

<span style='font-weight:bold;background:white'>零部件级别</span>

![image6](60419e1ac2aa4a758baffe8b377bc963.jpg)

<span style='background:white'>零部件级别一般为结构树中的最末节点，展示的信息主要为零部件的重量、材料、尺寸等基本信息以及八角度外观图片。</span>

<span style='background:white'>（2） 针对同类型数据的车辆对比方案</span>

![image7](68bc4e9404cb45d7975906b4bc65610e.jpg)

<span style='background:white'>在拆解模块首页点击【对比分析】按钮并选择需要对比的车型信息后，会进入到车型对比界面。在该界面中，可以从【数据】、【数据分析】、【重量】、【爆炸图】等四个维度对信息进行分类对比。另外，在对比过程中，也可通过点击左侧的结构树或搜索等方式，对数据进行快速定位。</span>
<span style='background:white'>系统在设计开发之初，便采用了数据分类存储方案，图片、文本、表格、爆炸图等不同类型的数据均采用不同的服务器进行存储。这一方案在提高系统使用效率的同时，也大大提高了系统的查询效率。同时，系统也采用柔性化设计方案，系统内的展示信息及展示结构均可根据用户需求自行定义。</span>
<span style='background:white'>数据资源中心下一步将开展总布置模块及新能源模块的开发及测试工作，相关开发成果及开发进度将会实时发布，敬请关注！（文/工程数据部 于书宇）</span>

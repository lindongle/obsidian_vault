**一、核心组织与现状总览**
1.  **组织架构**
    1.  标准化：独立于研发、品质管理部，4 名专职 + 各产线研发兼职工程师，周老师牵头
    2.  IT：流程数字化部 10 + 人，硬件 / 网络 1.5 人，正筹备 PLM 立项
    3.  研发：3C、半导体、汽车电子三大业务，订单驱动非标定制为主
    4.  管理层：罗总负责数字化，要求 12.31 上线，分阶段落地
2.  **系统现状**
    1.  在用：金蝶云星空、SRM、OA、WMS、MDM、IPGUARD 加密、SVN / 共享盘
    2.  设计工具：SW、EPLAN、AutoCAD、DXP，SW 版本不统一
    3.  痛点：系统分散无集成、文档散存个人电脑、非标重复设计严重、流程依赖线下 / Excel / 企业微信
3.  **规模**：300 + 设计作者，400 + 客户，多为非标订单，BOM 行数几十～1000+
**二、各部门关键需求与痛点**
**（一）标准化部（核心管控诉求）**
1.  **管控对象**
    1.  CBB 模块库、优选 / 限用 / 禁用物料、选型规范、技术标准 / 编码规则、设计模板、图纸文档
    2.  光机电软标准产品、标准模块台账、设计规范、物料优选库（MDM 支撑）
2.  **现有机制**
    1.  专职分工：体系规划、机械模块化、电气模块化、监督检查、体系文件审核
    2.  每周标准化会议：同步 CBB 执行、设计问题、生产 / 客户端反馈
    3.  编码：图号（隶属编号）+ 物料号（分类 + 流水）分离
3.  **痛点与期望**
    1.  物料选用范围管控、3D/2D 图纸规范化、研发文档失控问题
    2.  BOM 快速生成指导采购 / 生产、CE 认证统一管理
    3.  设计审查分散，缺乏系统硬管控；工艺数据库参数化配置
    4.  规范落地不到位、变更优化滞后、下游问题反馈闭环难
**（二）IT 部（系统落地支撑）**
1.  **资源与部署**
    1.  服务器部署华中激光，苏州 / 哈尔滨中心，本地无异地规划
    2.  内外网隔离、虚拟化平台、无域控、IPGUARD 加密
2.  **系统规划**
    1.  PLM 立项筹备，计划与金蝶、MDM、OA、SRM 集成
    2.  4 月切换钉钉，现有系统割裂，流程未线上化
3.  **诉求**
    1.  PLM 与设计工具、ERP、MDM 深度集成
    2.  研发交付周期缩短，流程数字化、权限与版本可控
**（三）研发部（业务执行层痛点最突出）**
1.  **研发模式**
    1.  订单驱动：标改 1 天内、定制 7-10 天，边设计边生产三边模式
    2.  常规订单不立项，共享文件夹管理，结构工程师统筹
    3.  BOM 靠 Excel 整合导入 ERP，图纸存共享盘，变更手动版本号
2.  **核心痛点**
    1.  数据散存个人电脑，跨部门重复设计严重
    2.  物料优选依赖人工，无库存联动推荐
    3.  重复设计无法快速查询、物料替代管理缺失
    4.  工控机等通用物料仅体现规格，无编码联动
    5.  变更需考虑在途 / 库存，流程希望简化高效
3.  **期望**
    1.  设计时可查库存优选物料、快速查重设计
    2.  物料替代、BOM 自动生成、图纸版本与变更管控
**（四）高层决策诉求**
1.  数字化转型迫切，先夯实基础数据与流程
2.  非标业务场景拆解标准化，构建体系能力
3.  咨询 + 流程梳理 + 培训 + 分阶段实施
4.  第一阶段后评估，整体升级扩展，12.31 完成上线
**三、PLM + 标准化建设核心解决方案（落地导向）**
**1. 基础层：统一数据源与编码体系**
- 固化**图号 + 物料号**双编码规则，PLM 与 MDM 主数据联动
- 建立标准件 / 通用物料库，优选 / 限用 / 禁用在设计端强制管控
- 统一 SW 等设计工具模板，内嵌标准化规范，强制调用
**2. 模块层：CBB 库与标准化场景沉淀**
- 搭建光机电软 CBB 标准模块库，建立台账与验证机制
- 非标订单拆解为**标准场景 + 定制部分**，提升复用率≥30%
- 知识库统一迁入 PLM，替代 SVN / 共享盘，实现权限与版本管理
**3. 流程层：端到端线上化**
- 售前→方案评审→设计→BOM→变更→发放全流程线上化
- 标改 / 定制订单差异化流程，简化审批，保留高效特性
- 设计变更联动库存 / 在途查询，变更单与 BOM / 图纸版本绑定
**4. 系统集成层**
- PLM ↔ MDM：物料主数据、优选库同步
- PLM ↔ 金蝶 ERP：BOM 一键下发、备货 / 采购 / 生产数据互通
- PLM ↔ SRM/OA/ 钉钉：流程审批、消息推送统一
- PLM 与 SW/EPLAN/CAD 深度集成，设计直接检入检出
**5. 管控与赋能层**
- 设计审查系统化，文档完整性 / 合规性自动检查
- CE 认证、工艺参数库配置化管理
- 设计查重、物料替代、库存优选推荐，减少重复设计
- 标准化会议议题线上沉淀，问题闭环跟踪
**四、实施路径（匹配 12.31 上线目标）**
1.  **第一阶段（奠基）**
    1.  需求确认 + 流程梳理 + 标准化体系优化
    2.  物料 / 编码 / CBB 基础库搭建、系统部署与集成方案
2.  **第二阶段（核心上线）**
    1.  PLM 上线：文档 / 图纸 / 版本 / BOM / 变更管理
    2.  设计工具集成、优选物料管控、基础流程跑通
3.  **第三阶段（优化提升）**
    1.  CBB 深化应用、工艺库、CE 认证管理
    2.  报表分析、用户培训、体系固化与迭代

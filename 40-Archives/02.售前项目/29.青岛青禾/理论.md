<span style='color:#191B1F'>BOM：</span>
<span style='background:white'>草坪（规格尺寸，草丝长度）</span>
<span style='font-family:-apple-system;background:white'>基布（尼龙</span>«span style='font-family:"Microsoft YaHei";background:white'»织物）«/span»
<span style='background:white'>草丝</span>
<span style='color:#191B1F'>PP/PE或色母</span>
<span style='background:white'>色母（绿色）</span>
<span style='color:#191B1F'>添加剂（阻燃剂/防腐剂/防滑剂等）</span>
<span style='background:white'>工艺：</span>
<span style='background:white'>第一步：原料拉丝</span>
<span style='color:#191B1F;background:white'>准备合成草丝纤维的各种原料，原料是主要有聚乙烯和聚丙烯，将各种</span><span style='color:#FA0000;background:white'>原料和环保型绿色色母</span>«span style='color: \#191B1F;background:white'»按照配比放入热熔机，融化混合后，通过喷丝板拉成草丝。«/span»
<span style='background:white'>第二步：捻线合股</span>
<span style='background:white'>将生产出的草丝通过加捻机，按照具体的工艺和比例进行编织，形成一定规格的草片。</span>
<span style='background:white'>第三步：编制簇绒</span>
<span style='background:white'>将加工完成的草丝，按照草丝长度，草丝密度等定制需求，通过簇绒机的一字走针或Z字走针编织至底布之上，制成人造草坪。</span>
<span style='background:white'>第四步：淋涂背胶</span>
<span style='background:white'>在人造草坪背面均匀的图上胶水，把草丝更好的固定在底布之上，减少草丝脱落。</span>
<span style='background:white'>第五步：高温烘箱烘干</span>
<span style='background:white'>将涂胶后的草坪背面朝上，放入烘箱内，设置好烘箱温度，对草坪进行烘干，使草坪上的胶水在高温下快速干燥，从而固定人造草坪。</span>
<span style='background:white'>第六步：制作排水孔</span>
<span style='background:white'>首先使用测量工具确定好排水孔的位置，再使用切割机在人造草坪背面切割出圆形或方形的小孔，方便人造草坪排水。</span>
<span style='background:white'>第七步：打卷包装</span>
<span style='background:white'>按照产品要求，将人造草坪裁剪拼装，放入包装袋，整理封口。</span>
<span style='color:#191B1F'></span>
<span style='background:white'>设备工装：</span>
<span style='background:white'>拉丝机，簇绒机和背胶机，烘干机</span>

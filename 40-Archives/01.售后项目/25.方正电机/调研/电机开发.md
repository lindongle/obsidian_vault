电机开发
2023年3月3日
8:59
1.  组织架构：
    1.  电机开发（电磁相关设计，定转子、旋变设计、信号线、部分辅料）
        1.  结构（仿真）
            1.  铁芯、绝缘、接线端子、信号线
        2.  电磁设计（转子里面磁钢，定转子绕组的出图由结构完成）
        3.  电机产品系统与应用（TPM）：
            1.  项目对接；
            2.  需求的接收及设计输出；
        4.  NVH：
            1.  NVH仿真；
            2.  测试报告；
        5.  实验中心：
            1.  实验需求；
            2.  实验报告反馈；
    2.  设计开发（机械结构）
        1.  应用：应用型项目
        2.  结构：（包装设计在采购部门的物流组）
            1.  B组：所有的轴、轴承、齿轮
            2.  A组：剩余所有，小总成，部分项目转子总成的搭建；
            3.  定子总成的搭建，单独定子或转子项目由电机开发部；
            4.  辅料整体总成搭建，但部分辅料从电机开发部获取，定额给出设计量，工艺验证后调整更新。
            5.  **讨论确认未来定转子组件总成图纸的搭建由哪个部门？目前不同项目不确认交叉设计；**
        3.  零部件设计：未来预留，减速器设计；
2.  需求管理：
    1.  来源：
        1.  客户需求/公司规划-\>领导确定大方向-\>项目经理-\>部门内部应用系统组；
    2.  类别：
        1.  按零部件去分工；
    3.  输入：
        1.  客户SOR+偏差项分析；
        2.  线下评审，会议及邮件下发；
        3.  需求确认后，项目启动会议，确定参数需求，确定分工；
    4.  优先级：
        1.  无
    5.  偏差：
        1.  无统一模板，直接调整；
        2.  需求变更，新需求流程一致；
    6.  痛点：
        1.  客户需求比较随意，没有严格的控制流程；
        2.  需求变更没有追踪和传递；
        3.  缺少统计分析；
    7.  待收集：
        1.  梳理需求结构化BOM模板；
        2.  梳理需求的审批流程及变更流程（可按设计阶段区分）；
3.  流程管理：
    1.  A样：完成需求参数后及性能功能测试通过后开始评审，评审后启动B样；
    2.  B样评审：B样开始，开模，结束后做OTS认证（含外部PRT），认证后做C样；
    3.  C样结束开始量产；
    4.  OTS结束后开发移交生产；
    5.  PPAP辅助支持；
    6.  项目SOP+6结束；
4.  文档管理：
    1.  公盘管理；
    2.  编码：
        1.  ![image1](ec7c4bc32636490992ad20d5b3742ed2.png)
        2.  DS(文档类型)+3301（物料组后四位）+2位流水，未来可使用纯流水；
        3.  物料编码及图纸新编码规则，尚未启用，需要与下游讨论切换与否；
    3.  梳理各个交付物模板及待优化的模板，结合其他企业模板进行优化分析，放入公共知识库-模板库；
    4.  梳理名称库及知识推送关系；
    5.  梳理公共知识库的结构（提供样例）
5.  物料及BOM管理：
    1.  物料的申请：未来增加物料号审批流程；
    2.  存在替代件，多供应商（旋变模块，可能模型不同，但是接口相同，同订单通用）。两家供应商共存时区分两个号；
    3.  无带料外协；
    4.  供应商交互，A样阶段邮件交互，B样及后续发正式纸质受控图纸；
    5.  痛点：
        1.  不同供应商零部件，出不同的产品BOM；
        2.  E/P分开；
        3.  按项目规划权限；
        4.  Creo/NX
        5.  Caxa，线束及部分螺钉的二维模板，二维模板一致；
        6.  标通件：正在梳理，不太根据客户需求不会调整的件；
        7.  版本规则，不再使用当前版本AV1.0，使用01…99
        8.  提供一套三维及二维图纸；
        9.  梳理电子签字，是否全签字，签字图章或水印，包括状态章（A/B/C样）
6.  变更管理

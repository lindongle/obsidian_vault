10. 修改数据库表（注意根据实际情况，几个volme节点的节点名称及路径处理）
update PIMANVOLUME set pnode_name='syixinf12.dosea.local' where pvolume_name='wuxi_localvolume';
update PIMANVOLUME set pnode_name='SYIXTST03.dosea.local' where pvolume_name='volume';
update PIMANVOLUME set pwnt_path_name='E:\Siemens\volume' where pvolume_name='volume';

    2.  修改导出的xml文件，将里面服务器名（TCQAS）均改为SYIXTST03.dosea.local

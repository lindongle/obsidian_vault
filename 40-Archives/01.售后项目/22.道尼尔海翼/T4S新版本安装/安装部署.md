1.  介质准备：
    1.  Active_Integration_Gateway_22.2.2_tc14_win64
    2.  DeploymentCenter_14.3.0.3.zip
    3.  原T4S配置文件
    4.  Vc++运行库
2.  部署中心安装：
    1.  管理员身份运行cmd，cd /d D:\Media\tc14\DeploymentCenter_14.3.0.3\deployment_center
deployment_center.bat -install -serverDir=D:\Siemens\deployment_center\server -serverPort=9090 -repoDir=D:\DC_REPO -repoPort=9595 -user=infodba -password=infodba -serviceName=DC_Service
2.  确认DC_SERVICE和RepositoryService服务已启动；
3.  安装AIG：
    1.  将AIG介质放到software文件夹中；
![image1](73fa5ca3bbbe4208a2b229346c6575d6.png)
2.  登陆部署中心后会看到自动创建了环境；
<http://localhost:9090/deploymentcenter/>
-user=infodba -password=infodba（用户/密码为上面脚本中的信息）
![image2](9045f400f74b410d8bbe7d43f922a850.png)
3.  选择环境-新建
注：如果软件中没有出来放的介质，重启下RepositoryService服务；
4.  切换到概述，修改环境名称；
5.  勾选介质

![image15](4b9001f2da314cf7954021c4b40a12ac.png)
12. 管理员身份运行cmd
CD /D D:\DC_REPO\deploy_scripts\T4S22\install\20230926101952CST\deploy_SYIXTST04.DOSEA.LOCAL
SET JRE_HOME=D:\Java\jdk
deploy.bat -dcusername=dcadmin -dcpassword=infodba -softwareLocation=D:\Siemens\DeploymentCenter\repository\software
13. 安装： The Microsoft Visual C++ Redistributable for Visual Studio 2015, 2017 and 2019
is required；[Latest supported Visual C++ Redistributable downloads \| Microsoft Learn](https://learn.microsoft.com/en-US/cpp/windows/latest-supported-vc-redist?view=msvc-170)，安装后根据提示重启服务器；

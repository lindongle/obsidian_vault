    1.  pom_schema_SOPFDB01.dosea.local_tc10prod-\>pom_schema_TCQAS_TCQAS
    2.  populate_new_db_SOPFDB01.dosea.local_tc10prod_V10000.1-\>populate_new_db_TCQAS_TCQAS_V10000
    3.  populate_new_db_SOPFDB01.dosea.local_tc10prod_V10000.1.USE-\>populate_new_db_TCQAS_TCQAS_V10000.1.USE

5.  还原数据库
    1.  删除原数据库，手动/用脚本？
    2.  附加数据库

4.  停止tc服务器，进入mssql，选择TCQAS，右键-重命名为TCQAS-OOTB，将tc10prod重命名为TCQAS。
3.  修改卷节点（host）
    1.  找到表PIMANVOLUME，将pnode_name列改为TCQAS
    2.  ![image5](9f0dae6111154b62854f60ae3d5fb8f0.png)
6.  install -regen_schema_file infodba infodba dba
7.  导出首选项修改Fms_BootStrap_Urls等带有生产环境host的地方均替换，导入首选项；(如果无法导出，可以在tc_profilevar.bat中直接设置首选项)
![image6](407ba9168d3f4e5481b0d6850515890b.png)
1.  启动fsc服务，导出首选项:preferences_manager -u=infodba -p=infodba -g=dba -mode=export -out_file=D:\tc_pre.xml -scope=site
2.  修改导出的xml文件，将里面服务器名（SOPFAP02）均改为TCQAS
3.  ![image7](485e070e64994c4e9d612c0d2220b7ad.png)
4.  导入首选项（修改后的文件）：
preferences_manager -u=infodba -p=infodba -g=dba -mode=import -file=D:\tc_pre.xml -scope=site -action=override
8.  修改FSC配置文件
    1.  backup_xmlinfo -u=infodba -p=infodba -g=dba
    2.  根据导出的文件，修改fms_master文件，重启fsc服务
    3.  ![image8](686c2392e4f74188b5119f09c21f71e2.png)
9.  更新Schema
    1.  install -regen_schema_file infodba infodba dba
10. 执行后处理
    1.  检查索引，index_verifier
    2.  verify_tasks -u=infodba -p=infodba -g=dba
11. 停用license：update dbo.PPOM_USER set pstatus=1 where puser_id !='infodba'
12. 登录tc验证
13. 部署BMIDE

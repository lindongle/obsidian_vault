<span style='color:black'>**典型一级路线**</span>
<span style='color:black'>**一、工艺路线手动填写原则**</span>
<span style='color:black'>**零件：**</span>
<span style='color:black'>1、下料—预制（厂内预制散件下料，如回油集块Q345D方管）</span>
<span style='color:black'>2、下料—铆焊（铆焊研配需要焊接的下料件，如高压管汇Q345D材质支架）</span>
<span style='color:black'>3、下料—铆焊—涂装（铆焊研配无需焊接的下料件，如Q345D材质安装支架）</span>
<span style='color:black'>4、下料—涂装（装配需要的下料散件、外协加工需提前底漆喷涂零件）</span>
<span style='color:black'>5、下料—外协—仓库—下料—预制（下料后需提外协，回司后转序预制焊接，如橇架的公母耳板）</span>
<span style='color:black'>6、下料—装配（无需研配的特殊材质两件，如侧防护）</span>
<span style='color:black'>**焊接件：**</span>
<span style='color:black'>1、预制—铆焊（厂内自制焊接件，铆焊研配后焊接到设备上，如高压管汇支架）</span>
<span style='color:black'>2、预制—涂装（无需研配的自制焊接件、预制后需喷涂底漆外协加工的部件）</span>
<span style='color:black'>3、预制—铆焊—涂装（厂内自制焊接件，铆焊研配后无需焊接，需转序涂装，如回油集块）</span>
<span style='color:black'>4、预制—铆焊—装配（厂内自制焊接件，铆焊研配后无需焊接及喷涂，转序总装，如燃油箱吸回油管汇）</span>
<span style='color:black'>5、预制—外协—仓库—预制(厂内预制部件提外协加工，回司后预制环节进行焊接，如认证项目橇架的吊耳)</span>
<span style='color:black'>6、预制—外协—仓库—预制—铆焊—涂装（厂内预制部件提外协加工后转序铆焊研配，研配后无需焊接转序涂装喷涂，如盘式制动器支架）</span>
<span style='color:black'>**预装件**</span>
<span style='color:black'>1、 预装-装配（预装后转序装配的预装件，如下灰阀、高能混合器）</span>
<span style='color:black'>2、 预装—涂装（预装后转序涂装的预装件，如注入头核心框架总成）</span>
<span style='color:black'>3、 预装—铆焊—涂装（预装后转序铆焊的预装件，如离心泵及马达装配总成</span>
<span style='color:black'>**装配件**</span>
<span style='color:black'>1、装配（总装级零件及虚拟件）</span>
<span style='color:black'>**外协/外购件：**</span>
<span style='color:black'>1、仓库—预制（外协散件回司预制，如回油集块丝头）</span>
<span style='color:black'>2、仓库—铆焊（外协零件需回司铆焊及焊接，如低压管汇支架）</span>
<span style='color:black'>3、仓库—涂装（外协回司无需研配，涂装后上装配的零部件，如计数齿盘）</span>
<span style='color:black'>4、仓库—装配（外协回司无需研配及喷涂的部件，如仪表箱）</span>
<span style='color:black'>5、仓库—铆焊—涂装；（研配无需焊接的外协结构件，如装配式的支架）</span>
<span style='color:black'>6、仓库—铆焊—装配（外协回司后铆焊研配，无需焊接及涂装，如燃油箱）</span>
<span style='color:black'>7、仓库—预装（外购件无需喷涂，回司预装，如离心泵盘根）</span>
<span style='color:black'>8、仓库—预装—下料—预装（采购件回司需拆卸加工，如离心泵蜗壳）</span>
<span style='color:black'>9、仓库---下料</span>
<span style='color:black'>**二、工艺路线自动添加原则**</span>
<span style='color:black'>1、零件上级为焊接件，顶层为装配件，零件、焊接件及装配件属性均为自制，为零件自动增加“下料—预制”一级路线；</span>
<span style='color:black'>2、装配总成自动增加“装配”一级工艺路线。</span>

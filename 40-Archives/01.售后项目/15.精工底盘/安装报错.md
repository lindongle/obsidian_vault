<span style='font-weight:bold;background:white'>Tcserver process crashes while opening user's TaskInbox</span>
<span style='background:white'>Software Versions/Configuration:</span>
<span style='background:white'>=========================</span>
<span style='background:white'>Teamcenter 13.1.0.5</span>
<span style='background:white'>Description of Problem:</span>
<span style='background:white'>==================</span>
<span style='background:white'>After upgrading to TC13 the tcserver process crashes while expanding the content of user's TaskInbox.</span>
<span style='background:white'>The crash produces a core dump, see below the stack trace retrieved from the coredump file.</span>
<span style='background:white'>The OOTB preference TaskInbox_DefaultChildProperties contains by default three entries:</span>
<span style='background:white'>- contents</span>
<span style='background:white'>- fnd0ScheduleTasks</span>
<span style='background:white'>- fnd0SubscriptionMessage</span>
<span style='background:white'>By removing the entries "fnd0ScheduleTasks" and "fnd0SubscriptionMessage" from the preference TaskInbox_DefaultChildProperties, the tcserver process does not crash any longer and the TaskInbox correctly loads the TaskToPerform and TaskToTrack folders. By adding one of the additional entries "fnd0ScheduleTasks" or "fnd0SubscriptionMessage" into the preference makes the tcserver crash again and no content of the user's TakInbox is loaded (not even the TaskToPerform or TaskToTrack folders).</span>
<span style='background:white'>Steps to Duplicate:</span>
<span style='background:white'>==============</span>
<span style='background:white'>N/A. Only in customer environment.</span>
<span style='background:white'>Workaround/Solution proposal:</span>
<span style='background:white'>========================</span>
<span style='background:white'>No</span>
<span style='background:white'>Refer to coordinator notepad for more information.</span>

<span style='background:white'>Siemens Digital Industries Software believes that the problem you reported where opening the Inbox-ScheduleTasks folder in RAC results in an exception thrown will be resolved by code changes made to the releases of our product Teamcenter versions 13.1.0.7, 13.3.0.5, 13.3 and 14.</span>

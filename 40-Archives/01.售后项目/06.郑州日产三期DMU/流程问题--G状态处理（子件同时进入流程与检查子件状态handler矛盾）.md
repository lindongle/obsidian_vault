8:59
1、120handler
一、根节点
指派：
- [x]  删除当前所选择发起流程对象的发布状态。  

开始节点：
验证规则
1）检查流程目标对象的对象类型必须为XX
2）检查流程目标对象的发起者必须是零件的所有者
3）验证流程目标对象必须是未发布状态
- [x]  4）验证当前选中对象的最终发布状态必须是S。  

操作处理：
1）遍历下级最新版本的所有人为当前登录用户的状态为非发布状态的子件进入流程
2）将当前对象规格关系、BOMVIEW、附件关系下的数据进入流程。
- [x]  3）将零件状态打为G状态。  

执行节点：
规则处理：
1）不允许流程中增加或移除目标附件
2）不允许未签入的目标进入流程。
二、提交
1）允许此步流程所有者可以编辑流程审批对象
- [x]  2）删除G状态标记。  

3）不允许流程中增加或移除目标附件
4）不允许未签入的目标进入流程
5）检查ECNote属性必须填写
- [x]  6）检查所有子件的状态必须是S。  

- [x]  7）删除G状态标记  

开发handler，放到根任务和do任务的开始节点，检查当前零组件所有下级件，如果有发布状态，则必须为XX状态，多个状态为或关系，如果没有发布状态，则继续，不检查。

<span style='color:red'>**注：调研时，关键用户需携带变更过程中产生的各个资料及文档，便于现场演示。**</span>
**A阶段：建议-工程更改建议**
1.  主机厂、供应商、内部提出问题或需求的方式和流程是什么？提供样例。
2.  提出更改申请的文件编号及表单样式？
**B阶段：工程更改建议评估：部门级评估-\>项目级评估-\>费用及方案审批-\>确定项目组**
1.  更改建议评估单中的项目阶段与设计阶段的关系；
2.  工程更改建议评估中部门级别与项目级别评估的侧重点？在工程更改建议评估单表单中如何划分；
3.  部门级别评估后才可以进行项目级别评估吗；
4.  部门级别和项目级别都是由哪些不同角色进行的（项目级别要求高级经理以上），是否有交集；
5.  工程更改费用方案审批流程目前的审批在哪个系统或线下走，是否规划到PLM中，流程节点和角色有哪些？
6.  项目组都有哪些角色，是否流程图涉及的角色都要进入项目组，每个角色的权限划分？
7.  <span style='color:red'>SOP+6之后发生的更改是否重新立项？</span>
8.  <span style='color:black'>变更建议评估单编码规则文件？</span>
9.  产品工程更改和过程更改的划分原则及流程区别，有无规范文档？--提供过程更改管理规定
10. <span style='color:black'>生产工厂，目前都有哪些？</span>
11. <span style='color:black'>更改原因及目的，目前有两个设计优化、过程优化，其他是否都合并到这两个中，是否细分？以下样例</span>
![image1](90b146980c02479db38710b8eeec2bb1.png)
12. <span style='color:black'>表单中说明中大概填写什么内容？</span>
13. <span style='color:black'>更改描述与建议措施是否可以分开填写？</span>
14. <span style='color:red'>需明确同一更改建议对应多个或一个工程更改建议评估单的拆分原则？</span>
15. <span style='color:black'>内部申请部门审批和接受部门审批，目前只有三个节点，审核和批准只有各一个人还是会签，具体的流程是什么？</span>
16. <span style='color:red'>评估内容：方案实施评估（技术可行性、产品认可法规认证、断点实施）、进度评估、成本评估及内部细节评估点的的串并行矩阵表？</span>
17. <span style='color:red'>评估中NA，即判断是否涉及，是否可以合并到否。</span>
18. <span style='color:black'>断点实施中非自然切换的库存的数量及成本等影响在哪体现？后面的呆滞产品处理费用？</span>
19. <span style='color:black'>方案内容可行性评估的判断原则的管理性或经验性文件提供，判断哪些点，未来系统形成判断的参考经验库等。</span>
20. 明确概念，首件-OTS，首批-PPAP，PRT-SOP前试生产
21. <span style='color:black'>咨询：传统与两片指什么？同时出现或二选一？</span>
22. <span style='color:black'>样件费用的计算工时或原则？主要PRE部分</span>
23. <span style='color:black'>样件费用中人工费用与下面的人工是什么区别？</span>
24. <span style='color:black'>工程更改等级定义的原则或判断依据？--提供文档和解释</span>
25. <span style='color:black'>评估总结中，判断方案可行性、进度可行性、经济可行性及综合可行性的判断？根据上述中哪一条为基准或按各个点的评估通过率来判断？</span>
26. <span style='color:black'>评估总结中，费用的处理办法有哪些，是否做下拉框</span>
27. <span style='color:black'>审批的流程节点？是否根据评估总结中的费用总结直接判断是否到总经理审批？</span>
<span style='color:black'></span>
<span style='color:black'>**C阶段（流程图是否标注错为B阶段）-批准-提交更改申请-\>细化方案-\>方案评审-\>费用审批-\>更改审批**</span>
1.  <span style='color:black'>向顾客提供更改申请的样式（初步方案）和方式？</span>
2.  <span style='color:black'>细化方案会编制哪些文档，什么类型或格式，如DFMEA等，描述主要开展的具体工作</span>
3.  <span style='color:black'>方案评审的流程节点和角色（如有分支，特殊说明）</span>
4.  <span style='color:black'>细化方案过程中涉及到供应商，如模具供应商的方案如何交互，产生哪些文件或表单？产生的各个文件同步流程审批还是各自的审批过程？DFA是哪个部门？</span>
5.  <span style='color:black'>细化后是否会对变更评审评估单的内容进行更新，主要更新哪些内容？</span>
6.  <span style='color:black'>费用审批的流程节点有哪些，与B阶段的费用审批流程是否不同，区别有哪些？真没审批单还是审批更改评审单？</span>
7.  <span style='color:black'>超出评估阶段的费用后重新提交流程是指什么意思？重新到评估阶段还是流程节点需增加或补充说明？</span>
8.  <span style='color:black'>费用中产生的商务谈判，主要针对供应商还是针对客户，商务谈判完成的输入是什么，如何体现，是否谈判结束后费用审批才能继续往下走流程？</span>
9.  <span style='color:black'>向顾客提交工程更改的资料或文件有哪些？什么形式交互？工程更改进度如何体现？</span>
10. <span style='color:black'>工程变更评审单的编码规则？</span>
11. <span style='color:black'>企业内部变更对零件号是否变更的原则是什么？变更前后前面的状态是什么含义（N/F/U）</span>
12. <span style='color:black'>评审单中更改只有产品名称，是否零部件的修改都会重新更换产品总成的名称，如果不换的情况，零部件如何体现？</span>
13. <span style='color:black'>关键节点信息，调试验证时间、首件认可时间、首批认可时间在评估单中为何不体现，是否可以放到产品总成信息中体现？</span>
14. <span style='color:black'>工作任务清单中，只有产品特殊特性清单由工艺填写，是否过程的特殊特性清单合并在了一起？</span>
15. <span style='color:black'>一个更改评审单可更改多个项目，不同项目的不同的任务的计划完成时间如何对应？</span>
16. <span style='color:black'>设计和工艺的控制计划是否都由质量部门负责编制？</span>
17. <span style='color:black'>工程更改负责人的任务基础数据维护，主要在哪维护哪些数据？进度计划在哪维护？</span>
18. <span style='color:black'>未发现对采购部在途、生产部在制、物流部在库的处理意见，目前在哪体现？</span>
<span style='color:black'></span>
<span style='color:black'>**D阶段：执行，工程更改单发放-\>实施跟踪-\>更改验证-\>更改认可**</span>
1.  <span style='color:black'>工程更改单与工程更改评审单在内容上有何区别？编码规则？</span>
2.  <span style='color:black'>TEA什么含义？</span>
3.  <span style='color:black'>更改实施跟踪每个环节（尤其设计及工艺）的具体工作及输出？如何操作执行的？</span>
4.  <span style='color:black'>更改后的样件是否还需要OTS？</span>
5.  <span style='color:black'>OTS/PPAP/PTR报告目前的管理方式？</span>
6.  <span style='color:black'>外部PTR后才能切换吗？还是并行即可</span>
<span style='color:black'></span>
<span style='color:black'>**E阶段：切换，切换通知-\>断点**</span>
<span style='color:black'></span>
1.  <span style='color:black'>获取顾客的切换通知是什么样的？</span>
2.  <span style='color:black'>工程更改切换工作主要有哪些具体工作？</span>
3.  <span style='color:black'>各部门更新并发放的文件是哪些？实施更改跟踪中的输出吗？</span>
4.  <span style='color:black'>断点切换检查表中的零件清单没有？单独附页吗？</span>
5.  <span style='color:black'>断点检查项的签字是否线上审批，文件中显示电子版？</span>
6.  <span style='color:black'>检查项负责人确认，如何检查是否完成？</span>
7.  <span style='color:black'>变更计划在哪个地方体现？</span>
8.  <span style='color:black'>断点切换检查表的审批只有PME确认即可？</span>
9.  <span style='color:black'>断点执行管理规范展示</span>
10. <span style='color:black'>更改执行单的审批角色？发放流程？属地质量负责人采用什么形式确认</span>
<span style='color:black'></span>
<span style='color:black'>**F阶段：总结**</span>
1.  <span style='color:black'>工程更改的计划及目标是否来自于更改建议评估单？目标是否达成如何统计，即实际情况如何跟踪？</span>
2.  <span style='color:black'>经验教训文件都有哪些？如何共享的？</span><span style='color:red'>后面数据整理提取</span>
3.  <span style='color:red'>工程更改跟踪管理表</span>？汇总统计表？
4.  如何管理各个项目的所有变更，变更类型的分析会是都定期举行，报表数据如何获取？
5.  整个项目变更资料目前如何管理所有输入输出

For using local translators:
• In the Teamcenter rich client, check that the value of EDA_PreferredLocalTS preference
is set to True.
• Check the TCEDAClient.properties file to make sure that ECADTranslatorDir is specified
correctly.
• Check the EMPS installation to make sure that all required translators are installed

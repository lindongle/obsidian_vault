你还在裸用 WorkBuddy 吗？别再装上后直接发起任务，默认设置里很多好用的功能都处于关闭状态，裸用相当于白白浪费一半实力。

跟着下面这套设置调整，教你调教出一个稳定不掉线、可控不翻车、产出高质量的 AI 搭子。

**01**

**设置入口**

所有设置入口统一：打开 WorkBuddy，点击左下角头像→设置→通用，即可进入设置界面。

![[99-Assets/ef9297c337a1e22e9466779412f8bb2d_MD5.png]]

**02**

**通用设置优化**

### **1\. 熄屏持续干活：熄屏后保持唤醒**

找到「允许锁屏运行」，切换为熄屏后保持唤醒。

电脑屏幕熄灭之后，WorkBuddy 依旧可以持续执行任务，适合长时间批量处理文档、数据分析、网页检索类任务。

![[99-Assets/9138ec4b7d35869ee4c085b90ea50e8e_MD5.png]]

### 2\. 防止系统休眠打断任务：运行时防止系统休眠

打开「运行时防止系统休眠」开关。很多长任务中断，根源不是软件崩溃，而是电脑自动休眠。开启之后，任务执行期间电脑不会自行休眠，保障任务跑完。

### 3\. 自动获取新能力：技能自动更新 + 套件自动更新

同时开启这两项。后续官方上新工具、修复 bug、优化原有技能，软件会自动更新，不用手动反复下载重装，随时用上最新能力。

### 4\. 必改！修改存储路径，拯救 C 盘

Windows 用户重点看：默认缓存、生成文件都存在 C 盘，任务一多很容易挤占系统盘空间，电脑越来越卡。

建议把默认存储路径迁移到 D 盘、E 盘等空间充足的磁盘。

### 5\. 任务完成提醒：开启通知提示音效

进入通知设置，选择一个听得见的提示音。

不用一直盯着界面刷新进度，任务跑完会自动响铃提醒，解放双手，安心做别的事。

![[99-Assets/b1f793e0dd7ec969752585391a2aac3d_MD5.png]]

**03**

**个性化设置优化**

路径：设置 → 个性化

在这里填入自定义指令，给你的智能体定下固定工作准则，不再只机械执行表层指令。下面三条可直接复制粘贴：

-   **第一性原理**：要求智能体刨根问底，挖掘问题底层逻辑，不局限于表面指令，拒绝套用模板化答案。
    
-   **PDCA 执行循环**：让智能体按照「计划→执行→检查→行动」闭环工作，任务完成后自动复盘、优化方案。
    
-   **对抗式审查**：每次交付内容前进行自我审查，主动排查逻辑漏洞、信息错误、格式问题，确认无误后再输出，减少返工。
    

![[99-Assets/9e2014c7ee76cbece4e1a920023e497a_MD5.png]]

设置好之后，每一次下发任务，AI 都会带着这套标准思考和产出，内容深度和靠谱度会明显提升。

上面的指令只是参考模板，你也可以结合自己的业务场景，自行设计指令，比如固定文档格式、行文风格、数据校验要求等，定制属于你的规则。

**04**

**记忆与进化设置**

路径：设置 → 记忆与进化

开启 云端记忆 和 本地记忆与技能。

开启后，WorkBuddy 会自动记录你的工作背景、表达偏好、常用格式、过往项目要求。同类需求不用反复重复说明背景，它会慢慢适配你的工作习惯，真正做到长期进化。

💡小提示：如果处理涉密、一次性敏感工作，可以临时关闭记忆功能，用完及时清理记录，兼顾效率和安全。

**05**

**快速配置清单（收藏保存）**

✅ 运行时防止系统休眠

✅ 技能自动更新、套件自动更新

✅ Windows 修改存储路径至 D/E 盘

✅ 开启任务完成提示音效

✅ 个性化填入：第一性原理 + PDCA 循环 + 对抗式审查

✅ 开启云端记忆、本地记忆与技能

简单调整完这一套配置，WorkBuddy 才算真正成为你的靠谱办公搭子。稳定不掉线、不挤占 C 盘、做完主动提醒，思考有深度、交付先自检，还能记住你的工作习惯，而不是一个只会简单应答的对话工具。

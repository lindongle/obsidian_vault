在 GitHub 上看到一个用 Rust 写的 Windows 任务管理器，叫 **Argus**。

项目在 10 月中旬开源，目前已经拿到 **2300 多个 Star**，采用 AGPL-3.0 协议，这篇文章简单介绍一下它的功能和使用方法。

平时电脑突然卡顿、风扇狂转，或者删文件提示被占用、调试服务撞端口，大家通常会打开 Windows 自带的任务管理器。

系统自带的工具日常够用，但想看清楚进程的父子层级、倒查几分钟前到底是谁吃满 CPU，或者顺手查一下文件占用和端口连接，往往还得再装几个辅助软件。

**Argus** 用 Rust 直接调用 Windows 原生接口，基于原生桌面组件绘制，整体响应比较快，顶部的一分钟负载曲线会跟着屏幕刷新率连续滚动。

![[99-Assets/f0472931608285513d57fb01dcacd343_MD5.jpg]]

打开软件后默认进入进程页，支持按应用、进程树和完整列表三种方式查看。

想排查某个软件拉起的所有后台子进程时，切换到进程树视图，再按 Ctrl+F 输入名称就能直接筛出来，右键可以一键结束整棵进程树。

遇到列表跳动太快不好选中目标时，按住 Ctrl 键就能临时暂停画面刷新，松开手自动恢复。

![[99-Assets/ef3d465d71af7e37508c48e15b896a4f_MD5.jpg]]

切换到性能页，可以看到更详细的硬件运行状态。

除了常见的内存、磁盘、网络和 GPU 曲线，处理器面板会列出每个性能核与能效核的实时负载，同时显示当前频率、温度和功耗读数。

![[99-Assets/569e745ef4dd616bcacace086b67bdbe_MD5.jpg]]

自带任务管理器有一个挺头疼的地方，电脑卡顿刚过去再打开，资源占用已经回落，很难追查刚才究竟是哪款软件引起的。

Argus 专门做了一个 **历史回溯** 页面。

用户可以在时间范围里选择几小时甚至几天，直接点击曲线上出现尖峰的那个时刻，下方列表就会还原出当时最忙的一批进程。

![[99-Assets/a28dec9b457a52b02265f7c61bb2ec40_MD5.jpg]]

日常整理资料时经常遇到文件夹删不掉，提示正在被另一个程序使用。

用 Argus 排查不需要记命令，直接把删不掉的文件或文件夹拖进软件窗口，界面会弹出占用列表，标出具体锁住文件的进程，直接在弹窗里结束掉就能删。

![[99-Assets/66304672e8ad1e070bb9efc96ce2f52e_MD5.jpg]]

如果电脑上有视频转码、同步盘这类容易抢资源的软件，右键点击进程可以直接把它设为低优先级或开启效率模式。

不想每次打开软件都手动调一遍的话，可以直接给它建一条规则，以后这个程序一启动就会自动套用对应的优先级设置。

![[99-Assets/e16a7b161e5a7e751e243f52734aee4a_MD5.jpg]]

写代码或者本地起服务时经常碰到端口冲突，软件内置了 **连接与端口** 页面。

在搜索框直接输入 8080 这类端口号，就能查出正在监听或建立连接的对应进程，选定后可以直接在界面里断开连接。

![[99-Assets/0e11144b6b339b150e2eb055d2075b56_MD5.jpg]]

除了上面几个常用功能，侧边栏还整合了系统服务启停、开机启动项管理、运行新任务和重启资源管理器。

软件外观支持 Mica 背景材质，跟随系统深浅主题和强调色切换，内置包括简体中文在内的 8 种语言。

![[99-Assets/99b5a3762e80ceec6783246f5de17b29_MD5.jpg]]

平时点击关闭可以缩进系统托盘常驻后台，隐藏状态下资源占用很低，按 Ctrl+Alt+Esc 随时呼出或隐藏窗口。

日常操作也配齐了常用快捷键，用 Ctrl+1 到 Ctrl+8 快速切换各个功能页，选中进程按 Enter 看详细信息，按 Delete 或 Alt+E 结束进程。

用顺手之后，也可以在设置里把 Argus 设为替换系统任务管理器，以后按 Ctrl+Shift+Esc 会直接拉起它。

如果还没决定要不要装，可以先在浏览器打开项目官网 argustask.com，里面做了一套免安装的在线界面演示，可以直接点一遍各个页面。

正式使用去官网下载页或 GitHub Releases 获取压缩包或安装程序就行。

官方同时提供了支持应用内自动更新的安装版 Argus\_0.5.0\_x64-setup.exe，以及单文件直接运行的免安装版 Argus\_0.5.0\_x64.exe，两者共用配置与历史记录。

如果想从源码自己编译，提前装好 Rust 工具链、Node.js、pnpm 和 Visual Studio 的 C++ 桌面开发组件，在仓库根目录用 PowerShell 运行下面命令即可：

```
.\start.bat
.\start.bat build
```

第一行用于开发调试并自动重新编译，第二行会直接构建出正式可执行文件。

开源地址：

> https://github.com/Ray-lea/Argus

实际使用前有几点限制需要先了解一下。

软件目前只支持 64 位的 Windows 10 22H2 及以上版本和 Windows 11，且需要支持 DirectX 11 的显卡驱动，暂不支持 ARM64 架构设备。

硬件温度和功耗读数取决于具体 CPU、主板和驱动支持情况，使用 Intel RST 或厂商 RAID 驱动管理的硬盘目前无法显示温度和健康状态。

开启替换系统任务管理器会修改对应的系统注册表项，卡巴斯基等部分杀毒软件可能会对这项改动给出提示，如果不想折腾误报，保持不替换，平时改用 Ctrl+Alt+Esc 呼出就行。

另外，项目目前处于接入正式代码签名的过渡阶段，下载安装程序首次运行时 Windows 可能会提示未知发布者，确认来源后继续运行即可。

## 写在最后

对于大部分 Windows 用户来说，系统自带的任务管理器平时够用，但真遇到回溯卡顿元凶、查文件占用、按端口杀进程或者给常用软件设自动优先级时，还是明显差一口气。

Argus 用原生组件把这些高频排查功能收进了一个轻量窗口里，响应跟手，界面也清爽，不需要为了不同需求在三四个工具之间切来切去。

如果你日常用 Windows 办公或开发，想找一个信息更全、又保留原生手感的任务管理器替代品，可以先去官网在线点一遍，或者直接下个免安装版试一试。

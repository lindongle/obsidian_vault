时间：3月6日 PM 1:20~2:10
地点：213会议室
参会者：
春风：技术中心/发动机研究部-朱部长； 四轮车事业部/ 产品管理部-张工；IT-郭经理；
西门子：蔡老师、李宏峰、孙毅；
1.  发动机研究部组织架构：
    1.  固定件科
    2.  运动件科
    3.  性能分析科
    4.  性能开发科
    5.  ......
2.  发动机开发流程：
    1.  发动机有自己的流程体系文件，整体上套用技术中心统一的开发流程，由于多年积累较成熟，会适当按自身开发特点做精简；
    2.  开发阶段：立项-C、方案确认-D1、方案验证-D2、品熟确认-E1、量产-E2、3M、12M；
    1.  产品端输入产品需求；
        1.  各事业部下属的产品管理部接收客户产品需求并组织解读；
        2.  各事业部的开发部转换为工程开发需求；
    2.  总布局方案设计：产出Layout布局图并评审通过；
        1.  全新的发动机开发，会在3d环境下做至少3轮的虚拟评审；
        2.  在初次评审时也会做2d的总布局的评审；2d详细设计完毕后做工程图的综合评审；
        3.  每次虚拟评审的数据都是在线下实时打开评审并记录问题表格，跟踪问题整改状态，当前未上传思普系统管理；
        4.  评审工作属于研发内部管控，非体系流程的严格要求，数据的冻结暂未有清晰的界限要求；
        5.  存在前期的多方案设计，会选择性的进行某一数模方案的冻结；
    3.  各个子系统做评审；
    4.  各个子系统做详细设计，产出2D图纸资料；
        1.  3D使用UG，大件（如：箱体）使用3D投图后导为dwg，在CAXA中修改并标注；小件直接用CAXA出图；2维、3维不关联，由工程师自己控制；
        2.  小的变更，直接改CAXA图纸，并同时管理上要求工程师同步修改UG；
        3.  3D未强制要求纳入思普系统中管理；
        4.  前期与供应商交流的使用Caxa的2D图纸，主要是考虑到灵活的修改及交流，如：拔模斜度等；
    5.  产品打样；
    6.  装机并做测试，处理问题；
    7.  小批件 - 模具件；
    8.  批产；
3.  发动机研究部与整车协同：
    1.  相较于乘用车，与整车协同更加频繁；
    2.  将发动机的数据打成轮廓，输入给整车进行评审；
4.  发动机研究部痛点&关注需求：
    1.  项目各阶段图纸如何合理管理？3d、2d、技术资料如何有效管理？特别是3d如何有效管理？
    2.  试制阶段的变更如何合理的管理？技术资料管控要有效且变更流程要简化；定版的数据进入D1后的变更如何管理？
    3.  问题整改的数据如何记录并控制版本？
    4.  UG出2D图比较麻烦，不适合发动机事业部使用，二维Caxa更适合；

5.  四轮车事业部/产品管理部组织架构：包含项目管理、产品开发管理两大职能；
    1.  产品经理：4人，按产品系列分工；
        1.  ATV系列；
        2.  方向把式；
        3.  UTV系列；
        4.  SSV系列等；
    2.  项目经理：5人，负责产品开发项目过程管理；
6.  四轮车项目管理：遵循技术中心出具的《新品项目开发手册》，包含开发流程、项目管理方法，由技术中心办公室按需修订；
1.  矩阵式的项目组管理，按项目组建横向项目组；
2.  事业部/开发部出项目技术负责人（DPL），同时也负责前期面向客户的技术对接；
3.  事业部/项目管理部出项目经理（LPL），主要负责项目过程的进度、协调、问题等；
4.  项目类别：项目立项时会分级，共7级；四轮车事业部今年有1、2个7级项目；另外是一些改型的中小项目；有三个新能源的项目在运行，其中1个主推、1个储备、1个研究；
    1.  全新开发项目周期约30M；
    2.  改型升级开发，如：增程开发等，周期约20M；
5.  项目立项阶段：
    1.  成立了公司级产品委员会，统筹从市场、客户等渠道收集信息并建立产品规划，明确后输入到各事业部的产品管理部产品经理；
    2.  产品经理进行产品和项目的规划，形成本事业部开发项目要求；
    3.  产品经理在BPM中执行立项流程；
    4.  LPL项目经理负责组建团队，设计（DPL--设计担当）、生产、供管（供管担当）等各环节制定接口人。
6.  项目创建及过程管理，使用国产的iMIS-PM集成项目管理系统，2022年刚上线，正在推广应用过程中，主要管理内容如下：
    1.  项目信息：体现项目分级和类别；未与BPM集成；
    2.  项目人力
    3.  项目动态
    4.  项目文档：与思普系统未集成，对于项目交付物的管理边界以及进度更新管理尚未全部清晰化；
    5.  项目进度：工程师在系统中更新进展；
    6.  项目对应车型的专用件开发要求，使用Excel表，如：《9DQ3专用件清单.xls》，由技术中心/新品开发质量部（项目管理科&焊接科、功能科、发动机科）/项目管理科，负责新品专用件清单中所有零部件的跟踪管理，各环节分工如下：
        1.  DPL部负责零部件的设计实现；
        2.  供管负责新供应商选择；
        3.  新品开发部负责与供应商对接进行外购件（含：成品件及毛坯件）的跟踪、管理、质量和导入；
四轮车：绝大部分外购；车间自己负责焊接，但其毛坯件属于外购，也需要由新品开发部管理

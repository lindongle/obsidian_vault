## 一、建模路线（NX 正向设计：先成品，再拆分，WAVE 骨架驱动）

✅ 建模顺序（严格正向）

1. 顶层骨架 Skeleton（Skel.prt）
    - 放总成外形边界、3 个毛坯定位 CSYS、孔的位置驱动点 / 驱动面；
    - **所有接口、打孔位置、毛坯布局全部在骨架定义**；
    - 骨架是唯一主驱动，后续所有零件从骨架拿参考。
2. 第一步：先做**最终成品零件 W’.prt（机加后焊接总成，带孔）**【正向起点】
    
    - W’是 NX Part，代表交付状态成品；
    - 在 W’里面，基于骨架 WAVE 链接定位基准，做出完整成品实体（包含那一个孔）；
    
    > 👉 这一步满足你的要求：**正向先有打孔后的总成**，先把成品状态定下来，评审、干涉、PMI、图纸、仿真全部拿 W’。
    
3. 第二步：从 W’/ 骨架，拆分出 3 个毛坯 A 的几何（WAVE 单向引用骨架，不反向参考 W’）
    - 激活毛坯 A.prt，WAVE 从骨架链接外形轮廓基准，创建毛坯实体（无孔）；
    - 3 份 A，共用同一个 prt，物料相同，几何完全一致，不带孔；
    - ❗重点：毛坯 A**禁止 WAVE 链接 W’上的孔面**，毛坯不继承孔特征，保证毛坯永远是焊前状态。
4. 第三步：搭建焊接装配 W（焊合中间态，无孔总成）
    - W 是 NX 装配，装配导航器放入 3 个 A 组件，约束绑定骨架 CSYS；
    - W 只表达 “三个毛坯拼焊在一起” 的几何状态，W 装配里**没有孔**；
    - W 可以增加焊接特征（焊缝、焊道），表达焊接工序后的状态。
5. W’和 W 之间的关联（可选，用于变更联动，不强求）
    - 方式 A（弱关联，推荐，变更可控）：W’和 W**都只依赖顶层 Skeleton**，同源骨架驱动，互相不直接 WAVE；骨架改孔位，W’孔跟着动、W 上毛坯位置同步动；
    - 方式 B（强关联，前面方案 3）：W’ WAVE 参考 W 里的实体，在 W’打孔；优点是 W 的毛坯外形修改自动带到 W’；缺点多一层 WAVE 链路。
- ```
【Assembly】W'.asm   顶层：机加后成品焊接总成（交付件，正向最先设计）
├─ [RefOnly 参考组件] ──WAVE──> 【Part】Skel.prt 顶层骨架
│        骨架内容：毛坯外形基准、定位CSYS、孔驱动点位（无切除孔特征）
├─ 组件 ──COMP──> 【Assembly】W.asm 焊接中间总成（BOM必须保留的中间件，无孔、带焊缝）
│        ├─ 组件 ×3 ──COMP──> 【Part】A.prt 毛坯件（仅WAVE引用骨架外形基准，不带孔）
│        └─ ──WAVE──> Skel.prt（读取定位CSYS）
└─ W'自身内部WAVE链接：从子装配W拾取目标毛坯几何 → 在W'.asm的工作部件内创建孔特征
```

# 数智化所（仿真、测试）
- **调研时间**：2026/10/19 9:00~12:00
- **调研人**：李婷、程攀龙
## 组织结构
- **总人数**：17-18 人；之前单纯做仿真，现扩展为仿真、测试、电气、软件多模块
- 部分人员负责多模块（仿真、电气、软件交叉）
### 机械（4 人）
- **结构 / 流体仿真**
  - 工具：UG 11（使用NX 13500模块，Simcenter 3D Structures）、Ansys（结构）、Fluent
  - 主要看个人熟悉哪些工具
- **测试**
  - 内容：振动、热分析、噪声等
  - 工具：LIMS 系统，另有不同测试工具（压力、热传感器、力锤等）
### 电气（4 人）
- 由电气所调入数智化所，目前均出差，做 PLC 开发
- 车间程序调试
- PLC 开发，偏硬件的开发、调试
- 现场数据采集（传感器外接采集模块，采集后进行转换处理）
- 目前与电气所交互不多；承担部分调试任务、电气原理图审核（人手不够时）
### 软件（5 人）
- 数控软件开发
- **数控系统二次开发**：语言 C++ / XML / C# / Linux，使用标准接口，立车比较多
- 自研小软件：温度采集系统、给设计做偏计算的开发
- **NX 二次开发不做**；但之前标准化部门工程师开发过 NX11 的功能，需评估在 NX12 上是否可用，并确认哪些功能还在用
- **LIMS 二次开发不做**，只使用其数据进行分析
- 源代码：放在自己本地，基本一个人独立完成
## 仿真交互
### 售前
- 前期了解，给比较粗的工件，前期做仿真分析，分析报告写入投标书；交互过程与设计阶段相同
### 设计节点
#### 机械仿真与设计交互
- 新设计的结构（如减重、轻量化优化），做一部分设计
- 设计方案不停迭代，辅助做仿真分析
  - 设计室编制仿真任务书（写明三维存放位置），线下打印 → 王院长签字 → 数智化所主任，主任分工执行
  - 仿真过程中的模型处理由仿真工程师持有；仿真结果文件较大，按需删除；仿真报告发设计员电子版，**没有走审批流程**
- **变更**：不再提供新任务书，直接发改后的模型
- 部分国家课题、高校项目的交互
#### 测试交互
- 生产、用户发现问题，反馈到设计，设计下任务书到数智化所，现场进行测试收集；通过无纸记录仪或带笔记本过去直接连 LIMS
- 其他与仿真过程一致：测试任务书 + 测试报告
#### 资料归档
- 有些国家项目等资料上传到 PDM 做归档；常规项目资料放到共享文件夹
## 软件交互
- **来源**：设计所、销售（用户，已安装调试后新增的功能需求，发客户联系函到数智化所）
- **方式**：售前 + 设计阶段，软件任务书；过程与仿真类似：接收 → 对接具体需求 → 编写框架及代码
- **变更**：设计所需求的变更很少，主要是所内程序的变更，不同版本存不同文件夹
- **调试归档**：直接在机床调试，最终代码发给设计主管或客户
### PDM 使用
- 登录查询明细、模型文档、科研项目资料
- 录入机床 BOM 的部综（机械主管给号，一级部件；科研试验部 / 试验部 XX 等，名字类似但不统一）
  - 试验用传感器（跟机床一起出厂）
  - 试验件（试验用，不跟机床一起出厂），如试验用传感器、刀具等
- 相同机床的多台，可能只在一个台份号 BOM 中录入试验件（不跟机床一起出厂）

# 标准化所
- **调研时间**：2026/10/20 9:00-12:00
- **调研人**：宋小艳、黄诗雨
## 组织结构
- 共 3 人，分为两块：1 人负责工艺数据，2 人负责标准及物料创建
### 工艺数据（1 人）
- 原工艺技术所大件工艺室借调，目前在标准化办公，以标准化工作为主
- **工艺路线 / 材料定额审核**
  - 工艺路线由工艺主管编制，标准化接收及确认
  - 材料定额由工艺员录入，标准化接收及确认
  - 工艺路线 / 工时 / 材料定额修改：工艺员提交工艺文件修改通知单（纸质小票，手工填写内容），均由标准化在转换平台中进行修改
  - 车间路线：系统自动生成后，如有问题由标准化调整
- **制造 BOM 分解与上传 SAP**
  - 制造 BOM 自制件的分解录入及上传 SAP
  - 车间变更：手动删除SAP 和数据转换平台中的 BOM，重新覆盖
- **机加工序与工时录入**
  - 工艺员通过流程将工时卡（工序定额卡片）流转到工艺标准化，标准化负责在数据转换平台录入
  - ==后续讨论：工艺员搭建工艺并发布后，直接获取工艺数据下发到 SAP。==
  - 上传 SAP 为工艺路线
    - 工作中心：手动选择（根据工序定额卡的加工机床进行选择）
    - 工序控制码：默认 PP01
    - 工时：准终 + 单件；系统自动将准终赋给 SAP 准终工时，单件赋给 SAP 的人工 / 动力 / 折旧 / 其他工时，单位均为 H
    - 工厂：==加工工序根据车间路线的第二个车间自动匹配工厂（下发界面的工厂列，确认该逻辑）==；采购都默认 1000 工厂
- ==讨论工艺路线（按设备或工段）和车间路线（按车间、分解 BOM）的区别及作用，能否整合。==
### 标准及物料创建（2 人）
- **二维图标准化审核**
  - 审核项：标题栏图框、技术要求、尺寸标准、字体大小、打印版式
  - 多个图幅、不同比例的，标题栏图框大小、字号、字体、颜色保持一致；标题栏高度均为 5，标注字体标准设置高度为 3.5
  - 主要件印章：重要件使用专门样式，标题栏多一个“审定”并据审定盖红章。==后续讨论与一般零件整合为相同模板，在属性中区分重要件及盖章。==
  - ==自动化审图：整理需要检查的 checklist 清单。==
  - 目前使用图号 + 规格型号拉引线；==后续讨论按国标方式拉序号的可行性（序号 + 明细栏）。==
- **明细表 / 装箱单审核**
  - 主要件明细表 + 部件综合明细表 + 装箱单（dwg 格式）等资料文件的审核
  - 主要审核格式的统一性，字体加粗、对齐
  - 未来讨论审核此文件格式的异议
  - 目前实验书、合格证已经更换为 Office
  - ==后面建议统一更换为 Office 格式并调用系统模板，讨论格式审核的必要性。==
- **创建物料**
  - 外购件、标准件按 01 机械 / 02 电气 / 03 专机 / 04 原材料 / 05 辅料 / 06 厂内件（没在用，原规划的自制件）区分
    - 设计所设计员拿供应商样册给到标准化，根据里面的型号、规格等先在数据转换平台中查重；如果没有则创建新物料，并归到对应零件分类表（树状结构）
    - **分类结构**：紧固件、操作件、管路附件等
      - 每类参数均相同：ID（分类层级号，如 010102）、代号或型号、名称、规格、厂家、计量单位、类型、审核
      - 代号或型号及规格在分类管理中以值模板通过 `%XXX%` 作为通配符，入库时系统会要求填写 XXX（自动将 XXX 作为独立属性输入参数）
      - 三维紧固件：前期在 PDM 系统中创建，根据物料号实例化，以文件夹结构方式管理，与物料的分类库独立管理，且未进行更新
      - ==未来梳理所有标准件，按母族 + 参数化的方式创建，并与分类库关联起来。==
    - **辅料库**
      - 分类库中只含机床、工装制作用的辅料，3 开头，由设计或工艺员提需求、标准化创建
      - 外购辅料：车间用的辅料（劳保用品、设备维修工具等），5 开头，车间自己创建、标准化审核
      - ==后续明确两种辅料的区分原则。==
- **材料牌号库**
  - 建立材料牌号库；如果没有，通过内网 EM 通讯工具进行录入，便于设计员填写
  - 专机库和机床库是分开的
- **标准编写及发布**
  - 国标 / 行标的编写及审核
  - 企标由技术编制，标准化审核
  - 发布到 OA 系统-企业专栏；目前都是线下审核
- **专利管理及跟踪**
  - 专利整体跟踪流程
    - 编制：技术专利提交初稿 → 标准化提交到代理机构 → 代理机构撰写及定稿
    - 审核：标准化进行发明人信息确认表，提交陈总审核 → 发明人（三张表）编制及技术内部签字后提交到标准化 → 公司专利负责人评审 → 公司领导批准，定稿权利要求书到标准化审核
    - 提交及受理：上传扫描件 → 代理机构 → 提交国家知识产权局、下发受理通知书
    - 审查及授权：初步审查合格通知书 → 公开发布通知书 → 实质审查通知书 → 下审查意见抄送标准化及技术人员 → 回复答复意见 → 授权或驳回
    - 年费缴纳：缴纳年费及监控（管理缴费、时间、金额；根据不同专利类型，按受理年份确认，每个专利的缴费时间不同）
  - 专利信息：类型、缴费时间、专利有效期（外观 15 年、发明 20 年、实用新型）
  - ==未来管理专利的整个流程监控及缴费提醒等。==
  - ==提供当前有效期内的专利台账清单。==
  - 软著流程差不多，不需要年费监控

### 软件组（3 人）
- 覆盖研发、生产、销售、财务、采购 / 物流 / 仓储（业务 MM）等领域。
- **PLM（天喻 PDM）**：研发生产核心，含文档、流程、知识库、BOM、变更、物料管理：
	- **文档管理**：
		- 上传文档、卡片、技术资料、技术通知、卡片（只存结果）；
		- 三维模型使用文件夹管理；每次版本上传新版本；
		- 零件图标体现是否有图：有图红色，无图灰色；
		- 三维模型仅上传部分零件三维，装配三维存本地文件夹；
		- 蓝图（正式下发用，档案室打印）+ 白图（临时用，综合管理室资料员打印，工程师走出图流程到资料员统一打印）。
	- **流程管理**：
		- 走审批流程，流程发布后生效。
	- **知识库文件夹**：
		- PDM 中的库文件夹由研究院资料员搭建，并设置归档路径，与档案管理系统文件夹结构一致；
		- 标准件库：三维模型由标准化所设计，一次性给到资料员上传；==2020 年上传后未再持续更新==；
		- 方案评审、公共资料等：资料员上传，未一直更新；
		- 各所按机型的资料实时更新。
	- **设计 BOM 管理**：
		- 使用图号管理；
		- 通过天喻 CAD 插件从二维 AutoCAD 明细表读取 BOM，单独明细表附页，均为单层，实时加载最新。
	- **变更管理**：
		- 变更申请 → 审批流程 → 通过 → 新图修改上传，换新版本重新发布。
	- **物料管理**：
		- 零件类型手动选择；导出明细表时按类型汇总到不同明细表；
		- 零件属性通过标题栏 + AutoCAD 属性填写功能（如零件特性）带过来。
	- **系统集成**：
		- ERP 数据按钮：下载数据转换平台导入模板 + 数据，手动导入数据转换平台；
		- 通过档案管理数据传递功能转 PDF，传档案管理系统，后打印下发；
		- 需求：后续打印分发放到 TC，定期传资料到档案系统做整体归档。
- **天喻 CAPP**：工艺卡片制作工具，导出卡片上传 PDM；
- **天喻 CAD**：AutoCAD + 天喻插件。
- **数据转换平台**：与天喻联合开发，设计 BOM 导入 SAP 的中转：
	- 从 PDM 系统一个菜单进入；
	- 选择客户（机台号）：一个机台对应一个客户，提前由综合管理员创建客户及所需机床型号信息；
	- 设计员导入设计 BOM（机床 + 部套件）：先导入机床，再选部套件导入，下面所有层级一次导入，几个部套件导几次。
	- **外购件（含标准件）**：
		- 存在性检查：外购件审核时匹配外购件图号和物料号，自制件不检查；
		- 审核时标准化查询库中是否存在 → 给物料号 → 转换平台维护物料号，==讨论未来放到 ERP 的 MDM 或PLM中维护==；
		- 设计时用到外购件，CAD 拉件号时到库找；找不到则标准化添加新外购件，维护参数并入库（外购件库），填写零件标准分类及物料号，设计员拉件号时可见；
		- 外购件库正在清洗，将给到新 ERP；
		- 无法匹配到库里的外购件（本身没有或写的不规范），需手动匹配外购件物料号。
	- 刚导入到临时库，确认无误后点击保存数据到正式库，正式库标识为“有”；
	- **自制件**：会校验材料牌号是否存在；需用新牌号时由标准化单独维护；
	- 工艺所专员在 BOM 上维护工艺路线、车间路线、材料定额、毛坯种类、毛坯等，维护后显示在 BOM 行中。
	- **工艺路线维护**：
		- **一级路线**：由机加工艺专员统一维护：
			- 机加、焊接（金结车间）、铸造工艺维护一级物料路线（工段），如 1610（原件下料）-1620（锻件）-2250（机加-2联车间5工段）-2241（机加-2联车间4工段）；
			- 材料定额：机加维护原件的材料定额，其他各专业维护；
			- 目前没有多一级工艺路线；因外协存在前面添加 W 的情况。
		- **装配工艺（二级）**：
			- 开机床生产订单时，生产找工艺所维护工艺路线；
			- 总装工序把部套件拉过来作为工序，增加涂漆、刮研、总装 3 道，主要供 SAP 报工/统计成本；维护工序的设备型号，根据设备型号自动判断工厂。
		- **机加工艺（二级）**：
			- 找到部件下需机加的零件，维护工艺路线；工序名称、设备型号从工艺路线库、设备型号库选择，也可单独手动维护；
			- 维护准终工时和单件工时（如 0.3 = 30 分钟），SAP 接收时乘以 100/60 转为小时。==待统一：后面统一为分钟。==；
			- 针对零件区分大件（>50kg）/中小件（≤50kg），工序库（按专业）和独立设备库；
			- 焊接件分件太多（大几十个），材料定额维护量大；
			- 目前没有多工艺路线。
		- **制造 BOM / 毛坯半成品 BOM**：
			- 以部件为单位分解（工艺路线、定额等填好后），自动生成毛坯/半成品 BOM；
			- 维护毛坯、原材料 BOM：根据车间路线（金结-中小件-立车）生成层数，名称及图号用零件图号 + “/” + 车间名称，工厂取对应车间工厂；
			- 例：车间路线金结（焊接）-中小车（机加）-立车（总装），将设计 BOM 中原焊接组件作为成品（机加后状态），在其焊接子件下插入焊接毛坯一层，名称加“/金结”；
			- 焊接件（焊接-机加-立车总装）：自动在焊接件之间插入焊接毛坯作为中间状态；
			- 有工艺路线与车间路线对照表，输入工艺路线可自动带出；
			- 需求：未来希望工艺针对设计 BOM，基于生产过程重构，目前只添加毛坯、原材料；
			- 处理数据时按图号和描述（自制件）、图号名称厂家规格（外购件）去库匹配物料号；未匹配的自动到新增物料号标签页，点击菜单批量给号；
			- 外购件发所有工厂；自制件按车间路线第一段匹配工厂，目前工厂按车间划分。
			- 下发 SAP 的 BOM：若 SAP 物料不存在，则加载需导入 SAP 物料数据的界面，先维护物料主数据，各视图取默认值下发：
				- MRP 视图特殊：每个车间独立核算，导致自制采购与车间强相关（工厂号）。X 强制标识自制；E 目前只在机床（产品）和部件（E50）用；
				- 相同物料号在不同工厂、不同采购类型，生产两行主数据。
- **物料及 BOM 更改：技术通知**：
	- 设计员先改图（内部改图通知单）。
	- **流程**：
		- 设计员修改数据（物料 + BOM）；
		- 变更申请菜单提交申请：先找到要变更部件的任一上级反查部件并打开；选择变更类型（新增/删除/修改数量/工艺修改，每一行填写）；填变更单申请（所属部件、图号、零件类型、自制件或选外购件）；
		- 工艺员维护工艺/车间路线、材料定额；
		- ERP 专员从执行变更清单中找要执行的变更数据，点击保存执行，设计 BOM 自动更新；
		- ERP 专员点击“信息办-变更单新增零件”菜单，按日期查询刚执行的变更记录，双击跳转工艺分解 BOM 界面，自动定位对应零件（变红色），点击产生 BOM 初步数据（按车间路线自动生成毛坯件），勾选 BOM，处理数据（形成正式 BOM、父子关系），保存到正式库；
		- 物料下发 SAP；BOM 更改，需要设计所的内容变更在 SAP 手动操作进行物料新增。
	- 变更数据维护后，同步 OA 发起技术通知单流程：
		- 流程到工艺，工艺进行设计；
		- 到设计的 ERP 专员，专员进行工艺路线维护、定额维护；
		- SAP 维护、执行变更、发 SAP、SAP 修改 BOM。机床一级部件的整体子件添加由标准化的 ERP 专员一起维护，单个添加由各设计所的 SAP 专员维护。
